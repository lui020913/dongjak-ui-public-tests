# v8.2.9 모바일 UI 좌표 통합 / 2026-11-14

기준: `DongjakApp_FULL_v8.2.8_KAKAO_OAUTH_DIAGNOSTICS_20261113(1).zip`

## 배경과 수정

기존 `v790`~`v828`의 UI CSS가 모바일 버튼·패널에 서로 다른 `top`, `bottom`, `width`, `z-index`를 `!important`로 반복 지정하여 특정 기기에서 요소가 밀리거나 겹치는 문제를 확인했습니다. **기존 파일 삭제/교체 대신** 마지막 위치에 로드되는 `src/v829-mobile-layout-system.css`를 추가했습니다.

- 상단: 앱 로고 / 검색창 / 테마 버튼을 한 줄에 고정하고 검색어 입력 영역이 좁아지지 않도록 `min-width:0` 및 16px 입력 규칙 적용
- 검색: 가려져 있던 기본 플레이스홀더를 다시 표시하고, 결과창은 화면 경계 내에서 독립 스크롤
- 모바일 도구: 지도 옵션·보행안전·야간시야·가독성·날씨·더보기 6개 버튼을 가변 크기 **동일한 원형**으로 배치. 활성 버튼이 확장되면서 나머지 아이콘이 밀리는 현상 제거
- 지도 조작: 나침반·도로폭·내 위치 등 우측 버튼을 도구줄 아래 세로 스택에 정렬
- 하단 메뉴: 5개 탭을 동일 폭으로 분배하고 홈 인디케이터/하단 안전영역 위에 고정. 내비게이션 안내와 몰입형 화면에서는 자동 숨김
- 버스·지하철: 선택한 시설 마커의 지도 화면이 남도록 하단 정보창 높이를 각각 최대 43dvh / 50dvh로 제한하고 창 내부 스크롤 유지
- 길찾기·커뮤니티·소식·내 기록: 화면별 패널을 하단 탭 위에 고정하고 본문 높이만 스크롤. X 버튼을 제목의 독립 그리드 칸에 중앙 정렬, SVG가 없을 때도 닫기 표시 제공
- 안전지도·지도옵션·행정동·시설정보 및 설정 모달: 안전영역과 화면 폭에 맞춰 최대 높이/좌우 여백 일치
- `hidden` 속성을 가진 교통/페이지 패널이 CSS에 의해 재등장하거나 터치를 가로채지 못하도록 처리
- 키보드 자동 확대 방지를 위한 모바일 입력 최소 16px 유지

## 적용 범위와 한계

`src/main.js`, 지도 지형·데이터·마커·교통 API, GPS 경로 로직, Supabase/카카오 OAuth 로직은 수정하지 않았습니다. 변경 소스는 신규 CSS, `index.html`의 링크 및 테스트, 패키지/릴리스 메타데이터에 한정됩니다.

Chromium의 **정적 레이아웃 시뮬레이션**에서 폭 320/360/390/430/600px, 지하철·버스·길찾기·내 기록·안전도구·지도 옵션·검색 상태에 대한 배치 검사를 수행했습니다. 실제 지도 타일과 API를 로드한 통합 실행이나 iOS Safari 실기기 검증과는 별개입니다.
