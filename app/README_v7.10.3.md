# DongjakApp v7.10.3 — 모바일 행정동 선택창·더보기 중첩·iOS PWA 테마

**기준 버전: v7.10.2**. 이 패치는 해당 통합본 전용입니다.

## 변경사항
- iOS 홈 화면 PWA에서 테마 버튼을 눌렀을 때 안전한 상태라면 변경된 테마를 저장하고 **1회 페이지 새로고침을 시도**해 최초 로딩의 상단 테마색을 다시 적용합니다. 진행 중인 길찾기/입력, 다른 탭 또는 열린 행정동·더보기 창에서는 재로드를 생략합니다. PC·Android는 새로고침 없이 기존 테마 전환 유지
- 행정동 선택창을 다른 탭과 **동일한 43dvh(최대 480px) 플로팅 패널**로 정리합니다. 제목·닫기(X) 버튼은 고정, 행정동 목록·초기화 버튼은 본문 안에서만 스크롤
- 행정동 창의 아이콘, 여백, 배경색, 테두리 및 하단 탭과의 간격을 통일하고 다크·라이트 색상 토큰을 함께 사용
- 더보기 메뉴를 열면 길찾기·커뮤니티·뉴스·내 기록·행정동 등 다른 플로팅을 **일시적으로 숨김**, 닫으면 기존 상태로 복귀해 화면 겹침 방지
- 지도 생성 및 교통 API 코드는 유지, 전체 업데이트 이력에 v7.10.3 추가

## 적용 방법
패치 ZIP을 별도 폴더에 압축 해제 → `APPLY_PATCH.cmd` 실행 → 기존 **v7.10.2 프로젝트 최상위 경로** 입력. 적용 전 원본 SHA-256 검증, 백업 후 덮어쓰기 방식입니다.

PowerShell 직접 실행: `powershell -ExecutionPolicy Bypass -File .\APPLY_PATCH.ps1 -ProjectRoot "C:\DongjakApp\프로젝트폴더"`

백업 복원: `RESTORE_PATCH.ps1 -ProjectRoot "프로젝트경로" -BackupFolder "백업경로"`

## 로컬 확인
```powershell
npm ci
npm test
npm run build
npm run dev
```

Cloudflare: 로컬 확인 후 `npm run deploy:pages` (기존 고정 프로젝트 주소 사용).

## 검증 및 제한
- 자동 테스트 **802/802 통과**
- 모바일 Chromium(320×700, 390×844, 430×932, 699×900) CSS/배치 점검 통과: 행정동·하단 탭 간격, 본문 스크롤, 더보기와 기존 창 중첩 방지
- 지도·교통 보호 소스 해시 확인, 압축 무결성 검사
- **실제 iPhone PWA의 시스템 상태 표시줄 색 변경 결과는 미검증**입니다. iOS가 시스템 상태 표시줄 색을 고정하면 재로드 후에도 유지될 수 있습니다.
- 실제 Vite 빌드는 npm 의존성이 설치되지 않은 본 검사 환경에서 확인하지 못했습니다.

**주의:** 새로고침은 지도 확대·이동 상태가 초기화될 수 있습니다. 길찾기·입력 중 자동 새로고침하지 않도록 제한했습니다.
