## 표시 우선순위
1. 모바일(가로 폭 699px 이하)에서 지도를 단독으로 보고 있을 때만 축척바를 표시합니다.
2. 교통정보, 시설 팝업, 검색 결과, 지도 설정·보행안전, 길찾기, 날씨, 야간 시야, 계정 안내, 알림창 등 다른 창이 열리면 축척바를 숨깁니다.
3. 창을 닫아 지도 단독 상태로 돌아오면 다시 표시합니다. 단순히 축척바 위치를 위로 밀어 가리는 방식을 사용하지 않습니다.
4. 자동 지도 이용 팁은 지도 진입 시 짧게(3.4초)만 보여주고 자동으로 사라집니다. 팁 표시 중에는 축척바를 숨겨 겹침을 없앱니다. 문구 자체는 10초마다 다음 회차 내용으로 갱신하지만 이미 닫힌 팁을 자동으로 다시 열지는 않습니다.
5. 모바일의 하단 탭은 축척바·팁보다 우선이며, 지도 이외 탭에서는 축척바를 표시하지 않습니다.
