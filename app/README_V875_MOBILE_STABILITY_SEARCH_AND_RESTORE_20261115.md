# 동작하는 안전지도 v8.7.5 — 모바일 창·검색·복귀 안정성

기준: v8.7.4 전체 프로젝트. PC 지도와 PC 대중교통 레이아웃은 보존합니다.

## 수정사항

- 모바일 하단 5개 탭 높이·아이콘·라벨의 고정 그리드로 탭 전환 흔들림 최소화
- 날씨 버튼은 저장된 최근 관측값으로 상세 정보를 열고 10분 이상 지났거나 수동 갱신한 경우에만 재조회
- 모바일 지도 옵션·보행안전 닫기에서 중복 클릭 경로 차단 및 아래로 내려가는 닫기 모션 적용
- 검색 추천창은 위치 이동 없는 페이드 전환, 검색 포커스 상태에서 배경색 고정 및 X 중앙 정렬
- 스타벅스 등 일반시설 검색 결과가 부족하면 동작구 인근 실제 OSM 상호명을 제한적으로 추가 조회
- 지도 옵션의 클릭·닫기 상태 통합, 상단 전체 폭 손잡이 드래그 영역 추가
- iOS PWA에서 다른 앱 복귀 시 MapLibre resize·재렌더, WebGL 컨텍스트 복구 이벤트 처리
- 더보기 창 최대 높이 약 50dvh로 제한하고 동작을 수행하는 버튼을 가짜 토글로 표현하지 않음
- 지하철·버스 즐겨찾기 아이콘 스타일 통일, 알약바 정렬 및 하단 데이터 스크롤 영역 확대
- 시설 상세창은 내려가는 닫기 모션에서 먼저 불투명 상태를 유지하고 손잡이·제목 구분선 보정
- 버스 카드의 몇 정거장 전 정보 오른쪽 정렬, 스크롤 중 교통창 헤더·상단 회색 손잡이 고정

## 제한사항

- iOS 시스템의 키보드 입력 보조 막대는 PWA 코드에서 제거할 수 없습니다. 검은 레터박스 문제는 앱의 배경색 및 검색 애니메이션을 보정했지만 모든 WebKit 버전에서의 해결을 보증할 수 없습니다.
- iOS PWA 프로세스 자체가 종료되어 JavaScript가 전혀 실행되지 않는 백지 화면에는 브라우저 복구 코드가 실행될 수 없습니다. 현재 코드는 정상적인 앱 재개와 WebGL 컨텍스트 복구를 처리합니다.
- 스타벅스·카페 검색 결과는 공개 OSM 상호명 데이터와 온라인 Overpass 연결에 따라 달라집니다. 운영·영업 여부와 지점 주소 정확도를 보장하지 않습니다.
- 실제 iPhone 배포 환경의 전체 화면·데이터·성능은 별도 테스트가 필요합니다.

## 검증

Node 정적 및 독립 테스트, CSS 파싱, ZIP 무결성 등. npm 설치와 빌드는 진행하지 않았습니다.
