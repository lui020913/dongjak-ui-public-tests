# 동작하는 안전지도 v8.7.3 — 모바일 안정성·시설 복구

기준: TalkFile_DongjakApp_FULL_v8.7.2_PLAYWRIGHT_INTEGRATED_20261115.zip
목표: PC 화면 보존, 모바일 홈·시설·프레임·해상도 개선

## 변경 사항

1. 안전지도 홈 탭: 모바일 하단 안전지도 탭을 Window 캡처 단계에서 우선 처리해 다른 버전의 탭 이벤트가 행정동 선택창을 여는 경로 차단. 행정동 선택은 지도 옵션의 명시적 조작에서 유지. PC 기존 내비게이션은 변경하지 않음.
2. 일반시설: 서울시 인허가 D1 조회는 유지. 비어 있거나 서버 구성이 없으면 Pages Function `/api/osm-general-facilities`를 통해 OSM 시설로 대체 조회. Pages Function 사용 불가 시 공개 Overpass를 브라우저에서 조회. 표시 결과에는 실제 출처 표시. `일반시설 새로고침` 버튼 추가. 확대 15.4부터 조회하며, 심볼은 확대 16.3부터 표시함.
3. 모바일 지도 화질·반응성: 지도 조작 중 DPR 기본 1.35, 정지 후 최대 2.0. 메모리 3GB 이하 장치는 이동 1.15, 정지 1.65. 화면 폭 700px 이상은 기존 1.5 DPR 제한을 유지. 지도 움직이는 동안 상단 바와 하단 네비게이션의 불필요한 backdrop blur만 해제.
4. 일반시설 검색: 서버 API가 실패해도 현재 지도에서 이미 불러온 일반시설을 검색 후보로 사용할 수 있도록 캐시를 연동.
5. PC·모바일 UI: 레이아웃은 유지, 모바일 성능 CSS는 699px 이하에서만 적용. 시설 새로고침·조회 상태는 기존 지도 안전시설 도구 안에서 확인 가능.

## 검사

- npm install, npm ci, npm build: 실행하지 않음 (요청 반영)
- node --test 신규 집중 검사: 8/8 통과
- 원본 v8.7.2 전체 검사: 1,396/1,419 통과, 23개 기존 실패
- v8.7.3 전체 검사: 1,404/1,427 통과, 동일한 23개 기존 실패 (추가 실패 없음)
- Chromium 간이 브라우저 테스트: 320, 390, 430, 690px의 안전지도 홈 캡처 및 PC 1440px 레이아웃 이벤트 분리 통과
- JS 구문, 버전 검사 및 ZIP 무결성 별도 확인

## 중요한 제한

- Overpass/서울시 D1 서버와 실제 모바일 네트워크, Android Studio APK, 원격 지도 스타일의 실시간 동작은 이 환경에서 최종 확인 불가. `일반시설 새로고침` 후 실제 수량과 출처를 확인할 것.
- 자동적인 대규모 정부 인허가 데이터 수집을 실행한 것이 아니라, 런타임 데이터를 재조회할 수 있는 경로를 구현한 것임.
- 지도 벡터 타일 자체의 원본 데이터 상세도는 해상도 설정만으로 늘어나지 않음. DPR은 화면 렌더링 선명도를 개선하되, 저사양 기기는 성능에 맞춰 상한을 둠.
- 기존 자동 테스트 23개는 원본부터 실패하던 보호 해시/구형 안내문·TIP 요구 등임. Playwright를 포함한 기존 원본 테스트 파일은 유지.

## 중간 점검

PowerShell (프로젝트 폴더):

    npm ci
    npm run build
    npm run dev

Cloudflare Pages (기존 프로젝트 배포):

    npm run deploy:pages

APK: Android Studio에서 Build APK(s)로 생성되는 `app-debug.apk`가 실제 앱 APK이며, `app-debug-androidTest.apk`는 테스트 전용 APK임.

실제 배포 전에 환경변수(.env.local / Pages secrets)와 OSM/서울시 시설 API 연결을 별도로 확인할 것.
