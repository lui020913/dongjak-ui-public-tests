# 동작하는 안전지도 · AUDIO/AED/SANGDO 후속 UI 수정본 (2026-11-13)

**기준 파일**: DongjakApp_FULL_v8.0.3_AUDIO_AED_SANGDO_PC_MOBILE_UX_APPLIED_20261113(1).zip
**앱 내부 버전**: v8.0.3 유지 / UI 후속 수정 식별자 v806. 기존 기능 및 전체 연구자료 보존.

## 수정 사항
- PC 도로폭 범례 창은 실제 좌측 탭의 높이를 측정해 맞춤, 보행안전과 중복 표시 방지
- PC 설정창은 가능한 화면 높이에 스크롤 없이 전체 표시 (매우 낮은 화면에서만 스크롤)
- 업데이트/설정/시트/팝업 등장·닫기 Web Animations 통일. 기존 애니메이션 중복 실행 차단
- 시설 팝업을 모바일 하단 탭/오른쪽 조작 버튼 및 PC 패널 영역 밖으로 자동 보정
- 버스정류장 타입/이름/ARS 중앙 정렬, 버스 아이콘 크기 소폭 확대
- 모바일 길찾기 제목과 입력창의 세로 간격 보정
- 다크모드 메뉴·카드·버튼·빈 상태 안내 등 테마 색상 일관성 개선
- UI 글꼴 나눔스퀘어 네오 적용: 네이버 공식 웹폰트 링크 이용. 외부 폰트 접속 실패 시 시스템 글꼴 fallback
- 학교/공공시설/운동시설 아이콘 등장 축소 범위 조정, 안전시설 아이콘 겹침 허용. 모든 화면 축척에서 모든 지점을 표시한다는 뜻은 아님
- 분석 화면은 2026-10-01 공식 상도1동 경계를 사용. 도로폭/경사 자료는 공간교차를 수행한 표시 전용 GeoJSON 생성. 보행사고·CCTV 등의 점 분석은 활성화 때 상도1동 범위로 표시. AED·음향신호기·실시간 정보는 기존 범위 유지
- 동작구 전체 도로폭/경사/사고/CCTV 원본 GeoJSON은 수정 없이 보존

## 핵심 한계
1) MapLibre 기본 지도에 서버에서 제공하는 타일형 지명 글꼴은 나눔스퀘어로 교체되지 않습니다. UI 글꼴만 변경했습니다.
2) 나눔스퀘어 네오는 공식 웹폰트 리소스가 필요합니다. 앱 자체에 폰트 파일을 넣지 않았습니다.
3) 자동 회귀 테스트에서 이전 소스의 SHA256 고정과 이전 버스 아이콘 크기만 검증하는 구형 기대값 일부는 이번 의도적 수정과 충돌합니다. 이를 성공으로 표시하지 않습니다.
4) 이 환경은 npm 의존성 설치가 불완전해 Vite 번들 빌드와 실제 Cloudflare/API 실운영 검증을 완료하지 못했습니다. 직접 로컬에서 설치/빌드 후 사용하세요.

## 패치 적용
전체 ZIP은 바로 새 폴더로 압축 해제하면 됩니다. 패치 ZIP은 위 **기준 파일**에만 적용합니다.
Windows: ZIP 압축 해제 후 APPLY_PATCH.cmd 실행 → 기존 프로젝트 폴더 경로 입력.
버전과 원본 파일 SHA256 확인, .patch_backups 아래 백업, 변경 파일 덮어쓰기가 순서대로 실행됩니다.
검증에 실패하면 덮어쓰지 않고 중단합니다.
