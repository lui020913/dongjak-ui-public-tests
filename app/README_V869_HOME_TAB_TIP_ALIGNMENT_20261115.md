# v8.6.9 안전지도 홈 탭 및 모바일 TIP 가독성 수정

기준: v8.6.8 전체 통합본.

## 변경 사항
- `src/main.js`: 하단 안전지도 탭 진입 시 `navigate('map',{suppressOverview:true})` 사용. 기존의 재선택 시 개요창 토글 기능 제거. 기존 지도 옵션에서 행정동 선택은 유지.
- `src/v869-safety-home-tip.css`: **699px 이하에서만** TIP 문구의 중앙 수직 정렬과 스크롤 텍스트의 좌측 7px/우측 12px 내부 여백 적용. TIP 배지와 외곽 오른쪽 14px 패딩, 고정 TIP 레이블과 이동 문구를 분리.
- `index.html`, 버전 메타데이터: v8.6.9 반영.

## 사용 시 확인
1. 모바일에서 길찾기 → 안전지도, 커뮤니티 → 안전지도, 동작 소식 → 안전지도, 내 정보 → 안전지도를 반복해도 행정동 선택창/개요창이 자동으로 뜨지 않는지 확인.
2. 지도 옵션의 행정동 선택 버튼은 여전히 필요할 때 작동하는지 확인.
3. 화면 폭 320/375/430px에서 하단 TIP 문장 기준선이 중앙에 있으며 오른쪽 잘림 없이 TIP 바 내부에서 좌우 이동하는지 확인.
4. PC에서는 기존 지도 배치를 유지하는지 확인.

npm 설치·실행·빌드는 요청에 따라 진행하지 않았습니다. Node 구문 및 버전 검증만 수행했습니다.

## 검증 기록
- Node 전체 테스트: 1,412개 중 1,395개 통과, 17개 실패(기존 v8.6.8에서 이어진 구버전 보호/기존 UI 검사 17개; 새 실패 없음).
- v8.6.9 전용 회귀 테스트: 4개 통과. 실제 하단탭 클릭 핸들러를 Node VM에서 실행해 모든 복귀 경로의 `suppressOverview:true` 확인.
- Chromium **격리 CSS 픽스처**: 320·375·430·690px에서 TIP 내부 문장 수직 정렬 오차 약 +1px, 좌측 7px·우측 12px 패딩과 텍스트 클리핑 확인. 800px에서는 모바일 CSS 미적용 확인.
- 실제 지도 앱 구동 및 iPhone 실기 검증은 수행하지 못했습니다. 필요 시 배포 후 실제 탭 전환 및 TIP 애니메이션을 확인하십시오.
