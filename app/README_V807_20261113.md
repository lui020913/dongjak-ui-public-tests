## 이번에 반영한 수정
- UI 본문과 버튼 폰트 굵기를 한 단계 강화
- 혼합형 landcover 레이어를 통째로 녹색 재칠하지 않음; 녹지 강조 불투명도를 높은 배율에서 조절
- 동작구 바깥 자치구 지명 글씨도 다크모드에서 밝게, 테두리를 어둡게 변경
- 지도 조작 안내의 PC/모바일 설명을 각각 독립된 줄로 분리
- 시설 선택 시 실제 시설 좌표에 임시 위치 핀을 표시하고 닫으면 제거, 팝업 가로폭 최대 395px로 확대 (가림 방지 계산 유지)
- PC 지도 표시 옵션·행정동 선택 제목 확대, 버스 도착정보 2열 배치, 보조 글자 +1px
- PC 도로폭 범례의 고정 전체높이 제거 및 내용 맞춤
- 다크모드의 커뮤니티·내 기록 빈 카드와 안내 문구의 배경/텍스트 대비 개선
- 모바일 하단 탭 아이콘을 연필 아이콘과 같은 24px/2.4px 스트로크 기준으로 통일
- 모바일 환승역 호선 전환 시 같은 패널의 재진입 애니메이션 취소
- 모바일 시트 열림 애니메이션 이동 거리를 28px/360ms로 조정
- 모바일 검색창의 순환 문구를 입력이 비어 있을 때 1~2줄로 표시 (실제 검색 입력 기능 유지)

## 적용
1. 패치 ZIP을 압축 해제하고 `APPLY_PATCH.cmd`를 실행합니다.
2. **위에 명시한 928 PASS 기준 ZIP을 해제한 폴더**를 선택합니다.
3. SHA256 검증이 일치하는 경우에만, 기존 파일을 `_patch_backups/v807_날짜`에 백업하고 수정된 파일을 덮어씁니다.
4. VS Code 터미널에서 `npm ci` (또는 `npm install`), `npm test`, `npm run build`, `npm run dev`.
5. Cloudflare Pages 배포: `npm run deploy:pages` (기존 프로젝트 이름 사용, 환경 변수 확인).

전체 ZIP을 사용할 때에는 패치 없이 새 폴더에 압축을 풀면 됩니다.
