# 동작하는 안전지도 v8.7.9 — 안정화 2단계 / 회귀 검사 정비

기준: v8.7.8 안정화 1차 전체본. 기존 PC·모바일 UI 및 API 로직은 유지합니다.

## 실제 수정 및 검증

- 지도 조작 안내창의 닫기 이벤트가 일부 이벤트 환경에서 `stopImmediatePropagation`을 제공하지 않아도 예외 없이 닫히도록 가드 처리. 동일한 닫기 상태 관리와 재열기 예약 취소는 유지.
- 배경 지도 버스 아이콘을 직접 누르는 테스트용 DOM 모형에 `classList`, `style`, `dataset`을 보강하여 실제 브라우저의 DOM 인터페이스와 일치시킴. 공식 정류소 목록이 실패해도 배경 POI 클릭으로 상세창을 여는 기능 테스트 통과.
- 모바일 안내창 닫기 이벤트에 대한 정적 검사에서 여러 줄 함수 구현도 올바르게 검사하도록 개선.
- TIP 교체 10초, iPhone 접이식 안내 마크업, 더보기 하강 종료 및 닫기 타이머 무효화, 최신 버전 정합성 검사로 구형 조건 갱신. **기능을 옛 동작으로 되돌리지 않음**.
