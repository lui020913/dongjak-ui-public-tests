# 지하철 환승역 축척별 마커 동작

## 표시 규칙
- 줌 10.2 미만: 역 아이콘을 숨기고 노선 중심으로 표시
- 줌 10.2 이상, 13.05 미만: 역마다 하나의 통합 배지 표시. 환승역은 노선별 색을 한 아이콘에 나눠 표시하고, 배지 안에는 `1·9`, `7·신림`처럼 번호를 합쳐 표기
- 줌 13.05 이상: 호선별 마커를 각각 실제 표시 노선의 지리 좌표에 표시
- 동일한 역 이름은 호선별 상세 마커 중 한 번만 표시. 이수/총신대입구처럼 실제 역명이 다른 경우는 각각 표시
- 통합 배지 클릭 시 해당 역의 전체 호선 정보를 열고, 확대 상태에서 개별 배지를 클릭하면 선택한 호선만 조회
