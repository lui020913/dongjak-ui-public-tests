# 동작구 보행안전 지도 — 전체 업데이트 내역 (v1~v6)

이 문서는 기존 버전명과 업데이트 문구를 보존하여 **처음부터 현재 버전까지 시간순**으로 정리한 기록입니다. 최신 버전은 v6.0.4입니다.

## 1. v1 — 기본 지도·길찾기 (4개 버전)

### v1.0

- 동작구 경계·입체 건물·지도 길찾기 기능의 기본 구성

### v1.1

- 버스·지하철 지도 아이콘 선택 및 상세정보 화면 개선

### v1.2

- 서울시 실시간 버스·지하철 정보 연동 기반

### v1.3

- 서울시 지하철 API 응답 처리 오류 수정
- 지하철역 강조 및 교통정보 표시 개선

## 2. v2 — 기초 지리·보행 자료 (3개 버전)
