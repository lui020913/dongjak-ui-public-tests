# 상도1동 종합 보행 취약도(PRI) — 6개 지수

## 계산 및 화면 규칙

- 개별 점수는 **위험점수 0~100**이며 높을수록 위험합니다. 기존 내부 안전점수(100-위험점수)는 저장 호환성 때문에 유지되지만 **사용자에게 표시할 때 다시 위험점수로 변환**합니다.
- 6개 지수는 야간 조명(lighting), 교통사고(accidents), 제도적 사각지대(protectionGap), 제한속도(speed), 횡단보도(crossing), 보차혼용도로(sharedRoad)입니다.
- 모두 평가된 경우: 위험점수 **(6개 점수 합)/6**. 평가되지 않은 항목은 NULL이지 0점이 아닙니다. 2~5개 유효 지표가 있는 구간은 해당 지표들의 동일 가중 평균을 **부분평가(x/6)**라고 구분합니다. 유효 지표가 1개 이하인 구간은 종합 미평가(회색)입니다.
- 지도 위험구간 색: 0~39점 청록색(상대적 저위험), 40~69점 주황색(주의), 70~100점 빨간색(고위험), NULL 회색. 이는 연구용 상대지표이며 법정 위험등급 또는 실제 사고확률이 아닙니다.

## ⑤ 횡단보도 평가 (첨부 「보행자 위험도 지수(횡단보도)」 PDF)

4개 영역을 각각 고위험 25점, 주의 15점, 안전 5점으로 평가해 합산합니다.
1. 보행 단절성: 횡단보도 간 이격 및 접근·가시거리
2. 도로·지형 환경: 급경사·곡선·주정차 등 시거 차단
3. 보행약자 취약성: 보호구역·보행약자 통행 및 시설 누락
4. 야간 및 사고 이력: 조도·CCTV 및 최근 5년 교통사고 이력

**주의:** 이 PDF는 평가기준표로서 각 상도1동 조사도로의 실측 총점을 포함하지 않습니다. 팀 횡단보도 좌표 참고자료는 미검증이므로 자동으로 고위험 점수를 부여하지 않습니다.

## ⑥ 보차혼용도로 평가 (첨부 「상도1동 보차혼용도로 평가기준표」 PDF)

**1안 채택:** 보도·차도 물리적 분리(0 또는 4), 보행자 회피공간(0 또는 3), 시야 차단(0 또는 2), 속도저감시설(0 또는 1)을 합산한 0~10점에 ×10을 적용합니다. PDF에는 중간점수 판정 근거가 없으므로 0 또는 각 항목 최고점만 자동 채점합니다. 팀이 확정한 10점 만점의 구간별 원점수는 `scoreMax:10` 형식으로도 입력할 수 있습니다. 별도의 **2안(보차혼용 10점/보차분리 0점)**과 세부평가 1안을 동일 지수에서 혼합하지 않습니다.

기존 지도에 있는 PDF 이미지에서 디지털화한 보차혼용도로 선형은 위치 오차 가능성과 구간별 평가점수 부재가 명시된 참고자료입니다. 이를 확인된 100점 위험구간으로 간주하지 않습니다.

## 실제 도로별 4항목 평가 자료 입력

원본 JSON 파일 불러오기에서 아래와 같이 평가된 도로 ID와 4항목을 함께 지정할 수 있습니다. 두 파일의 `networkVersion`은 기존 공통 25m 도로망과 정확히 같아야 합니다. 데이터로 검증되지 않은 도로는 행 자체를 생략하거나 일부 값에 `null`을 넣을 수 있습니다.

**횡단보도 예시**

```json
{
  "schemaVersion": 1,
  "type": "pri-factor-rubric",
  "networkVersion": "sangdo1-lighting-2026-11-20-b8433fe8",
  "factor": {
    "id": "crossing",
    "label": "횡단보도 보행자 위험도",
    "scoreDirection": "risk",
    "source": "현장평가 또는 검증된 자료 출처",
    "method": "4개 항목 고위험25·주의15·안전5 합산"
  },
  "rows": [
    {
      "id": "확인된 도로구간 ID",
      "components": {
        "discontinuity": "고위험",
        "terrain": "주의",
        "vulnerable": "안전",
        "nightAccident": "고위험"
      }
    }
  ]
}
```

**보차혼용도로 예시**

```json
{
  "schemaVersion": 1,
  "type": "pri-factor-rubric",
  "networkVersion": "sangdo1-lighting-2026-11-20-b8433fe8",
  "factor": {
    "id": "sharedRoad",
    "label": "보차혼용도로 위험도",
    "scoreDirection": "risk",
    "source": "현장평가 또는 검증된 자료 출처",
    "method": "4+3+2+1점 합산 후 ×10"
  },
  "rows": [
    {
      "id": "확인된 도로구간 ID",
      "components": {
        "separation": 4,
        "refuge": 3,
        "sight": 0,
        "speedCalming": 0
      }
    }
  ]
}
```

위 예시의 ID는 자리표시자이므로 실제 등록된 1,686개 ID 중 정확히 일치하는 값으로 변경해야 합니다. 항목이 누락된 도로는 미평가(NULL)입니다.
