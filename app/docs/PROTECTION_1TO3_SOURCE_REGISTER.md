# 상도1동 보호구역 1~3차 자료 반영 (2026-11-10)

이 배포본은 사용자 제공 원본 v6.0.21에서 보행안전 보호구역 기능만 보강했습니다.

## 실제 지도에 반영된 것
- 상도1동 기존 보호구역 도형 9개(어린이 7, 노인 2), 예비검토 도로 125개, 그중 R0248·R0288 중점 구간은 기존 GIS 기하를 그대로 유지
- 두 구간의 추정 도로폭·보호구역 도형 거리·등록 조명시설 거리·2023~2024 표기 사고다발지역 통계 도형 교차 길이
- 1~3차 연구 상태 필드와 검증 완료/미확인 구분, 실제 보행자 행동 안내 문구
- 사용자가 도로 선택 시 확인 가능한 설명 패널 및 내부 조사 기록 기능
- 자동 길찾기 회피 가중치는 추가하지 않음

## 절대로 해석하지 말아야 할 것
- '공개 보호구역 도형 밖' = 법적 보호 대상에서 누락 / 법령상 거리 초과 (해당하지 않음)
- '사고다발지역 도형과 겹침' = 그 도로에서 실제 사고 발생/건수
- '추정 도로폭' = 보도 유효폭이나 보차분리 여부
- '가장 가까운 OSM 보행로 선형까지 거리' = 보도 없음
- '시설 대표점' = 법적 주 출입문
- '서울시 생활인구' = 해당 골목 실제 통과 보행량

## 미확보
1. TAAS 개별 보행자 사고 원자료와 도로 일치 검증
2. 실제 보도·보차분리 및 공식 횡단보도·보행신호 원자료
3. 동작구청 최신 지정 고시(시점·종점·경계) 및 상현초 실제 통학 동선
4. 최신 250m 격자 생활인구 원자료, 구간별 규제속도, 지형 DEM 및 종단경사 계산

## 공개 출처 확인 페이지
- TAAS: https://taas.koroad.or.kr/gis/mcm/mcl/initMap.do?menuId=0
- 서울시 횡단보도: https://data.seoul.go.kr/dataList/OA-22906/S/1/datasetView.do
- 서울시 250m 생활인구: https://data.seoul.go.kr/dataList/OA-22784/S/1/datasetView.do
- 정보공개포털: https://www.open.go.kr/

기존 1~3차 사용자 제공 원자료는 /mnt/data에 별도로 제공됐으며, 정확히 일치하는 도로 ID를 기준으로 수치를 추가했습니다. 웹 배포 시 제3자 원자료나 환경변수는 포함하지 않습니다.

## 1~3차 자료 정합성 확인
원본 후보 도로 125개 선형 중 `R0299`는 서로 다른 두 조각에 중복 부여되어 있고, 3차 수집 파일에는 이 ID의 두 복제본이 존재합니다. 이 패치는 **원본 지도에 있는 서로 다른 두 선형을 유지**하면서 연구팀 현장기록 충돌을 막기 위해 두 번째 선형에만 `review_fieldwork_id=R0299-2`를 부여합니다. 이는 공식 도로 ID 변경이나 추가 도로 생성이 아닙니다.
