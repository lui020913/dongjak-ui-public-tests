  `src/dongjak-*` 구현, `src/workers` 및 `public/data/safety` 지도 데이터를 그대로 보존했습니다.
- 두 작업의 공통 변경 파일인 `index.html`만 **양쪽 변경사항을 3-way 병합**했습니다.
- 다른 패치 파일은 원본 SHA-256이 사용자 첨부본과 일치하는 것을 확인한 후 적용했습니다.
- 기존 PC/지도 원본 보존 SHA 목록을 변경하지 않았습니다. 다만 통합본에서
  의도적으로 수정된 `src/main.js`는 승인된 첨부본 SHA `594eaa43476eac26c866e017eac0a23532bbaa8d8d724e1ed83e4034aab879b1`로
  별도 검증합니다. `tests/support/approved-walk-integration.mjs` 참조.

## 주요 기능
- 서울시 도보 링크 기반 경로 선택, 경사 회피 비교·실패 시 외부 경로 서버 보완
- 사고 기록·CCTV·보행 경사·횡단 조사·승강기 등의 선택형 지도 레이어
- iOS PWA 테마·야간시야 새로고침 시 전환 안내 화면과 상태 복원
- 신규 라이트·다크 앱 아이콘, 초기 로딩 이미지 교체
- 모바일 보조 버튼 및 중복 메뉴 정리, 버전 기록 통계 제거

## 주의
- 공급된 서울시 도보 링크와 안전자료에는 미검증 사항이 있으며 실시간 안전·통행 가능성을 보장하지 않습니다.
- 자동 테스트는 구성·자료 로직 중심이며 실제 iPhone PWA 지도 타일 표시·Vite 빌드·야간시야 복원은 별도 확인이 필요합니다.
- 사용자 첨부 통합본 자체가 명시한 외부 경로 서버 전송·자료 한계는 그대로 적용됩니다.
