### 델타 패치
- 원본 **v7.12.0** 프로젝트의 최상위 폴더가 필요합니다.
- 패치 ZIP을 다른 폴더에 풀고 `APPLY_PATCH.cmd` 실행 → 프로젝트 경로 지정.
- 패치 스크립트는 `package.json` 버전 및 원본 변경 대상·보호 파일의 SHA-256 검증 → 자동 백업 → 변경 파일 적용 → SHA-256 재검증을 수행합니다.
- 실패 시 원래 변경 대상 파일을 자동 복원하며, 나중에 복원하려면 `RESTORE_PATCH.cmd`를 사용합니다.
