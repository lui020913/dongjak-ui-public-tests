# 상도1동 보차혼용도로·이면도로 현황자료 레이어

- 입력: 팀에서 확보한 실제 상도1동 현황자료 PDF의 표시 구간. 원본 선형 236개를 추출하고 상도1동 참고 경계에 클리핑해 237개 구간으로 구성했습니다.
- 합산 표시선 길이는 약 15,845.5m입니다. PDF에서 추출·지리참조한 선형 길이이며 현장 실측 도로 길이는 아닙니다.
- 자료의 도로 구간은 실제 현황자료에 근거합니다. 다만 PDF 지도 이미지에서 좌표화했으므로 화면 선형 위치에는 지리참조 오차가 있을 수 있습니다.
- 별도 GIS·현장 대조 전에는 법정 도로분류, 보도 유효폭, 사고 위험등급 또는 정밀 내비게이션 회피 기준으로 사용하지 않습니다. PDF에 도로별 평가점수는 없어 모든 구간은 미평가로 유지합니다.
- 안전지도 → 사고·지도자료 → 보차혼용도로·이면도로: 황토색 점선, 구간 상세창, 모두 끄기, 지도 스타일 변경 후 복구를 지원합니다.
- PRI·경로비용·안전경로 계산 모듈은 수정하지 않았으며, 레이어는 기본 꺼짐 상태의 독립 오버레이입니다.
- 기준 최신 UI: `hotfix/v8.9.11-motion-20261118`, `6fb80f221846f21d9fdc0d84832775f738b6b0cb`. 보차혼용도로 변경은 기존 PR #85에 보존합니다.
- 검증: `node --test tests/bocha-road-layer.test.mjs`, `npm run build`, 모바일·태블릿·PC Preview 브라우저 검증.
