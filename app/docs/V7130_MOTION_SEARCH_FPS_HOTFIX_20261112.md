# 동작하는 안전지도 v7.13.0 · UI/검색/렌더링 통합 수정

**기준:** DongjakApp_FULL_v7.13.0_PC_MOBILE_UX_INTEGRATED_20261112.zip

## 반영 내역
- 기존 v7.13.0의 PC/모바일 화면 구조와 `src/main.js`, 버스/지하철·안전 데이터 보존
- 길찾기 일반 장소: 공식 주소가 있는 로컬 대표 장소 및 외부 Photon 검색, 서버 보조 경로 제공
- 길찾기 위치 선택·경로 미리보기·GPS 안내와 야간 시야 분석의 충돌 방지
- PC에서 3D 건물 렌더링이 무거운 드래그 중에만 보충 건물 레이어를 임시 경량화 후 원상 복원
- 앱의 검색 폼 내부 중복 로고를 숨김(별도 앱정보 버튼 유지), 모바일 앱정보 아이콘 축소
- 지도 옵션·보행안전·도보길찾기·소식·내 기록·교통정보·다이얼로그 등의 창 열림 애니메이션 복구
- 테마/야간 화면의 기존 로더는 하나만 사용하고 등장 효과 부드럽게 조정
- 커뮤니티 연필 아이콘 벡터 크기 통일

## 범위와 검증
- 자동 테스트 857/857 통과(기존 852 + 신규 5개), JS 문법 검사 통과
- Chromium 정적 CSS 검사: 검색 내부 로고 미표시, 창 등장 애니메이션, 모바일 26px 아이콘 표시 확인
- `움직임 줄이기`/기기 접근성의 동작 감소 옵션은 유지
- 3D 성능 개선은 감지 조건을 갖춘 선택적 최적화이며 실제 모니터 주사율 FPS를 보장하지 않음
- npm 오프라인 캐시에서 `yauzl@2.10.0` 파일을 확보할 수 없어 **Vite 전체 빌드 미검증**
- 실제 Windows 및 Cloudflare 구동/배포는 이 실행 환경에서 확인하지 못함
- 실제 3D 건물/야간시야/모바일 검색 조작을 로컬에서 재검증 후 배포할 것

## 전체 통합본 실행
1. 기존 프로젝트와 섞지 말고 새 폴더에 압축 해제합니다.
2. VS Code에서 폴더를 연 후 `npm ci`, `npm test`, `npm run build`, `npm run dev`를 실행합니다.
3. 검색창 일반 장소, 야간시야-길찾기 충돌, 3D 상태, 라이트·다크/모바일 창 애니메이션을 확인합니다.
4. 정상 구동 확인 뒤 `npm run deploy:pages`로 기존 Cloudflare Pages 프로젝트에 배포할 수 있습니다.

## 델타 패치 적용
전체 통합본 사용 시 패치 적용은 **불필요**합니다.
1. 이 패치는 위 v7.13.0 원본 전체 소스에만 적용할 수 있습니다.
2. 별도 폴더에 압축 해제하고 `APPLY_PATCH.cmd`를 실행하여 원본 프로젝트 최상위 폴더를 선택합니다.
3. 기존 해시·버전 검사 후 백업이 생성됩니다. `RESTORE_PATCH.cmd`에서 백업 폴더를 지정하면 복원할 수 있습니다.
4. 다른 버전·수정본에 강제로 덮어쓰지 마세요.

**장소 위치 유의:** 로컬 대표장소 좌표는 출입구 정밀 좌표가 아닐 수 있으며, 공개 Photon 서비스는 일시적인 장애나 호출 제한이 발생할 수 있습니다.
