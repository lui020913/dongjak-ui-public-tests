# 동작구 지도 접근성 기능 — 2026-11-05

## 지하철 출입구 좌표

- 행정안전부 전국 지하철 출구 공개 피처 서비스(MOIS_KR_Subway, KR_Sub_Exit).
- 2026.04.30 기준 자료이며 신림선 출구 데이터는 원본의 누락으로 인해 표시되지 않을 수 있습니다.
- 웹 지도에서 축척 14.25 이상일 때 파란 출구 원을 보여줍니다.
- 출구 번호는 데이터에 번호가 존재할 때만 표시합니다.
- 행정안전부 출구 데이터에는 출구별 계단/에스컬레이터 구분이 없으므로 '미확인'으로 안내합니다.

## 엘리베이터

서울열린데이터광장 `tbTraficElvtr` 공식 서비스의 지리좌표를 사용합니다.
실시간 가동/고장 정보는 제공하지 않습니다. 공식 자료의 일부 기준연도는 2020년입니다.

사용자 `.env`에 별도 인증키를 입력한 경우 사용됩니다.

    SEOUL_OPEN_API_KEY=본인_서울열린데이터광장_인증키

`.env` 파일을 외부에 공유하지 마세요. 기존 버스·지하철 실시간 API 키는 변경하지 않습니다.

## 계단 / 에스컬레이터 (현장 검증 자료)

출구별 설비 방식은 출구 좌표만으로 결정할 수 없습니다. 출구마다 계단/에스컬레이터를
임의로 지정하지 않습니다. 현장에서 확인한 시설은 다음 파일에 GeoJSON Point 형식으로
추가할 수 있습니다.

    public/data/metro-accessibility-verified.geojson

필수 속성:
- `type`: `stairs` 또는 `escalator` 또는 `elevator`
- `verified`: `true`
- `source`: 현장조사 또는 공신력 있는 출처
- `observedAt`: 조사 날짜(예: `2026-11-05`)
- `station`: 역명, `number`: 출구번호 (아는 경우)
- `geometry`: `Point`, 좌표는 실제 현장 위치의 [경도, 위도]

**좌표가 불명확하면 입력하지 마세요.** 임의로 점을 만들지 않습니다.
수정한 뒤에는 `npm run dev` 서버를 재실행해야 로컬 데이터가 다시 읽힙니다.

## 자료 제공 및 오류

교통 API 서버가 `GET /api/transport/accessibility`에서 공개 출구 위치와
선택적으로 엘리베이터 위치 및 검증된 현장 데이터를 반환합니다.
외부 서비스 요청 실패 시 실제 위치 대신 임의 아이콘을 생성하지 않고
'위치 조회 실패' 안내를 표시합니다.

## 기타 지도 수정

- 9호선: 여의도 방향 안내용 연결부를 더하고 경계 근처 페이드를 늦췄습니다.
- 신림선: 샛강역에서 선이 선명하게 끝나도록 실제 종착역에서 종점 페이드를 생략합니다.
- 공원·잔디·녹지: 통일된 연녹색, 공원 이름 전용 POI 텍스트 표시.
- 일방통행 화살표: 지도 화면에 고정되지 않고 도로 선의 방향에 따라 회전.

## 주의

역 좌표는 기존 서울시 역사마스터 기반 자료를 유지했습니다. 노선 사이 곡선 및
9호선 여의도 방향 연장은 정밀 터널 측량선이 아닌 안내용 선형입니다.
온라인 피처 서비스 및 서울시 별도 인증키 이용 가능 여부는 개발 PC에서 확인해야 합니다.
