# 동작구 보행안전 지도 v7.10.3 기준 도보·안전자료 통합

이 문서는 최신 v7.10.3 전체 소스에 추가된 **실험용 데이터 통합 기능**을 설명합니다. 원본 UI의 버전 표시는 변경되지 않았으며, 정식 배포 전 수동 확인이 필요합니다.

## 1. 길찾기 데이터 연결
- `src/workers/dongjak-walk-worker.mjs`: Worker에서 `public/data/safety/walk/dongjak_walk_graph.json` 및 `slope_by_link.json`을 로드하여 동작구 최단거리/경사 완화 경로를 계산합니다.
- `src/dongjak-local-routing.js`: Worker 응답을 기존 `routeResult` 형식으로 변환합니다.
- `src/main.js`: 기존 도보 길찾기 버튼 및 GPS 재탐색에 연결합니다. 도보 그래프 실패 시만 기존 Valhalla 서버를 사용합니다.
- 실제 걷는 위치와 네트워크 스냅 지점이 다를 수 있으며, 경사도는 실제 보도 측정이 아닙니다.
- 동작구 보행망에는 차량 허용 링크가 다수 포함되어 있어 휠체어·보행자전용·계단 없음·실시간 통행 허용을 보증할 수 없습니다.

## 2. 보행안전 선택 레이어
- 보행안전 → 추가 보행안전 자료에서 사고다발지역(연도별 기록), CCTV 목적별, 지형 경사, 팀원 횡단지점, 교통약자 엘리베이터 자료 선택
- `src/dongjak-verified-data-layers.js`은 사용 시에만 데이터 요청하고 동작구 경계를 확인해야 점형 데이터를 지도에 표시합니다.
- 서울시 자료와 팀원 미검증 좌표는 현장 안전이나 실시간 운영상태로 해석하지 않습니다.

## 3. 검증과 운영
```
node --test tests/v7103-dongjak-walk-data-integration.test.mjs
npm test
npm run build
npm run dev
```
- 데이터 구조/경로 계산 테스트 5건 통과, 전체 테스트 807건 중 803건 통과.
- 4건은 의도적으로 변경한 `src/main.js`와 과거 버전의 동일성(SHA-256)을 비교하는 보호용 테스트입니다. 원본 SHA 파일을 거짓으로 수정하지 않았습니다.
- 본 실행 환경은 npm 레지스트리 접근이 제한되어 실제 Vite 빌드와 브라우저 지도의 최종 작동을 확인하지 못했습니다. 실제 PC에서 `npm ci`, `npm run build` 후 모바일/PC 화면 검사를 실시하세요.
- 버전 번호를 `v7.11`로 갱신하거나 운영 배포하기 전에 프런트엔드 빌드, 지도 스타일 로드, 서비스워커 캐시, 통행 경로의 현장 정확도 점검이 추가로 필요합니다.
