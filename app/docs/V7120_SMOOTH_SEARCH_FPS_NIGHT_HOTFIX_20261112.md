# 동작지도 v7.12.0 UX·성능 개선 패치 (2026-11-12)

## 적용 기준
`DongjakApp_FULL_v7.12.0_PC_MOBILE_UX_FIXED_20261112.zip` (바로 직전 제공한 PC·모바일 UX 수정 전체본).
**`DongjakApp_FULL_v7.12.0_SETTINGS_TRANSITION_NIGHT_UI_20261112.zip`에는 적용하지 마세요.**

## 반영 기능
1. **테마 전환**: PC·모바일의 테마 덮개를 GPU 비용이 높은 blur 대신 opacity 중심의 자연스러운 크로스페이드로 처리. 기기 움직임 줄이기 설정 존중.
2. **PC 프레임 경량화**: 화면 너비 1080px 이상 + 정밀 포인터 + 3D 회전 시 실제 프레임 간격이 27ms를 연속 3번 넘으면 드래그 동안 GIS 3D 건물 레이어만 임시 숨기고, 이동 완료 후 복구. 지형·CCTV·교통시설·경로 레이어는 유지. 모니터 주사율과 동일한 FPS는 보장하지 않음.
3. **일반 장소 길찾기 검색**: 기존 캐시 역·정류장 검색에 더해 중앙대학교·숭실대학교·총신대학교·동작구청·서울현충원 등 검증된 시설의 로컬 좌표를 추가. 일반 카페·상점·공원·주소는 Photon 공개 지오코더 조회 및 Cloudflare Pages/Vite 프록시 대체 경로. 외부 검색 장애 시 미확인 시설을 임의 생성하지 않음. 공용 서비스라 이용량 제한 가능.
4. **야간시야·길찾기 상태 정리**: 위치 선택·경로 미리보기·GPS 안내 중 야간 분석 켜기 차단. 반대로 분석 중 길찾기 상태 진입 시 야간 분석을 자동 종료. 경고 메시지 및 선택 UI 중복 방지.
5. **모바일 커뮤니티 탭**: 작은 ✎ 글자 기호를 24~26px 벡터 연필 아이콘으로 변경.

## 검증 상태
`npm test` 자동 테스트 850/850 통과. Windows 적용 스크립트는 Linux에서 내용 및 체크섬을 검사했으나 PowerShell 실제 실행은 미검증.
`npm ci --offline`은 `yauzl-2.10.0.tgz`가 npm 캐시에 없어 실패. 따라서 `npm run build` 및 실제 지도 주사율별 성능 측정은 미완료.

## 적용
1. 프로젝트 폴더를 먼저 별도 백업합니다.
2. 이 ZIP을 별도 폴더에 압축 해제한 다음 `APPLY_PATCH.cmd`를 더블클릭합니다.
3. 압축 해제한 **직전 전체 통합본 프로젝트 루트** (package.json 위치)를 지정합니다.
4. 버전·핵심 파일·변경 파일 해시가 일치하면 적용하고 `.patch_backups/`에 백업합니다.
5. VS Code에서 `npm ci`, `npm test`, `npm run build`, `npm run dev`를 순서대로 실행합니다.
6. 모바일에서는 일반 장소명(예: 중앙대학교) 검색, 장소 선택 중 야간시야 버튼, 다크 테마 전환, 커뮤니티 연필 크기를 검증합니다.
7. PC에서는 3D를 보며 지도를 드래그하고, 이동 종료 후 건물이 복원되는지 확인합니다.

## 복원
`RESTORE_PATCH.cmd`를 실행하고 적용 결과로 출력된 `.patch_backups` 백업 경로를 넣습니다.
패치 이후 변경 파일의 해시가 달라진 경우 자동 복원을 중단하므로 덮어쓰기 전에 파일 변경 내용을 비교해 주세요.

## 주의
실제 장소 검색과 프레임 효율은 네트워크 상태·GPU·기기별로 달라질 수 있습니다. 공용 검색 서비스에 과도한 요청을 하지 말고 정식 운영 시 사용량 정책을 검토해야 합니다. 기존 기본 지도, 길찾기 알고리즘, 교통 API는 교체하지 않았습니다.
