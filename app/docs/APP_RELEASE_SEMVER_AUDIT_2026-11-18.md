# 앱 릴리스 64건 SemVer 재분류 감사 (2026-11-18)

## 판정 원칙

- **Major**: 기존 API·데이터 계약·저장 형식·핵심 사용자 흐름과의 하위 호환성을 깨거나, 마이그레이션이 필요한 핵심 아키텍처 변경
- **Minor**: 기존 기능과 호환되는 신규 사용자 기능·데이터 연동·독립 사용자 흐름 또는 넓은 UX 구조 개편

- 한 릴리스에 여러 종류가 섞이면 가장 높은 등급을 적용합니다. 파일 수·수정 줄 수만으로 등급을 결정하지 않습니다.
