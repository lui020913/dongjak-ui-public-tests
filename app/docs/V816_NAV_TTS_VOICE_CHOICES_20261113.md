# 도보 내비게이션 한국어 TTS 목소리 선택 (v8.0.3용)

## 적용 위치
- 길찾기 → 경로 계산 → GPS 안내 → **음성 안내** 버튼 아래 **안내 목소리 선택** 펼치기
- 메뉴: 기기 기본 음성 / 여성 목소리 / 남성 목소리 / 전체 한국어 목소리
- 목소리 선택 및 **음성 미리 듣기**, 브라우저 로컬 저장
- GPS 회전·도착·재탐색 안내에 선택한 SpeechSynthesisVoice 객체를 적용

## 음성의 성별 정보에 관한 한계
Web Speech API의 SpeechSynthesisVoice는 성별 속성을 표준으로 제공하지 않습니다.
따라서 남성/여성 분류는 음성 이름에 명확히 나타나는 일부 한국어 음성에 대한 추정이며 완전한 식별이 아닙니다.
분류되지 않는 음성은 **전체 한국어 목소리** 메뉴에서 직접 듣고 고를 수 있습니다.
원하는 성별의 음성이 기기에 없다면 브라우저 기본 음성으로 안내되며, 설정 화면에 해당 음성이 없음을 표시합니다.

## 사용 제약
- 해당 기기/브라우저가 제공하는 `speechSynthesis.getVoices()` 음성만 사용
- 별도 유료 API, 서버 인증키, 음성 파일 다운로드 필요 없음
- 음성 미리 듣기는 사용자의 명시적 클릭으로만 실행
- 기존 음성 안내 켜기/끄기는 변경하지 않음 (기본 꺼짐)
- 실제 성별·음질·지원 목소리 수, iOS 잠금화면 동작은 기기마다 다름
- 음성 목록은 `voiceschanged` 이벤트가 도착하면 갱신

## 코드 변경
- `src/main.js`: 기존 `speakNav`에 선택 음성 적용 + 설정 초기화 코드 3곳만 변경
- 신규 `src/nav-voice-logic.js`: 음성 이름 기반 분류, 한국어 필터, 설정 검증
- 신규 `src/nav-voice-picker.js`: 메뉴 UI, 로컬 설정값, 미리 듣기, 동적 음성 목록
- 신규 `src/nav-voice-picker.css`: 모바일·PC·다크테마 UI
- 신규 `tests/v816-navigation-voice-picker.test.mjs`: 네 가지 기능 테스트

## 검증 및 기존 보호 테스트
- JavaScript 구문 검사 통과
- Chromium 모의 TTS 실동작: 남/여 목소리 각각 선택 및 미리 듣기 콜 대상 확인
- 폭 320/390/1440px 레이아웃 가로 넘침 없음
- 기존 `src/main.js` SHA-256을 불변으로 가정하는 구형 테스트 8건은 변경 후 실패할 수 있음. 해당 파일의 실제 수정은 명시적인 TTS 연동이며, 별도 모듈과 무관한 지도 코드에 대한 변경은 없음.
- 실제 iOS/Android/Windows 한국어 음성 가용성 테스트 및 Vite 빌드는 환경 제약으로 미검증
