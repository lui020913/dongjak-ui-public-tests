# 지도 앱 1·2차 기능 확장 — v8.0.3 FADE+4SAFE 기준

## 기준·정책
- 기준 원본은 `DongjakApp_FULL_v8.0.3_FADE_ICON_FOUR_WALK_SAFETY_INTEGRATED_20261113.zip`(2026-11-13)입니다.
- **이 패치는 기존 v8.0.3의 `src/main.js`를 의도적으로 수정합니다.** 경유지 계산을 기존 `routeStart`·`routeEnd`·`calculateRoute` 및 실제 보행 네트워크와 연결하기 위한 최소 변경이며, 이전의 'src/main.js 파일 전체 변경 금지' SHA-256 불변 테스트 8건은 과거 요구조건과 충돌합니다. 변경한 원본은 패치 적용 전에 백업됩니다.
- 원래 모바일 페이드 애니메이션·아이콘·안전시설 데이터·TOPIS·S-DoT·AED 및 기존 지도 렌더러·교통 데이터 파일은 변경하지 않았습니다.
- 프로젝트 공개 버전 `8.0.3`은 변경하지 않았습니다. 내부 작업 표기: `v815 map-product phase1+phase2`.

## 1차: 장소 검색·상세정보·저장·공유
- 지도 검색의 로컬 자동완성 범위를 지하철·버스정류장뿐 아니라 검증된 일반 시설로 확장했습니다. 원격 Photon 검색은 검색 버튼을 누를 때만 호출합니다.
- 검색 메뉴에 유형별 빠른 검색(대학교·공원·도서관·지하철역·약국)과 **현재 지도 화면 범위만 보기** 옵션을 추가했습니다. 공공 Photon의 보장되지 않은 최신성/포함 범위를 보완하기 위해 2자 이상 유효한 질의만 원격 조회합니다.
- 지도 내 일반 장소를 선택하면 기존 사실 기반 상세정보 팝업과 연결되고, **장소 저장·공유·여기서 출발·여기로 도착**을 사용할 수 있습니다.
- 저장 폴더: 즐겨찾기·집·학교·직장·기타. 모든 기록은 현재 브라우저의 `localStorage`에만 저장되며 계정 간 동기화되지 않습니다.
- 최근 선택 장소는 최대 12개, 저장 장소는 최대 100개입니다. `내 기록` 탭에 저장 장소 목록을 묶고, 지도 검색창에 최근 선택 목록을 표시합니다.
- 장소 공유 URL은 **사용자가 선택한 위치**만 포함합니다. 사용자 GPS 위치·방문 기록은 자동 전송하지 않습니다. 브라우저 공유 시트가 없으면 링크 복사 또는 수동 복사 안내를 사용합니다.
- 새 링크 파라미터: `dj_place=경도,위도`, `dj_name=장소명`.

## 2차: 다중 경유지·지하철 연계 이동안
- 기존 길찾기 카드에 경유지 1~5개 추가 및 검색·지도 지정, 삭제, 순서 변경을 추가했습니다. PC 드래그·모바일 이동 버튼으로 순서를 조절합니다.
- 도보 경유지별로 기존 **서울시 동작구 보행 네트워크** 또는 기존 외부 보행경로 서버를 호출하고, **실제 반환된 도로 선형·거리·시간·내비게이션 정보를 순서대로 합산**합니다. 서버가 거부하거나 유효한 선형이 없는 구간을 직선으로 대체하지 않습니다.
- 기존 일반 도보·경사 회피 경로의 비교와 GPS 안내를 재사용하되, 한쪽 프로필이 일부 구간에서 실패하면 해당 전체 프로필은 생성하지 않습니다.
- 지하철 연계 이동안은 공개된 **역 위치·노선별 역 순서**로 접근 가능한 후보를 찾아주며, 후보 선택 시 출발지↔역·역↔도착지 **두 보행 구간**을 실제 보행 네트워크로 계산합니다. 지도에 역 간 연결은 측량된 선로가 아닌 **개략 직선 안내**로 표시합니다.
- 지하철 참고 시간은 정해진 역간 3분·환승 5분 및 **직선거리 기준** 접근 시간을 사용하는 *참고 계산*입니다. **실시간 도착·정확한 열차 운행시간·실제 승차 지점·환승 통로·요금·버스 경로 정보가 아닙니다.** 버스+지하철 완전한 환승 경로는 구체적인 노선 네트워크 부재로 미구현입니다.
- 경유지 포함한 경로 공유 URL은 순서대로 좌표와 명칭만 담습니다. 수신자는 앱에서 해당 장소를 열고 **경로 계산 버튼을 별도로 눌러야** 합니다.

## 검증 및 제한
- 신규 기능 단위 테스트 13건 통과. 구형 회귀 테스트 979개 중 971개 통과, 8개는 **보호 대상 `src/main.js` 변경 금지 주장**이 현재 신규 요청과 양립하지 않아 실패합니다.
- 320/390/1440px 반응형 카드에 가로 넘침이 없음을 정적 Chromium에서 확인했습니다.
- JavaScript 문법 검사 통과.
- 현재 실행 환경의 오프라인 npm 캐시에 `yauzl`이 없어 Vite 빌드를 완료하지 못했습니다. Windows 실제 브라우저·Capacitor·GPS 및 실시간 대중교통 정보 통합 테스트는 배포 전 필요합니다.

## 적용
1. `APPLY_PATCH.cmd`를 실행하고 **바로 위 기준 원본 ZIP을 압축 해제한 프로젝트 최상위 폴더**를 지정합니다.
2. 파일 해시 검증에 실패하면 다른 v8.0.3 변형에 무단 덮어쓰지 않습니다.
3. 적용 파일은 백업되며 `RESTORE_PATCH.cmd`로 복원할 수 있습니다.
4. `npm ci`, `npm test`, `npm run build`를 실행합니다. `npm test`의 과거 보호 해시 테스트 8건 실패를 위 설명대로 검토합니다.
5. 실제 지도의 검색·저장·공유·복수 경유지·역 연계 이동안 및 모바일 바텀시트가 정상 작동하는지 확인한 후 배포합니다.
