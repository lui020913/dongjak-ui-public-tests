# 동작구 보행안전 지도 — 새 기준 전체 업데이트 내역

현재 서비스 버전: **v8.3.0** · 과거 소급 이력 마지막: v8.0.3 · 보존 기록 136건 · 원문 변경사항 623건

과거 변경 기록을 소급 재분류한 기록이며, 표시된 새 번호가 실제 과거 배포에 사용되었다는 의미는 아닙니다.
구버전 번호는 릴리스 간 추적용이며, 구버전에서 동일한 번호로 기록된 경우에도 새 번호는 각각 부여합니다.

## 번호 규칙

- Major(X.0.0): 새로운 주요 기능 체계나 핵심 구조 변경
- Minor(X.Y.0): 신규 사용자 기능, 중간 규모 UI 개편
- Patch(X.Y.Z): 기능 오류, 성능, 데이터, 표시·안정화 수정

- 더보기 팝오버를 열 때 다른 플로팅 창을 일시적으로 숨기고 닫으면 기존 창으로 되돌려 중복 표시 방지
