동작구 보행안전 지도 — v7.8.1 전체 통합본

1. 반드시 완전히 비어 있는 새 폴더에 이 전체 ZIP을 압축 해제하십시오.
2. 기존 API 키가 있는 경우 .env 파일만 기존 폴더에서 새 폴더로 복사하십시오.
   공개 자료에 키를 붙여넣지 마십시오.
3. Node.js가 설치된 Windows에서 RUN_SEMVER_CURRENT.cmd를 실행하십시오.
   또는 VS Code 터미널에서 npm ci, npm test, npm run build, npm run dev를 순서대로 실행할 수 있습니다.
4. http://127.0.0.1:5195/ 로 접속하십시오.
5. 업데이트 내역에서 v1.0.0부터 v7.8.1까지 표시되는지 확인하십시오.
6. 기존 폴더의 APPLY_PATCH*.cmd / APPLY_RECOVERY*.cmd 등은 구버전용이므로 새 버전 실행에 사용하지 마십시오.
7. Cloudflare 배포는 로컬에서 빌드 및 지도가 정상 작동함을 확인한 후에만 npm run deploy:pages를 실행하십시오.

버전 체계는 첫째 자리=대규모, 둘째 자리=기능 개선, 셋째 자리=작은 수정입니다.
원문 기록 115건과 R1, R2, 재분류 3건 합계 118건을 표시합니다.
구 버전과 신규 버전 대조표: docs/VERSION_MIGRATION_MAP.csv
전체 변경사항: docs/CHANGELOG_SEMVER_FULL.md

이번 빌드는 npm 의존성이 현재 생성 환경에 설치되지 않아 실제 Vite 빌드와 MapLibre 타일 렌더링의 현장 확인이 완료되지 않았습니다.
