# 상도1동 팀원 보행자 사고다발지역 분석 연동

## 기준 및 자료
- 기준 프로젝트: DongjakApp_FULL_v8.0.2_AUDIOSIGNALS_AED_INTEGRATED_20261112.zip
- 추가 자료: dongjak_pedestrian_hotspots.csv, geojason.zip, 사고분석-지역별(TAAS 자료).zip
- 팀원 CSV 38행과 기존 사고다발지역 `dongjak_accident_points_all.geojson` 중 **보행자 유형 38개는 source_fid 기준 100% 동일**합니다. 추가 사고 지점 없음. **중복 추가 금지**.
- 업로드 파일 `geojason.zip` 안의 `*.geojson.gpkg`는 일반 GeoJSON이 아니라 GeoPackage입니다.
- 상도1동 경계는 OSM 기반 9개 선을 연결해 Polygon으로 복원했습니다. 공식 행정동 법정 경계로 단정하지 마세요.
- OSM 경계 기준 내부 대표점은 3개: 2022년 선정 6778949(8건,사망1), 2023년 선정 6838434(7건,사망1), 2024년 선정 6931875(8건,사망1). 대표점 간 거리 약 35~79m.
- **선정 기준연도 ≠ 개별 사고 발생연도**, **3개 기록의 사고건수·사망자수 합산 금지**: 집계기간과 실제 사고의 중복 여부 불명.
- 팀원 설명의 '사고다발 지점 1곳'은 근접 권역 **한 곳**이라는 해석으로 재구성합니다. 공식 단일 위치나 개별 사고 장소 하나로 확정하는 것은 아닙니다.
- TAAS 엑셀 두 파일은 SHA256이 동일하며 모두 **2023년 13행(주간 7, 야간 6)**입니다. 파일명 2024~2025의 데이터가 아니므로 해당 연도 집계로 사용하지 않습니다. 동 단위 주소·좌표가 없어서 상도1동 사고 표식에 연결하지 않습니다.
- 데이터 원본 체크섬: CSV SHA256=831bb304eb3bd20759a6ac0ec15cf8878992121e3dfddbaf04c7d7742281a348

## 구현 방식
- 기존 보행안전 → 사고·횡단 지점 → 보행사고 다발지역 아래 **상도1동 집중 검토** 버튼 추가.
- 활성화 시 기존 사고레이어를 사용하고, 상도1동 경계(청록 점선) 및 근접 통계권역(얇은 적색 면)만 추가합니다. **신규 사고 점마커는 만들지 않습니다.**
- 2022/2023/2024 선정 기록을 별도 카드로 표시하며, 사고건수 합산 금지를 명시합니다.
- TAAS 2023의 동작구 전체 참고 기록은 접힘 영역에서만 제공; 좌표 위조/표시 금지.
- 스타일 변경 중 레이어 복원, 토글 해제, 모션 줄이기 지원.

## 검증
- `npm test` (Node 기본 테스트 명령)
- `npm run build` (Vite 설치된 로컬 프로젝트에서 실행)
- 지도의 오리지널 38개 사고 선택 켜기 → 상도1동 집중 검토 → 경계/면 강조 및 연도별 분석 카드 확인 → 끄기 → 지도 복원.
