# Community moderation (staged)
Deploy only as a coordinated release: configure server-only GEMINI_API_KEY and COMMUNITY_MODERATION_MODEL (a currently available Gemini vision model), publish the new Edge Function, apply community_moderation.sql, and deploy the matching client. Direct inserts are then intentionally blocked. Use a staging project first; validate authenticated allow/remove/review, private notification RLS, duplicate detection, photo OCR, missing AI key, concurrency and service outage. Never place keys or content in a public repository. User submissions are sent to Gemini for moderation; disclose this in privacy policy and configure appropriate contractual data-handling settings before launch. Queue is dashboard-admin-only; use SQL editor with community_moderation_finish for review (published/removed, reason enum). Set an approved retention schedule for removed/review payloads; no automated retention purge or appeals UI yet. Existing published content was not retroactively scanned. Notifications are in-app; not push notifications.
