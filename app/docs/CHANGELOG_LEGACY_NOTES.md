# 정리 및 적용 내역

## 2026-11-05 — v5.2 소스 정리 (새 배포 버전이 아닌 작업 폴더 정리)

### 유지
- 사용자 ZIP의 `dongjak_v5_2_RESTORE`를 **유일한 실행 소스**로 채택했습니다.
- 기존 동작구 경계, 보행안전/도로폭, 3D 건물, 길찾기, 커뮤니티, 버스·지하철 조회 코드, 6개 지하철 노선 및 역사 위치 보정 데이터는 그대로 유지합니다.
- `src/fixed-rail-data.js`, `src/fixed-rail-lines.js`에 있는 역사 좌표 보정과 경계/종점 페이드를 보존했습니다.
- 16개 건물 GeoJSON과 도로폭 GeoJSON은 앱에 필요하므로 제거하지 않았습니다.

### 정리
- 원본 ZIP의 과거 프로젝트 `dongjak_v17_3_1`, Cloudflare 별도 프로젝트, 이전 수동 패치 폴더를 새 프로젝트에서 **제외**했습니다. 원본 ZIP에는 그대로 남아 있습니다.
- 오래된 버전별 README와 백업 파일 `index.html.dj-before-transit.bak`을 제외했습니다. 필요한 설명은 `README.md`, 본 파일 두 개로 통합했습니다.
- 실제 엔트리포인트에서 읽지 않는 `vite.transit.config.mjs` 및 `public/dongjak-transit/` 과거 오버레이를 제외했습니다. 기존 `src/transport-map.js`가 유일한 지하철 레이어입니다.
- 이전 `node_modules`, `.wrangler`, 생성된 `dist` 등 재설치 가능한 산출물은 제외했습니다.

### 실행 환경 변경 (기능 코드 변경 아님)
- `package.json`: `npm run dev`가 `scripts/start-local.mjs`를 실행해 지도와 API 서버를 함께 시작하게 변경했습니다.
- `package.json`: 개별 디버깅용 `npm run dev:map` 명령 추가.
- `vite.config.js`: 기본 지도 포트를 5194에서 **5195**로 통일했습니다. `/api/transport` → 5178 프록시 유지.
- `scripts/start-local.mjs`: 단일 터미널 서버 시작/종료 실행기 신규 추가.
- `scripts/stop-old-servers.ps1`: Windows용 관련 Node 서버 종료 보조 도구 신규 추가.
- `.env`: 이전 `dongjak_v17_3_1`에 들어 있던 사용자 API 키 설정을 **새 정리본으로 이동**해 5178 서버가 읽도록 했습니다.
- `.env.example` (빈 키) / `.gitignore` 신규 추가.

### 정확성 및 제약
- 지하철 역 마커는 역사마스터 유래 좌표 기반이지만, 선형은 실제 터널/선로 측량 결과가 아닌 근사선입니다.
- `GET /api/transport/status`의 두 boolean은 키 존재 유무이지 실시간 도착정보 API의 성공 보장이 아닙니다.
- 로컬 서버는 `127.0.0.1`에 바인딩됩니다. 외부 접속은 별도 서버 배포 설계가 필요합니다.
- 사용자 기록(커뮤니티/즐겨찾기 등)은 브라우저 로컬 저장소에도 들어갈 수 있습니다. 프로젝트 ZIP 정리는 브라우저 저장소를 삭제하지도 복원하지도 않습니다.
