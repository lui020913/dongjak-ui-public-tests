# 미출시 앱 공개 표시 및 내부 배포 식별자

- 로딩 화면: **버전 1.0**. 앱 정보: **1.0**. 개발 중에는 사용자용 버전 숫자를 자동으로 올리지 않습니다.
- 업데이트 내역: 숫자별 항목이 아닌 **주요 개편 / 기능 추가·개선 / 디자인·사용성 / 오류 수정·안정화** 기준으로 분류합니다.
- 기존 원문, 아카이브, 날짜와 모든 기술적 버전 번호는 내부 기록에 그대로 남깁니다. 화면 표시 분류만 변경합니다.
- 내부 `package.json`, Git SHA, `release-source.json`, 빌드 식별자와 클라이언트 캐시 검증용 버전은 유지합니다. 실제 운영 코드와 배포 자동화에서 번호를 제거하면 추적성 및 안전한 롤백이 깨집니다.
- `src/public-release-display.js`가 공개 버전과 변경 유형의 단일 정의입니다. `scripts/stamp-version.mjs`는 빌드 시 공개 화면을 그 값에 맞춰 쓰되 내부 릴리스 메타데이터를 그대로 유지합니다.
- `1.0`은 **사용자 화면에 표시되는 미출시 표식**이며, 정식 출시가 완료되었다는 주장이나 GitHub 배포번호가 아닙니다.
