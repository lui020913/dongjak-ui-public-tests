# 보차혼용도로 도로폭 적용 (신규 팀 평가표)

- 기존 2안 100/0은 최신 PDF 1쪽의 100/70/30/0 기준으로 대체. 4m 이상 6m 미만은 70, 6m 이상은 30. 확인된 물리적 분리는 폭 무관 0. 분류 미확인 또는 필요한 폭 미확인 NULL.
- 서울시 실폭도로 2026-10 상도1동 참고경계 폴리곤 212개, 실제 측량값 아님. 공통 조사망 전체 선형 2m 이하 표본이 단일 폴리곤에 포함되는 경우만 매칭. 대표폭과 P10/P90의 점수 구간이 일치하며 추정 신뢰도 양호/보통인 경우만 조건부 분류.
- 전체 차량 도로망 1,276개 중 폭 정합 649개, 안정 구간 226개. 여기에는 경계와 교차하는 원본 도로 전체가 포함되어 기존 1,606개 클리핑 조사 범위와 집계 분모가 다름.
- 기존 PDF 공간정합 후보 224개 중 폭 정합 127개, 동일 점수 구간 6개(혼용으로 확인된다면 모두 30점). 나머지 121개 폭 불확실, 97개 미정합. 원본 PDF 표시선은 모두 보차분리 여부 미확인. 후보의 실제 점수는 전부 NULL, PRI 및 길찾기 제외. 기존 종합 PRI 값은 따라서 변경되지 않음.
- 폭을 추가한 후보 상세 정보만 기존 단일 보차혼용도로 레이어에 연결. 새 색상/레이어 없음. 과거 후보 가정 100점은 삭제.
- 재현: app 디렉토리에서 node scripts/generate-pri-crossing-shared-20261125.mjs.
