# 보차혼용도로 도로폭 적용 (신규 팀 평가표)

- 최신 PDF: 혼용 도로 폭 <4m 100, 4~<6m 70, >=6m 30. 물리적 분리 확인 0. 미확인 분류/필요 폭은 NULL.
- 기존 서울시 실폭도로 2026-10 추정폭 212개 폴리곤 재사용. 길이 가중 2m 이하 중점 표본의 동일 RW_SN 중첩률 >=70%, 차순위 대비 >=20%p. 신뢰도 낮음/추정 불가 제외. 대표폭으로 조건부 점수를 산정하고 P10/P90 등 폭 변동은 별도 현장 확인 표기로 유지. 이 임계값은 공간 분석용 가정이지 법정 기준이 아님.
- 전체 차량 도로망 1,276개 중 폭 정합 774개(기존 엄격 조건 649개), 대표폭 조건부 계산 774개, 폭 구간 안정 238개. 원본 전체 도로망 집계이며 1,606개 경계 클리핑 범위와 분모 다름.
- 기존 PDF 후보 224개 중 대표폭 조건부 156개(100점 4개, 70점 93개, 30점 59개), 미정합 68개. 156개 중 폭 구간 안정 8개. 이전 조건부 계산 6개. 보차 분리 확인 전 실제 점수는 모두 NULL이며 PRI/길찾기 제외. 기존 종합 PRI 값 유지.
- 기존 단일 메뉴, 범례 및 위험색 유지. 조건부 점수·중첩률·폭 변동은 상세 정보로만 표시. 원본 PDF 표시선은 물리적 분리 여부 미확인 상태.
- 재현: app에서 node scripts/generate-pri-crossing-shared-20261125.mjs.

## 미정합 후보 직각 단면 보완
기존 대표폭 연결 156개는 그대로 보존. 68개 미정합 후보에 한해 도로 중심선 법선과 동일 도로 폴리곤 경계의 양방향 최근접 교점 거리 합을 측정. 중첩 폴리곤, 편심 단면(짧은 쪽 <15%), 폭 1.5~25m 범위 밖, 유효 단면 3개 또는 60% 미만, 동일 점수 구간 75% 미만 및 P90/P10>2.5 제외. 기준은 공간분석용 가정. 4개 추가(70점 1, 30점 3), 단면 부족 61개 및 폭 불안정 3개 유지. 총 160/224개 조건부 폭 평가(100점 4, 70점 94, 30점 62). 실제 물리적 분리 여부 미확인으로 점수 NULL 및 종합 PRI 제외 유지. 원본 도로폭 데이터와 독립 레이어 무변경.
