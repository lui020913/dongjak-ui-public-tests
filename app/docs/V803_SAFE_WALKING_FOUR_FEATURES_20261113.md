# 동작구 보행안전 지도 v8.0.3 4종 기능 확장 패치

기준: `DongjakApp_FULL_v8.0.3_AUDIO_AED_SANGDO_TEAM_INTEGRATED_20261113.zip` (v8.0.3)

## 변경 범위

원본 `src/main.js`, 모바일 모션, 헤더, 기존 안전 레이어와 기존 데이터는 변경하지 않습니다. 기존 보행안전 → 보행도구 영역에 날씨 연계 보행정보와 지역별 보고서 생성 기능을 추가합니다.

### 1) 경로 비교

- 기존 서울시 동작구 도보 네트워크의 `일반 보행` 및 `경사 회피 우선` 실제 계산 결과를 사용합니다.
- 각 경로의 거리, 예상시간, 지형 기반 추정 상승, 고도 미확인 길이, 사고다발 *선정기록의 대표점* 반경 60m 근접 수를 나란히 표시합니다.
- 카드 선택 시 기존 지도 경로 선택 기능을 호출합니다. 같은 선형이면 명시합니다.
- 별도의 3·4번째 경로, 야간 안전경로, 무계단 경로, 정량 안전점수는 생성하지 않습니다.
- 외부 경로 서버 전환 시 로컬 경로별 세부 비교는 제공하지 않습니다. 실제 보행 불가능 구간을 자동 회피했다고 주장하지 않습니다.

### 2) GPS 안내 개선

- 기존 GPS 따라가기, 방향표시, 회전안내, 오차 감시, 연속 표본 기반 재탐색, 음성 안내는 보존합니다.
- Android 등 `navigator.vibrate()` 지원 기기에서만 **명시적으로 켠 경우** 회전 안내 진동을 제공합니다.
- `Wake Lock API`가 지원되는 브라우저에서만 명시적으로 켠 경우 화면 켜짐 유지를 요청하고, 안내 종료·비가시 상태에서 해제합니다.
- 위치 오차를 양호/주의/큼으로 간결하게 구분합니다. GPS 오차가 큰 경우 진동 안내를 발생시키지 않습니다.
- iOS Safari/PWA에서 진동 또는 화면 유지가 지원되지 않을 수 있습니다. 지원되지 않으면 해당 사실을 표시합니다. 보행 중 화면 주시를 요구하지 않습니다.

### 3) 날씨 연계 보행정보

- 기존 Open-Meteo `fetchCurrentWeather` 인터페이스를 사용하여 동작구 대표 지점의 기온·체감기온·강수·풍속을 보여줍니다.
- 비·추위·더위·강풍에 대해 **비공식 참고 조건**을 표시합니다. 공식 기상특보가 아닙니다.
- 응답 측정시각이 확인되지 않거나 현 시각과 2시간 이상 차이나면 상태 판단을 보류합니다.
- S-DoT 레이어를 켜고 끌 수 있지만 기존 레이어 선택을 사용자 허락 없이 강제로 바꾸지 않습니다.
- 강수량과 기온으로 특정 보행로가 위험/안전하다는 등급은 매기지 않습니다.

### 4) 보행안전 분석 현황 보고서

- 동작구 전체 또는 상도1동을 선택해 사고다발 선정기록, CCTV 등록지점, 음향신호기, 경사 추정 보행 링크를 현황표로 만듭니다.
- 도로 돌발정보·AED는 서버 API가 정상 응답한 경우에만 반영하고, 응답 누락이나 미완료 시 '미확인'을 표시합니다.
- S-DoT 주간 센서 기록은 **2026년 10월 26일~11월 1일 과거 기록**으로만 표시합니다.
- 상도1동 범위는 앱에 포함된 `admdongkor` 참고 폴리곤(2026-10-01)을 이용합니다. 보행 링크는 선형 중간점 기준의 대략적인 건수입니다.
- 기본 브라우저에서 새 창에 보고서를 열어 **인쇄 → PDF로 저장**할 수 있습니다. 인쇄 창을 지원하지 않는 환경은 독립형 HTML 파일로 저장합니다.
- 자동 PDF 바이너리 생성, 정밀 안전도 인증, 현장 위험등급 분석은 제공하지 않습니다.

## 실행/확인

```powershell
npm ci
npm test
npm run build
npm run dev
```

`npm run dev`는 해당 프로젝트의 로컬 실행 스크립트입니다. 실제 Cloudflare Functions는 배포 혹은 `npx wrangler pages dev dist --port 8788`에서 확인합니다.

## 배포 전 확인

- 길찾기 두 경로가 같은 경우/다른 경우 비교 카드 정상 표시
- 외부 경로 서버 사용 시 존재하지 않는 대체 경로 정보 미표시
- GPS 안내 종료 후 Wake Lock 해제 및 진동 비활성화
- 동작구 대표 날씨의 측정시각, 실패 시 정보 미표시
- 동작구 전체 및 상도1동 보고서 출력·HTML 저장
- 실제 Android WebView·iOS Safari·Cloudflare Pages Functions 결과

이번 환경에서는 실제 Vite 빌드와 스마트폰 실기기 GPS·Wake Lock 동작까지 검증하지 못했습니다. 기존 자동 테스트 및 신규 테스트와 정적 브라우저 레이아웃만 검증했습니다.
