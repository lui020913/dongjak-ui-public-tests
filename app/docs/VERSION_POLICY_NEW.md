# 동작구 보행안전 지도 — 버전 관리 원칙 (과거 자료)

> **이 문서는 과거 v7.9.3 소급 재분류 작업 당시의 보관 문서입니다.** 현재 v8.3.0 이후의 실제 운영 버전 관리 정책과 명령어는 [`VERSIONING_OPERATIONS.md`](VERSIONING_OPERATIONS.md)를 기준으로 합니다. 기존 기록은 감사 목적으로 보존합니다.

현재 통합 버전: **v7.9.3** (기준 소스: v7.0.29-R2)

| 변경 규모 | 번호 규칙 | 적용 기준 |
|---|---|---|
| 대규모 (Major) | `X.0.0`의 X+1 | 지도·데이터 처리 아키텍처 또는 새로운 핵심 보행안전 분석 체계 |
| 중간 규모 (Minor) | `X.Y.0`의 Y+1 | 사용자에게 보이는 신규 기능·정보 흐름·상당한 UI 개편 |
| 소규모 (Patch) | `X.Y.Z`의 Z+1 | 오류 해결, CSS·표시 보완, 안정성·데이터 및 버전 정보 정리 |

- 매 변경은 **가장 높은 변경 규모 하나**로 판정합니다. Major/Minor 때 하위 숫자는 0으로 초기화합니다.
- 프로젝트 최초 릴리스는 **v1.0.0**입니다.
- 이전 배포의 버전 기록 115개/원문 변경사항 519개는 수정하지 않고 `src/version-history.js`, `src/version-history-legacy.js`에 보존했습니다.
- 그 위에 R1, R2, 이번 버전 체계 정비 3건을 추가했습니다. 화면과 신규 전체 이력 문서는 새 번호를 표시합니다.
- **소급 편집 번호**는 과거 서버에 해당 버전이 배포되었다는 의미가 아닙니다. 기존 원본 파일·패치 ZIP은 옛 번호를 그대로 사용할 수 있습니다.
- 원래 기록에서 `v7.0.25`가 중복된 2건은 합치지 않았습니다. 새 번호는 별도 부여하고 옛 번호 대조표에서 기록 순번으로 구분했습니다.
- 본 작업은 **기본 지도 초기화 및 교통 데이터 로더를 변경하지 않는 버전·이력 UI 작업**입니다.
- R2의 실제 MapLibre 타일 렌더링과 Vite 빌드 성공 여부는 별도 검증이 필요합니다.

## 버전 번호 작업 순서

1. 변경 내용을 Major/Minor/Patch 기준으로 평가합니다.
2. 신규 릴리스 한 건을 `src/release-semver.js`의 `REBUILT_RELEASES`에 기록하고, 버전 산출 결과를 확인합니다.
3. `package.json`, `package-lock.json`, `public/version.json`, `src/build-info.json` 및 `index.html` 표시를 같은 값으로 업데이트합니다.
4. `node scripts/export-semver-history.mjs`로 전체 이력 문서와 대조표를 생성합니다.
5. `npm test`로 데이터 보존·버전 일치·기능 회귀 검사를 수행하고 실제 빌드와 브라우저 실행도 확인합니다.
