# v8.2.14 · 모바일 바로가기 개인화 / 날씨 패널 / 동작구 경계 보호

기준: `DongjakApp_FULL_v8.2.13_PRIORITY_SHORTCUTS_INFO_SHEET_INTEGRATED_20261114.zip`

## 사용자 요청 반영

1. 펼쳐진 원형 버튼 폭을 문구 길이 기반 측정값으로 조정했습니다. 버튼별 폭을 단일 최소값으로 제한하지 않습니다.
2. 동일한 `circle-translate`와 `text-translate`를 이용해 군집 개수 배지와 글자 중심을 일치시켰습니다.
3. 안전지도 로고 버튼에 추가로 그려지는 배경·테두리·그림자를 제거하고, PNG 이미지 자체를 터치 타깃으로 사용하도록 조정했습니다.
4. 기존 글자 크기/굵기 조절 기능은 '더보기'로 이동했습니다. 팝업은 하단 탭 위에 표시됩니다.
5. 날씨 원형 버튼에 현재 조회값과 상세 메타데이터를 표시하는 하단 플로팅 정보창을 연결했습니다. X와 새로고침 버튼이 있습니다.
6. 실시간 버스·지하철 기본 바로가기를 더보기로 이동했습니다. 사용자가 원하면 상단에 다시 추가할 수 있습니다.
7. 야간 시야 버튼은 중앙 확인창에서 '예, 시작'을 선택한 경우에만 기존 야간 시야 분석을 켜고 다크 테마로 전환합니다. '아니요'는 상태를 변경하지 않습니다. 실행 중에는 버튼으로 즉시 끌 수 있습니다.
8. '내 주변 보행정보'는 기존 동작구 경계 검증과 데이터 미확인 경고를 유지합니다. 경계 밖 또는 경계 미확인 시 기존 위치 조회 모듈이 알립니다.
9. 이미 켜진 지도 데이터를 하단 설명창 X/스와이프로 닫아 원형으로 접은 경우, 다음 탭에서 켜진 상태를 확인한 뒤 바로 끕니다.
10. 지도 기본 레이어 항목은 추가 정보창 없이 기존 ON/OFF 동작만 실행합니다.
11. 사용자는 더보기의 '상단 바로가기 편집' 또는 각 항목의 '밖으로' 버튼에서 기능을 이동할 수 있습니다. 선택은 이 브라우저의 `localStorage`에 저장됩니다. 초기 중요 기능은 사고다발, 방범 CCTV, 횡단보도, 경사도, 보호구역, 주변정보이며 실시간 차량은 더보기에 둡니다.
12. 동작구 외부 선택 차단은 지도 직접 선택, 교통시설 확인, 검색 결과, 외부 시설 선택, 경유지 관리 및 실제 경로 계산 직전에 모두 적용합니다. 경계자료가 아직 로드되지 않았다면 안전하게 거부하고 안내합니다.

## 안전성·한계

- 지하철 차량 위치는 실제 GPS가 아닌 추정이며, 버스 실시간 위치는 API 응답에 따라 표시됩니다.
- 주행·보행 경로는 출발·경유·도착 좌표가 동작구 내부인 경우에만 계산 요청됩니다. 인근 경계에서 경로 자체가 일시적으로 구 외부 도로를 통과하는지까지 완전 검증하는 기능은 이번 패치에 추가하지 않았습니다.
- 날씨 패널은 기존 Open-Meteo 조회 결과만 읽고, 실제 값을 임의 생성하지 않습니다.
- 브라우저별 사용자 저장공간 정책에 따라 바로가기 배치가 초기화될 수 있습니다.
- 기존 v8.2.13 버전의 SHA-256 보호검사 중 `src/main.js` 변경 금지 부분은 사용자 요청에 따라 동작구 경계 확인 로직을 추가하는 변경으로 재승인했습니다. 종전 지도/교통 코드를 유지하면서 새 경계 동작 8개 테스트를 추가했습니다.

## 검증 및 배포

`npm ci`, `npm test`, `npm run check:release`, `npm run build`, `npm run deploy:pages` 순서로 수행하십시오. 현재 도구 환경에서는 외부 의존성 캐시가 없어서 전체 Vite 빌드를 완료하지 못했습니다. 자동검사와 분리된 Chromium 인터랙션 스모크 테스트는 수행했습니다.
