# 동작하는 안전지도 v8.4.1 — v8.4.0 × v8.3.2 UX 패치 병합

## 병합 기준과 우선순위
- 원본: `DongjakApp_FULL_v8.4.0_TRANSIT_15_FIXES_INTEGRATED_20261114(1).zip`
- 반영할 기능: `Dongjak_v8.3.2_TRANSIT_ROUTE_MOBILE_UX_DeltaPatch_20261114.zip`
- 원본 v8.4.0의 15개 UI 수정, 카카오 계정, 검색, 지도 팁, 탭 위치, 뉴스·리뷰·교통 API, SemVer 릴리스 관리는 그대로 유지
- v8.3.2의 예전 `index.html`·`package.json`·버전 메타데이터는 통째로 덮어쓰지 않음

## 추가 반영
1. GPS 현재 위치를 길찾기 출발지로 설정할 때 동작구 밖 또는 경계정보 미확인 상태면 성공 알림을 표시하지 않음. 안내 플로팅창으로 재선택 요청
2. 경유지는 `＋ 경유지 추가` 버튼으로 펼쳐 선택하고, 도보+지하철 참고 이동안과 공유 메뉴를 경로 계산 버튼보다 앞에 표시
3. 버스 헤더 겹침·노선 번호와 방면 문자 시작선·고정 헤더 스크롤 차폐 조정
4. 즐겨찾기 로그인 플로팅창을 실제 모바일 하단 탭 높이에 따라 위치 조정
5. 모바일 축척바를 대중교통 패널이 열려도 조건에 따라 노출
6. 커뮤니티·동작 소식·내 정보 페이지를 검색창 아래부터 하단 탭 위까지 확장하고 본문에서 스크롤
7. SemVer 패치 릴리스 `8.4.1`을 기록하고 기존 v8.4.0 변경 내역 보존

## 적용·검사
- 델타 패치는 **이 v8.4.0 원본 전용**이며, 설치 전 파일 SHA-256 검증과 자동 백업·복원 제공
- Windows: `APPLY_PATCH.cmd` 실행 → 원본 프로젝트 폴더 지정
- 확인: `npm ci` → `npm test` → `npm run check:release` → `npm run build` → `npm run deploy:pages`
- 전체 테스트: 별도 검증 로그를 참조하십시오. 런타임 실기기 GPS·카카오 로그인·대중교통 API는 자동검사를 넘어서는 추가 검증 필요
- 현재 환경의 Vite 실행 파일 부재로 실제 번들 빌드는 별도 PC에서 필요

## 기능적 제한
- 동작구 안의 출발·도착·경유지만 허용하지만, 모든 경로 선형이 구 경계 안에만 있는지까지 검사하지는 않습니다.
- 모바일 축척바는 안전한 위치를 찾은 경우에만 표시합니다.
