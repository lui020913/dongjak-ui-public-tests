# 보관된 PC·태블릿 CSS (실행 경로 제외)

- 이전 경로: `app/src/`
- 보관 위치: `app/archive/pc-tablet-legacy-css/`
- 본 PR에서 미참조 CSS 추가 제거: 15개(그중 PC·태블릿 13개 보관, 공통·모바일 2개 삭제)
- 먼저 main에 반영된 정리 커밋 `d1b110af`: 7개 삭제 및 과거 경로를 읽던 테스트 현대화
- 종합: 총 22개 미참조 CSS가 활성 소스에서 제외됨
- 사용 중인 CSS 169개 및 지도/교통/AI/계정 모듈은 보존

이동·삭제 파일은 Git 이력에서 복원할 수 있습니다. 과거 버전이라는 이유만으로 현재 가져오는 CSS를 삭제하지 않습니다. 전체 CSS 충돌과 중복 애니메이션 문제는 별도 테스트가 필요한 상태입니다.
