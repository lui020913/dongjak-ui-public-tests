# 동작하는 안전지도 — v8.0.1

기준 프로젝트: `DongjakApp_FULL_v8.0.0_UNIFIED_UI_ARCHITECTURE_20261112.zip`

## 개선 내용

- 모바일 주요 플로팅 창(하단 탭, 교통정보, 행정동, 지도 메뉴 등)을 표시할 때 Web Animations API 기반 진입 애니메이션을 실행합니다. 접근성 설정의 움직임 줄이기를 따릅니다.
- 모바일 독립 앱 로고를 테마 버튼보다 약 6px 크게 표시합니다.
- iOS/Android 모바일 및 PC의 앱 로고를 누르면 라이트/다크와 무관하게 **동일한 업데이트 내역 창**을 엽니다.
- PC 검색창의 기존 56px 높이를 복구하고 날씨·테마·버전·설정 버튼 높이를 맞춥니다.
- 지도 설정 및 업데이트 내역이 열릴 때 지도의 암전과 배경 블러를 제거합니다. 창 자체에는 경계·그림자와 등장 애니메이션을 유지합니다.

## 적용 범위와 제약

- 지도 엔진(`src/main.js`), 교통 API, 보행안전 GIS 자료는 변경하지 않았습니다.
- 기존 133개 릴리스 이력을 유지하고 v8.0.1 패치 기록을 추가했습니다.
- iPhone 홈 화면 PWA의 상태 표시줄은 iOS 자체 제어가 있으므로 실제 기기에서 최종 확인이 필요합니다.
- 브라우저 Web Animations API가 없는 환경에는 CSS 기본 진입 효과가 남아 있습니다.

## 실행

```powershell

npm test

npm run dev
```
