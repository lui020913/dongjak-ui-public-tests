# 동작하는 안전지도 v8.4.3 — v8.4.2 모바일 축척바와 경로·TIP 개선 통합

## 기준 버전
- 업로드하신 `DongjakApp_FULL_v8.4.2_MOBILE_SCALE_OVERLAY_COLLISION_FIXED_20261114.zip`에서 직접 수정
- v8.4.2의 모바일 축척바 / 오버레이 표시 우선순위와 v8.3.2 경유지 입력·교통 기능을 보존
- SemVer Patch: 8.4.2 → 8.4.3, 기존 v8.4.2 및 v8.4.1 릴리스 기록 보존

## 이번 병합
1. 실제 계산된 보행 경로 비교를 길찾기 입력창 대신 지도 위 `#route-map-card` 내부에 표시합니다. 중복 비교 컴포넌트는 제거합니다.
2. `＋ 경유지 검색` 버튼에서도 입력 패널 확장과 키보드에 따른 스크롤을 적용합니다. 이전 `검색으로 추가` 문구도 지원합니다.
3. 지도 위에 경로 미리보기·내비게이션 패널이 있는 경우 지도 렌더링 모드를 유지하면서 하단 **길찾기** 탭을 활성으로 표시합니다.
4. 더보기 기본 지도 레이어의 실제 표시 ON/OFF 토글을 복원합니다. 레이어의 상단 바로가기 추가는 여전히 제한하며 '상단 표시' 문구와 중복 메뉴·여백을 정리합니다.
5. TIP 앞에 굵은 글씨를 표시하고 안내 문구의 순환 간격을 5초로 변경합니다. 물음표 도움말에서도 전체 목록을 확인할 수 있습니다.

## v8.4.2 축척바와 TIP 충돌 방지 정책
- 기존 v8.4.2의 축척바 비가림 정책을 우선합니다. 지도 진입 시 TIP을 3.4초만 표시해 축척바를 복원합니다.
- 문구는 5초마다 다음 메시지로 갱신하지만 **TIP이 계속 표시되거나 매 5초마다 재등장하지는 않습니다**. 지도에 다시 진입하면 갱신된 안내가 표시됩니다.
- 지도 관련 팝업·바텀시트가 열려 있으면 TIP과 축척바가 중복으로 표시되지 않습니다.
