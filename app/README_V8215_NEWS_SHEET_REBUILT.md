# 동작구 보행안전 지도 v8.2.15 — 창 헤더 재구성

기준 전체본: DongjakApp_v8.2.15_LAYOUT_FIXED_FULL.zip

## 핵심 변경
- 동작구 소식, 도보 길찾기, 우리 동네 이야기, 내 정보, 행정동 선택의 헤더를 **동일한 새 DOM 구조**로 재작성했습니다.
- 각 창 제목·아이콘은 왼쪽, 닫기(X)는 오른쪽, 회색 드래그 손잡이는 위쪽 중앙에 고정합니다.
- 기존 `page-heading` / `admin-dong-heading` 헤더 클래스를 사용하지 않아 구형 CSS와 직접 충돌하지 않습니다.
- 행정동 아이콘 SVG는 24×24 고정이며, 15개 행정동은 패널 내부에서 스크롤됩니다.
- 모바일 패널 높이는 최대 50dvh이며 길찾기 입력·커뮤니티·내 정보·행정동 선택·뉴스의 데이터와 기존 클릭 동작을 보존합니다.
- 기존 제스처 컨트롤러와 내 정보 화면, 관심장소 삽입 모듈을 새 헤더에 맞게 연결했습니다.
- 지도 엔진, 실제 지도 데이터, 로그인 설정 및 계정 로직은 수정하지 않았습니다.

## 검증
- npm test : 1,212개 전부 통과
- 모바일 Chromium 격리 렌더링: 375×667, 390×844, 430×932에서 5개 헤더 X 오른쪽/아이콘 24px/손잡이 중앙/창 높이 50% 이하 확인
- 행정동 버튼 15개 구성 후 작은 화면의 내부 스크롤 확인
- 기존 스와이프 제어기를 실행해 손잡이 아래로 드래그 시 행정동 선택 종료 확인; 나머지 네 창 X 닫기 클릭 확인
- npm run build : 이 실행 환경에 Vite 패키지가 없어 미완료
- 실제 iPhone Safari/PWA 및 Cloudflare 배포 후 UI는 미검증

## 설치 (전체본)
1. 별도 프로젝트 폴더에 전체 ZIP을 압축 해제합니다.
2. 기존 `.env.local` / `.env.production.local` 및 서버 측 환경변수를 안전하게 유지합니다. 이 ZIP에 인증 비밀키를 넣지 않았습니다.
3. VS Code 터미널에서 `npm ci`, `npm test`, `npm run build`, `npm run deploy:pages`를 실행합니다.
4. 실제 iPhone에서 길찾기, 커뮤니티, 동작 소식, 내 정보, 행정동 선택 창을 확인합니다.

## 설치 (패치본)
1. 패치 ZIP을 별도 폴더에 압축 해제합니다.
2. `APPLY_PATCH.cmd`를 실행한 다음 기존 v8.2.15 프로젝트의 루트 폴더를 입력합니다.
3. 모든 원본 파일 해시를 먼저 검사합니다. 파일이 변경된 최신 버전이면 안전을 위해 적용을 중단합니다.
4. 적용된 파일은 기존 프로젝트 안 `_dj_v8215_rebuild_backup_*` 폴더에 자동 백업됩니다.
5. 필요시 `ROLLBACK_PATCH.ps1`로 백업을 복원합니다.

이미 다른 프로젝트나 최신 버전에서 같은 파일을 수정했다면 강제 덮어쓰지 마십시오. 첨부 최신본으로 재병합해야 합니다.
