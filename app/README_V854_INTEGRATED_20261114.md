# 동작구 보행안전 지도 v8.5.4 — PC 헤더·검색·모바일 UI 통합

기준 소스: `DongjakApp_FULL_v8.5.3_PC_RESPONSIVE_MOBILE_UX_INTEGRATED_20261114(2).zip`

## 반영 사항

### 1. PC 상단 헤더와 우측 지도 도구
- PC 검색창에 기존 폭 상한 560px를 복원했습니다. 넓은 화면에서 검색창이 불필요하게 늘어나지 않고 우측 도구 영역과 겹치지 않습니다.
- 700~1079px 구간에 별도 반응형 헤더 배치를 추가했습니다. 검색창의 위치·정렬을 명시하고 날씨/버전 보조 요소를 축약해 버튼 충돌을 방지합니다.
- 우측 나침반·홈·도움말·위치 도구를 상단 헤더 아래로 이동했습니다.
- PC 사이드 내비게이션에서 안전지도 탭을 첫 번째로 배치했습니다.
- 지도 옵션·야간 시야·보행안전 버튼의 높이, 글꼴, 아이콘 박스 크기를 통일했습니다.

### 2. 검색 추천창
- 결과를 대중교통 시설과 일반 시설의 좌우 2개 열로 나누고, 각 열을 독립 스크롤로 구성했습니다.
- 각 열의 스크롤바는 시각적으로 숨기되 스크롤 기능은 유지합니다.
- 검색어를 입력하면 빠른 검색 칩을 접어 결과 영역을 확보합니다.
- `현재 지도 범위에서만 찾기` 체크박스를 제거했습니다. 검색 결과가 현재 화면 밖에 있다는 이유로 누락되지 않습니다.
- 검색 결과를 병합할 때 교통시설 결과가 일반 POI에 밀려 사라지지 않도록 결과 슬롯을 분배합니다.
- 기존 검색 엔진, 동작구 검증 장소, 서울시 공식 시설 조회, 중복 좌표 제거 및 장소 선택 이벤트는 유지했습니다.

### 3. 더보기·레이어·날씨
- 모바일 더보기 패널에 고정형 제목과 닫기(X) 버튼을 추가했습니다.
- 모바일의 중복 지도 옵션 바로가기를 숨기고, 기존 더보기의 `지도 설정` 동작을 통해 동일한 지도 옵션에 접근하도록 정리했습니다.
- 기존 기본 지도 레이어·안전 레이어의 표시 토글은 더보기 내 기능으로 유지했습니다.
- 날씨 표시는 아이콘과 기온 중심으로 간소화했습니다. 모바일은 기존 상세 날씨 시트를 사용하고, PC에도 클릭형 상세 날씨 시트를 추가했습니다.

### 4. 언어·즐겨찾기·지도 TIP
- 내 정보에 한국어/English 언어 선택을 추가하고 선택을 브라우저에 저장합니다.
- 앱 인터페이스의 주요 메뉴·패널·버튼·안내 문구를 영어로 전환합니다. 장소 고유명, 주소, 사용자 작성 내용, 외부 지도 타일의 지명은 원문을 유지합니다.
- 시설 상세창의 즐겨찾기 버튼을 별 아이콘으로 표시하고 `aria-label`, `title`, `aria-pressed`를 유지했습니다. 대중교통 즐겨찾기 아이콘은 기존 구현을 보존했습니다.
- 모바일 지도 TIP을 축척바와 겹치지 않는 우측 영역에 고정하고, 문구가 길 때 알약 영역 내부에서만 좌우로 이동하도록 했습니다.
- 노들섬 우선 마커/명칭과 1·4·7·9호선·신림선 개략 연결선, 기존 v8.5.2 모바일 UX 및 v8.5.3 PC/교통/시설 개선은 기준 소스의 구현을 보존했습니다.

## 검증
- `npm test`: **1,323개 테스트 통과**.
- `npm run check:release`: **v8.5.4 / 136개 릴리스 기록 정합성 검사 통과**.
- 변경 JavaScript `node --check` 및 신규 CSS 중괄호 검사 통과.
- `npm run build`: 이 실행 환경에서 npm registry DNS 오류(`EAI_AGAIN registry.npmjs.org`)로 의존성 설치가 완료되지 않아 `vite: not found`로 종료됐습니다. **Vite 빌드는 검증되지 않았습니다.** 기존 `node_modules`는 원본 ZIP에 없으며, 부분 설치 폴더는 배포 ZIP에서 제외합니다.
- 이전 대화에서 빨간색 원으로 표시한 UI 요소는 원본 이미지가 현재 대화에 없어 정확한 대상을 확인할 수 없으므로 임의로 숨기거나 삭제하지 않았습니다.

## 적용
전체 통합본은 프로젝트 폴더에 새로 풀어 사용합니다. 델타 패치는 v8.5.3 프로젝트 루트에서 `APPLY_PATCH.cmd`를 실행해 적용할 수 있습니다. 패치 스크립트는 기준 버전을 확인하고 변경 파일을 백업한 뒤 덮어씁니다.
