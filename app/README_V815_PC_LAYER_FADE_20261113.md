# v815 – PC 창 디자인/데이터 레이어 페이드 (2026-11-13)

기준 전체 프로젝트: `DongjakApp_FULL_v8.0.3_SINGLE_WINDOW_LOGIC_977PASS_20261113.zip`.
본 패치는 기존 앱 버전 표기 `v8.0.3`을 유지하며, 지도 소스 데이터와 교통 API는 수정하지 않습니다.

## 반영 내용
1. PC 검색창 입력 영역의 안쪽 회색 사각 배경 제거. 둥근 검색 폼은 유지.
2. 테마 전환 버튼의 좌우 여백 확대, 텍스트 길이에 따라 버튼 너비 자동 조정.
3. 지도 조작 안내 `원위치`의 나침반/집 아이콘 안내를 각각 한 줄로 분리(PC/모바일 공통).
4. 설정창의 회색 설정 그룹/푸터 배경 제거 및 구분선 유지.
5. 주요 창 X 버튼의 크기·테두리·기호를 42px 기준으로 통일하고 중복 기호 제거.
6. PC 보행안전 도구창의 가로폭을 최대 790px(화면 여유폭 이내)로 확장.
7. 추가 안전·환경 데이터와 도로폭 GeoJSON 레이어에 280ms 투명도 전환 적용.
   - MapLibre 레이어의 투명도 속성(기호/원/선/면)만 전환합니다.
   - 끌 때 투명도가 0이 된 후 비표시 처리하여 잔상·즉시 사라짐을 방지합니다.
   - 빠른 연속 조작은 이전 종료 콜백을 취소해 새 표시를 유지합니다.
   - 운영체제 또는 앱의 '움직임 줄이기' 설정에서는 전환을 생략합니다.
   - 기본 지도(타일·건물·지명) 전체에 페이드를 강제하지 않습니다.
