# 동작하는 안전지도 v8.6.3 — 게스트 온보딩 및 지도 안내 개선

## 기준 및 적용 대상
- 기준 프로젝트: `DongjakApp_FULL_v8.6.2_REQUESTED_UX_INTEGRATED_20261114.zip`
- 패치 버전: `8.6.3`
- 적용 대상은 반드시 v8.6.2 전체 프로젝트입니다. 자동 적용 스크립트가 `package.json`과 `package-lock.json`의 기준 버전을 확인합니다.

## 반영 내용

1. **로그아웃 상태의 앱 둘러보기 우선 표시**
   - Supabase 인증 상태가 확인될 때까지 `checking` 상태로 대기해 인증된 사용자를 게스트로 오인하지 않습니다.
   - 로그아웃 상태가 확인되면 이전에 안내를 완료했더라도 첫 번째 온보딩 화면부터 표시합니다.
   - 로그아웃 버튼 실행 직후에도 인증 상태 이벤트를 전달해 앱 둘러보기를 엽니다.

2. **전체 화면 온보딩 및 조작 개선**
   - 모바일 화면 전체를 차지하는 플로팅 레이어로 표시합니다.
   - 영어 킥커·앱명 브랜드 아이콘·일러스트 아래 앱명/스와이프 문구를 제거합니다.
   - 버튼과 텍스트 영역을 제외한 화면 전역에서 좌우 스와이프가 작동합니다.
   - 설명·체크 항목·진행 표시의 작은 글씨를 확대합니다.
   - 마지막 `시작하기` 버튼은 닫기 애니메이션이 끝난 후 지도 조작 안내를 엽니다.

3. **지도 조작 안내창**
   - iPhone 홈 화면 설치와 지도 이용 TIP 박스의 여백·높이·화살표를 통일하고 축소합니다.
   - 지도 이용 TIP은 최초에 접힌 상태입니다.
   - iPhone 설치 안내의 중복 설명 문단을 제거했습니다.
   - 온보딩이 자동 안내 세션 키를 선점해 지도 조작 안내가 닫힌 뒤 중복으로 다시 뜨는 경합을 차단합니다.

4. **지도 TIP 알약바**
   - `TIP` 라벨은 고정하고 문구만 별도 클리핑 영역에서 움직이도록 구성했습니다.
   - 알약바 가장자리와 문구 사이에 좌우 여백을 확보했습니다.

## 변경 파일
`PATCH_MANIFEST.txt`에 적힌 파일만 교체됩니다. 기존 파일은 프로젝트의 `_patch_backups` 아래에 자동 백업됩니다.

## 적용 방법
1. v8.6.2 프로젝트 전체 ZIP을 새 폴더에 압축 해제합니다.
2. 이 패치 ZIP을 별도 폴더에 압축 해제합니다.
3. `APPLY_PATCH.cmd`를 실행하고 v8.6.2 프로젝트 폴더를 선택합니다.
4. 기준 버전 검사를 통과하면 변경 파일만 덮어쓰고 백업합니다.

`npm install`, `npm ci`, `npm run build`는 이 패치 제작·검증 과정에서 실행하지 않았습니다. 적용 후 별도 빌드가 필요하다면 프로젝트 운영 절차에 따라 진행하십시오.
