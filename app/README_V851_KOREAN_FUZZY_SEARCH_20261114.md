# v8.5.1 — 한글 자모·초성·오타 허용 통합 검색

## 적용 내용
- `스ㅌㅏ 버ㄱ스` → `스타벅스`처럼 한글 자모가 분리된 입력을 조합형 한글로 정규화합니다.
- `스타 벅스`처럼 띄어쓰기가 다른 검색어를 동일하게 처리합니다.
- `ㅅㅌㅂㅅ`처럼 초성만 입력한 검색을 지원합니다.
- `스타벅수`처럼 짧은 오타는 편집거리 기반 유사도로 검색합니다.
- 검색 결과는 정확 일치 → 포함 일치 → 초성 → 오타 유사도 순으로 정렬합니다.
- 지도에 실제로 로드된 OSM POI, 저장된 주요 장소, 역 목록에 적용합니다.
- 전체 검색 제출 시 정규화된 검색어를 서울 공식 시설 API 및 Photon 검색에 전달합니다.

## 제한사항
- 초성·오타 매칭은 현재 지도에 로드된 OSM POI 및 앱 내부 저장 장소 후보에 대해 우선 적용됩니다.
- 외부 검색 서비스가 초성 검색을 직접 이해하는 것은 아니며, 전체 검색 시에는 자모를 조합한 검색어로 요청합니다.
- 매우 짧은 검색어는 오탐 방지를 위해 퍼지 매칭을 제한합니다.
- `스ㅌㅏ 버ㄱ스`는 자모를 조합하여 `스타벅스`로 바꾸지만, 실제 결과는 해당 장소가 OSM/공식 시설/외부 검색 데이터에 존재해야 합니다.

## 검사
- 한글 자모 조합, 초성, 오타, 결과 순위 단위 테스트 통과.
- 관련 검색 회귀 테스트 통과.
- 전체 테스트는 기준 소스에서 보호 파일 해시를 검사하는 기존 10개 항목이 실패하여 전체 통과로 판정하지 않았습니다.
- 이 실행 환경에는 `node_modules`가 없어 Vite 빌드는 수행하지 않았습니다.
