# 동작구 보행안전 지도 v8.5.2 — 모바일 지도·패널 UX 보정

기준 프로젝트: `DongjakApp_FULL_v8.5.1_KOREAN_FUZZY_SEARCH_20261114(1).zip`

## 반영 사항
1. 최초 지도 조작 안내창의 헤더와 닫기 버튼을 스크롤 중에도 상단에 고정하고 스크롤바를 숨겼습니다.
2. 안내창의 `지도 이용 TIP`을 접고 펼칠 수 있게 했습니다. iPhone 설치 안내의 펼침 화살표도 중앙 정렬하고 크기를 키웠습니다.
3. 검색창 아래 바로가기 도구는 실제로 숨겨졌다가 다시 나타나는 경우에만 페이드인합니다. 이미 표시 중인 상태에서 다른 창을 닫아도 애니메이션이 반복되지 않습니다.
4. 더보기 창을 닫을 때 190ms 페이드아웃 후 숨기며, 애니메이션 중 다시 열면 이전 닫기 타이머가 새 화면을 닫지 않도록 전환 토큰을 사용합니다.
5. 지도 TIP은 지도 단독 화면에서 계속 표시하고, 5초마다 문구만 페이드 전환합니다. 축척바는 왼쪽, TIP은 오른쪽에 알약형으로 배치하며 서로 다른 공간을 사용합니다. TIP을 누르면 지도 조작 안내창이 열립니다.
6. 하단 탭, 대중교통, 시설·상세정보 창에 아래에서 올라오는 진입 애니메이션을 적용했습니다. 모바일 창은 헤더 전체에서 아래로 당겨 닫을 수 있도록 제스처 영역을 넓혔습니다. 버튼·입력 요소는 기존 클릭 동작을 유지합니다.
7. iOS 터치 하이라이트를 제거하고 버튼 상태 전환을 부드럽게 정리했습니다.
8. 내 정보의 프로필 상세 화면 전환에 페이드아웃·페이드인을 적용하고, 사용하지 않는 `지도 & 이동` 그룹을 제거했습니다.
9. 안전지도 탭의 아이콘·라벨 행 높이와 위치를 고정해 탭 선택 시 위로 움직이는 현상을 방지했습니다.
10. MapLibre의 공개 `setPixelRatio()` API를 이용해 터치형 699px 이하 화면에서만 최대 1.75배로 렌더링합니다. PC와 비터치 화면은 기존 1.5배 상한을 유지합니다.

## 적용 및 확인
```powershell
npm ci
npm test
npm run check:release
npm run build
```

모바일 지도 픽셀 비율은 `src/map-scale-docking.js`에서 반응형으로 조정합니다. MapLibre 공식 API는 `getPixelRatio()`와 `setPixelRatio()`를 제공합니다.

## 주의
- 소스 테스트 및 정적 검증은 자동으로 수행할 수 있지만, iPhone Safari/PWA의 실제 터치·애니메이션은 기기에서 최종 확인해야 합니다.
- 1.75배 렌더링은 1.5배보다 픽셀 처리량이 증가합니다. 발열·프레임 저하가 확인되면 모바일 상한을 1.6~1.65로 낮출 수 있습니다.
