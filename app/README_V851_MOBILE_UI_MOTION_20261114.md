# v8.5.1 모바일 HUD·전환 모션 보완

기준: v8.5.0 서울시 공식 시설 데이터 통합본

## 적용 내용
- 지도 TIP은 축척바 표시를 막는 오버레이가 아니라 별도 HUD로 처리합니다. TIP의 실제 위치를 관찰해 축척바를 위쪽의 별도 레인으로 이동시키므로 두 요소가 번갈아 사라지지 않습니다. 검색·경로·시설·대중교통 등 실제 창은 기존처럼 축척바를 숨깁니다.
- iOS 터치 하이라이트를 모든 앱 내 버튼·링크·역할 버튼에서 투명 처리하고, 프로필·주요 패널의 배경을 불투명하게 유지해 전환 중 검정 합성 레이어가 드러나는 현상을 줄입니다.
- 검색창 아래 지도 도구 모음은 창을 닫고 지도 화면으로 돌아올 때 opacity 기반 약 320ms 페이드인으로 복귀합니다. transform이나 지도 상태는 변경하지 않습니다.
- 커뮤니티·동작 소식·내 정보 전체화면 패널은 기존 dj-v8212 공통 포인터 스와이프 컨트롤러를 그대로 사용하며, 드래그 중 실제 translate/opacity 변수가 적용되도록 CSS를 보완합니다.
- v8.5.0 서울시 약국·동물약국·음식점 공식 데이터 및 Cloudflare D1 연동 코드는 보존합니다.

## 검증
- Node 회귀검사: 1,291/1,291 통과.
- JS 구문 검사: `map-scale-docking.js`, `v845-mobile-motion.js`, `v840-coordinated-ui.js` 통과.
- 릴리스 버전 검사: v8.5.1 전체 버전 표기 동기화 통과.
- Vite 프로덕션 빌드와 iOS Safari/PWA 실기기 GPU 합성 동작은 별도 검증이 필요합니다.
