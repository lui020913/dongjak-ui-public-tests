# 동작구 보행안전 지도 – 모바일 애니메이션·다크 아이콘 소규모 개선

기준: `DongjakApp_FULL_v8.0.3_MOBILE_UX_MOTION_OPTIONS_965PASS_20261113.zip`

## 반영 내용

1. 모바일 플로팅 창 애니메이션은 **부드러운 페이드만 사용**합니다. 열기 220ms / 닫기 180ms이며 위아래 이동·확대·클립 전환을 제거했습니다.
   - 지도 설정에서 과거 애니메이션 스타일 선택 UI를 제거했습니다.
   - 기기에 과거 '아래에서 펼치기', '효과 없음'을 저장했어도 무시하고 페이드로 초기화합니다.
   - 사용자의 iOS 손쉬운 사용 설정 또는 앱의 '움직임 줄이기'는 접근성 예외로 그대로 존중합니다.
2. **다크 테마 아이콘 PNG**의 사각형 바깥 검정색 매트 영역을 투명하게 변경했습니다.
   - 짙은 청록색 둥근 아이콘 내부 배경과 3D 로고 그림은 유지합니다.
   - `public/icons/dongjak-dark-{180,192,512,1024}.png` 네 개 파일을 갱신했습니다.
   - 기존 **라이트 테마 아이콘** 및 **iPhone 홈 화면용 아이콘**은 수정하지 않았습니다.
3. 모바일 글씨 크기 버튼의 큰 `가`와 작은 `가` 간격을 **3px → 2px**로 1px 줄였습니다.

## 검증

- `npm test`: 970/970 통과
- Chromium 모바일 뷰포트: 길찾기·교통정보 창의 열기/닫기 시 페이드 키프레임(투명도만)을 실제 브라우저에서 확인했습니다.
- PNG 알파값 확인: 각 다크 아이콘 모서리 알파=0, 중앙 알파=255.
- `npm run build`: 현 환경에서 Vite 미설치로 실행 불가(로컬에서 의존성 설치 후 확인 필요).

## 실행·배포 명령

```powershell
npm ci
npm test
npm run build
npm run dev
npm run deploy:pages
```

## 배포 후 확인

Safari/iPhone PWA 및 브라우저는 아이콘 이미지를 캐시할 수 있습니다. 배포 후 새로고침하고, 그래도 이전 검정 매트가 나타나면 사이트 데이터를 새로고침하거나 홈 화면 아이콘을 다시 추가해 확인하십시오. 다크 테마 아이콘과 iPhone 홈 화면용 아이콘은 별개입니다.
