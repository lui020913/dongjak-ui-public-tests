# v8.6.7 | 대중교통 창 열기·닫기 로직 재구성

기준: v8.6.6 FULL CLOSE_EVENT_FIX_INTEGRATED_20261115

## 문제
교통 상세창의 X 클릭은 여러 애니메이션·닫기 관리자를 거치며 synthetic click이 재생성되고, iOS에서 지도 아래쪽으로 같은 터치가 전달돼 창이 다시 등장했습니다.

## 수정
- `transport-window-lifecycle.js`의 단일 상태 관리자를 통해 교통 창 열기 및 닫기를 처리합니다.
- 지도 포인트 중복 이벤트를 같은 터치 기준으로 한 번만 허용합니다.
- iOS에서 X로 닫힌 뒤 바로 이어지는 지도 유령 클릭을 차단합니다 (700ms). 명시적인 즐겨찾기·이전역/다음역 동작은 유지합니다.
- `transport-close` 클릭은 교통 모듈이 직접 처리하며, 공통 애니메이션 관리자에서 가짜 클릭을 발생시키지 않습니다.
- 다른 UI 창이 열릴 때 기존 교통 창은 단일 dismiss 이벤트로 닫습니다.
- 기존 PC·모바일 CSS, 지도 스타일, 실시간 교통정보 API, 즐겨찾기, 온보딩은 수정하지 않습니다.

## 적용
`APPLY_PATCH.cmd` 또는 `APPLY_PATCH.ps1`로 v8.6.6 원본 폴더에 적용. 파일 SHA256 확인, 백업 수행. `npm` 명령은 사용하지 않았습니다.

## 검증
JS 구문 검사 및 Node 내장 테스트, 패치 전후 파일 해시·ZIP CRC 검증. 실제 iOS Safari와 프로덕션 빌드는 별도 기기 확인 필요.
