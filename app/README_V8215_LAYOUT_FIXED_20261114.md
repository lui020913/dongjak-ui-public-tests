# 동작구 보행안전 지도 v8.2.15 모바일 패널 구조 수정

기준 파일: DongjakApp_v8.2.15_FIXED.zip (v8.2.15)
제공 형태: 전체 통합본과 변경 파일 델타 패치

## 변경 내용
1. 길찾기·커뮤니티·동작구 소식·내 정보의 HTML 헤더 순서를 회색 손잡이 → 아이콘 → 제목 → X 버튼으로 통일했습니다. 오른쪽 X 버튼이 CSS 로딩 순서에만 의존하지 않습니다.
2. 모바일 공통 헤더 스타일의 소유자를 v829-mobile-layout-system.css 한 곳으로 정리했습니다. v833-home-sheet-layout.css는 높이/애니메이션만 담당하며 과거 중복 Grid 헤더 규칙은 제거했습니다.
3. 길찾기만 외곽 패딩 15px이 달라 헤더가 어긋나던 문제를 해결하고, 본문에만 별도 좌우 여백을 유지했습니다.
4. 과거 73dvh 및 61dvh 높이 규칙을 제거하고 모바일 메인 플로팅 패널은 최대 50dvh로 유지합니다. 긴 본문은 패널 내부에서 스크롤됩니다.
5. HTML에 실제 회색 손잡이 요소를 추가했습니다. 기존 dj-v8212-sheet-controller.js의 헤더 드래그 종료 이벤트를 그대로 사용합니다.
6. '내 정보'가 선택된 상태인데 패널이 숨겨진 경우, 다시 탭하면 재개방할 수 있도록 화면 전환의 가드 로직을 보강했습니다. 계정/Supabase 기능은 변경하지 않았습니다.

## 적용 및 테스트
- 패치 ZIP: 압축 해제 후 APPLY_PATCH.cmd 실행 → 기존 v8.2.15 프로젝트 루트 폴더 선택
- 적용기에서 기준 파일 SHA-256을 먼저 검사합니다. 서로 다른 최신 소스면 덮어쓰지 않고 중단합니다.
- 전체본 ZIP: 압축 해제하여 사용하며 별도의 패치는 적용할 필요 없습니다.
- 루트의 .env.local/.env.production.local 등 개인 설정 파일은 기존 PC 프로젝트에서 별도로 보존하십시오.
- VS Code 터미널에서 다음 순서로 확인하십시오.
  npm ci
  npm test
  npm run check:release
  npm run build
  npm run deploy:pages

주의: 이 패치는 카카오 로그인 서버 오류나 대중교통 API를 수정하지 않습니다. 인증 설정 실패를 해결했다고 주장하지 않습니다.
