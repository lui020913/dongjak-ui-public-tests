# 동작하는 안전지도 v8.6.0 — 최초 실행 온보딩

## 기준 버전

- 기준 전체 ZIP: `DongjakApp_FULL_v8.5.7_REQUESTED_UI_FIX_20261114(1).zip`
- 신규 버전: `8.6.0` (minor)
- 기존 `v857-requested-ux.js`, 지도 코어, 교통 코어, 인증·즐겨찾기 기능은 유지합니다.

## 반영 기능

- 지도 시작 로딩 화면이 정상적으로 닫힌 뒤, 최초 접속 사용자에게 5페이지 온보딩을 표시합니다.
- 5페이지 구성:
  1. 동작구 지도 소개
  2. 보행안전 정보와 안전시설
  3. 도보 경로 비교 및 GPS·음성 안내
  4. 버스·지하철 및 생활정보
  5. 카카오·이메일 로그인과 즐겨찾기
- 좌우 스와이프, 이전/다음, 페이지 점프, 키보드 방향키, 건너뛰기, 시작하기를 지원합니다.
- 닫기와 페이지 전환에 모션을 적용하고 `prefers-reduced-motion` 설정을 존중합니다.
- 라이트·다크 테마와 기존 한국어·영어 UI 언어 설정을 따릅니다.
- 최초 완료 상태는 `localStorage`의 `dongjak_onboarding_seen_v860`에 저장합니다.
- 더보기와 지도 조작 안내에서 다시 열 수 있습니다.
- 온보딩에서 로그인은 강제하지 않습니다. 로그인 관련 안내는 기존 내 정보 화면으로 연결합니다.

## 모바일 캡처 이미지 슬롯 5개

이번 통합본에는 실제 사진/캡처 이미지가 포함되지 않습니다. 기존 벡터 일러스트를 기본 화면으로 표시합니다. 추후 아래 파일을 기준으로 실제 모바일 캡처를 연결합니다.

| 순서 | 슬롯 | 파일 경로 | 설명 |
|---|---|---|---|
| 1 | `map-overview` | `public/onboarding/01-map-overview.png` | 메인 지도 화면 |
| 2 | `safety-layers` | `public/onboarding/02-safety-layers.png` | 보행안전 레이어 |
| 3 | `walking-route` | `public/onboarding/03-walking-route.png` | 도보 경로/내비게이션 |
| 4 | `local-discovery` | `public/onboarding/04-local-discovery.png` | 대중교통·생활시설 |
| 5 | `account-favorites` | `public/onboarding/05-account-favorites.png` | 로그인·즐겨찾기 |

권장 규격은 **1080 × 2340px, 세로 9:19.5, PNG**입니다. 실제 기기에서 캡처한 원본 화면을 사용하고, 개인정보는 캡처 전에 가려 주세요.

각 슬롯의 `src`는 `src/v860-onboarding.js`의 `ONBOARDING_IMAGE_SLOTS`에서 관리합니다. 사진을 연결하기 전까지는 `src`가 빈 문자열이므로 불필요한 404 요청이 발생하지 않고 기본 일러스트가 표시됩니다. 사진을 전달받으면 해당 슬롯의 `src`를 `/onboarding/파일명.png`로 연결하고 이미지를 `public/onboarding/`에 넣으면 됩니다. 사진이 로드되지 않으면 벡터 일러스트로 자동 복귀합니다.

## 최초 실행/재확인 QA

- 최초 실행: 지도 로딩이 종료된 다음 온보딩이 자동으로 열리는지 확인
- 건너뛰기/시작하기: 온보딩 종료 후 지도가 조작 가능한지 확인
- 재접속: 완료 상태가 저장되어 자동으로 다시 열리지 않는지 확인
- 다시 보기: 더보기와 지도 조작 안내의 `앱 처음부터 둘러보기` 동작 확인
- 모바일: 좌우 스와이프와 세로 스크롤이 서로 방해하지 않는지 확인
- PC: 마우스 드래그, 이전/다음, 페이지 점프, 키보드 방향키 확인
- 테마/언어: 라이트·다크 및 한국어·영어 전환 확인

테스트를 위해 최초 실행 상태로 되돌릴 때 브라우저 개발자 도구에서 다음을 실행합니다.

```js
localStorage.removeItem('dongjak_onboarding_seen_v860');
location.reload();
```
