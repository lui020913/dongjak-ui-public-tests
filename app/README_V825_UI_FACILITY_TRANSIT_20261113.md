# Dongjak 보행안전지도 v8.25.0 — 시설·대중교통 UI 개선

기준 프로젝트: `DongjakApp_FULL_v8.24.0_PRETENDARD_UI_VERSION_20261113.zip`

## 사용자 요청 반영

- **PC 시설정보:** 시설 팝업의 외곽 너비와 내부 내용의 고정 폭이 불일치해 생기던 넓은 빈 영역을 수정했습니다. 상세 정보, 주소·연락처, 기능 버튼, AI 설명을 팝업 폭에 맞췄습니다. 본문이 길어도 팝업 내부 스크롤로 접근할 수 있도록 했습니다.
- **개별 글꼴 계층:** Pretendard는 유지하되, 패널 제목·소제목·필드명·값·설명·보조정보·버튼마다 크기와 굵기를 구분했습니다. 불필요한 일괄 bold 규칙을 덮어썼습니다.
- **버스 도착정보:** PC 및 충분히 넓은 화면에는 4열, 모바일 폭 360~699px에는 2열, 더 좁은 화면에는 1열로 표시합니다. 좁은 화면에서 4열을 강제로 유지하면 가독성을 해쳐 반응형으로 처리했습니다.
- **닫기 X 아이콘:** 상충되는 이전 CSS 때문에 정렬이 어긋나거나 보이지 않던 버튼의 X를 중앙 배치했습니다.
- **대중교통 선택 마커:** 모바일에서 버스 정류장이나 지하철역을 선택하면 해당 위치의 실제 좌표에 선택 마커를 보여 주고, 열려 있는 바텀시트의 위쪽에 표시되도록 카메라 이동을 보정했습니다. 패널을 닫으면 마커가 사라집니다.
- **지하철 상행·하행:** 라이트와 다크모드에서 구분되는 차가운 파란색 및 따뜻한 황색 계열의 배경을 지정했습니다.
- **버전:** v8.25.0, 앱 화면/버전 파일/변경 내역 동기화.

## 검증 범위

- Node 회귀테스트: 1,058개 통과, 0개 실패.
- JS 문법 및 CSS 규칙 파싱 확인, 릴리스 버전 점검 통과.
- Chromium CSS 격리 렌더 검사: 시설 내용 폭, 상세 스크롤, PC/태블릿 버스 4열·모바일 2열, 닫기 X 표시 확인.
- 실제 지도 앱 전체 Vite 빌드 및 iOS PWA 실기기 통합 테스트는 완료하지 못했습니다. 이 환경에 Vite 의존성이 없어 `npm run build`가 중단됐습니다.

## 델타 패치 적용

1. 패치 ZIP을 별도 폴더에 압축 해제하십시오.
2. `APPLY_PATCH.cmd`를 실행해 v8.24.0 프로젝트 루트(`package.json` 위치)를 지정하십시오.
3. 원본 파일 SHA-256 검사 및 자동 백업 후 변경 파일을 덮어씁니다. 로컬 수정이 있으면 안전을 위해 중지합니다.
4. `npm ci`, `npm test`, `npm run check:release`, `npm run build`, `npm run dev`로 확인합니다.
5. 배포할 때만 `npm run deploy:pages`를 실행합니다. PWA 캐시로 과거 화면이 남으면 배포 후 새로고침/재실행하십시오.
6. 문제 시 `RESTORE_PATCH.cmd`를 실행해 백업본으로 되돌립니다.

**주의:** v8.24.0 전체 ZIP을 기준으로 제작했습니다. 다른 버전에 델타 ZIP을 직접 적용하지 마십시오. 전체 ZIP은 v8.25.0의 모든 파일이 포함된 별도 설치본입니다.
