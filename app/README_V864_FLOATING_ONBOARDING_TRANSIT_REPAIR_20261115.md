# 동작하는 안전지도 v8.6.4 — 플로팅 온보딩·교통 헤더·닫기 동작 보정

## 기준 버전
- 기준 프로젝트: `DongjakApp_FULL_v8.6.3_GUEST_ONBOARDING_INTEGRATED_20261114.zip`
- 통합 버전: `8.6.4`
- npm 설치·테스트·빌드는 요청에 따라 실행하지 않았습니다.

## 반영 사항
1. 모바일 앱 둘러보기를 전체 화면 점유형이 아닌 지도 위 중앙 플로팅 카드로 변경했습니다. 지도는 어두운 반투명 배경 뒤에서 가장자리로 보입니다.
2. 카드 버튼을 포함한 화면 전체에서 좌우 스와이프가 작동하도록 조정했습니다. 스와이프 동작 뒤 발생하는 합성 클릭만 억제해 버튼 오작동을 방지합니다.
3. iPhone 설치와 지도 이용 TIP 펼치기/접기 높이·투명도 애니메이션을 적용하고 화살표 모양을 통일했습니다.
4. 최근 업데이트 버전과 전체 업데이트 내역 버튼을 같은 박스의 좌우에 배치했습니다.
5. 지도 조작 안내를 닫을 때 자동 안내 타이머를 취소하고 세션 표시를 확정합니다. 온보딩의 시작하기는 합성 클릭 대신 단일 이벤트로 안내창을 엽니다.
6. 지하철역명 글자 크기와 호선 배지 간격을 확대하고 출발·도착 버튼을 텍스트로 변경했습니다. 즐겨찾기·공유·출발·도착 버튼의 중앙 정렬과 색상을 통일했습니다.
7. 지하철 이전역/다음역과 헤더 사이의 중복 구분선 중 하단선을 제거했습니다.
8. 버스정류장 유형·정류장명·ARS를 세로로 넉넉하게 배치하고 액션 버튼을 두 번째 줄에 정렬했습니다.
9. 버스 도착 카드 두 개를 한 줄에 배치하고 좌측에 노선·행선지, 우측에 도착 또는 운행 상태를 표시합니다.
10. 교통정보 헤더의 비대화형 영역을 드래그해 내릴 수 있으며, 버튼 탭은 그대로 유지합니다.
11. 지하철·버스 X 닫기 후 개요 플로팅 창을 자동으로 다시 띄우지 않습니다.
12. 지도 TIP 알약바의 라벨 간격을 줄이고 문구 오른쪽 끝에도 여백을 확보해 문구가 여백 안에서만 움직이도록 했습니다.

- 안내창 단일 이벤트 수신기의 `window` 참조 오류를 수정했습니다. 안내창 초기화 중 발생할 수 있던 `ReferenceError`를 방지합니다.
