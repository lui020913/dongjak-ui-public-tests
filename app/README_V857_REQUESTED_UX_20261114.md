# 동작하는 안전지도 v8.5.7 — PC/모바일 미반영 UI 수정

기준 전체본: `DongjakApp_FULL_v8.5.6_UI_COMPLETION_INTEGRATED_20261114.zip`
목표 버전: `v8.5.7`

## 이번 수정 범위

### PC 버전
- 700px 이상 마우스·트랙패드 환경에 공통 3열 헤더(앱 로고 / 검색창 / 유틸리티)를 적용했습니다.
- 검색창은 최대 560px로 제한하고, 우측 설정·테마·버전·날씨 영역은 고정 폭을 유지해 애매한 창 너비에서 서로 겹치지 않게 했습니다.
- 700~899px, 900~1279px, 1280px 이상 구간별로 날씨·버전 버튼을 단계적으로 축약했습니다.
- 모바일 툴바·더보기 패널·구형 지도 옵션 버튼이 PC 화면에 잔류하지 않도록 숨김 및 레거시 제거 동작을 보강했습니다.
- 안전지도 탭을 PC 내비게이션 첫 번째 위치로 유지하고, 좌측 지도 도구 버튼의 높이·아이콘·글씨 규격을 통일했습니다.

### 모바일 공통 창 / 행정동 선택
- 안전지도 하단 탭은 지도 화면만 전환하도록 했습니다. 행정동 선택 창은 하단 탭 클릭으로 열리지 않으며, 이미 열려 있으면 탭 클릭 시 닫힙니다.
- 길찾기·커뮤니티·동작 소식·내 정보 등 하단 탭 창은 아래에서 올라오는 진입 애니메이션을 유지합니다.
- 각 창 상단에 전용 23~24px 드래그 가장자리 영역을 사용하고, 아래로 끌면 창이 따라 내려가며 임계 거리/속도에서 닫히도록 기존 시트 컨트롤러와 연결했습니다.

### 지도·더보기·안내·검색
- 노들섬 아이콘과 '노들섬' 지명을 독립 MapLibre 심볼 레이어로 분리했습니다. 아이콘 스프라이트 또는 아이콘 배치 문제로 지명까지 사라지지 않도록 했습니다.
- 모바일 상단의 별도 지도 옵션 버튼은 제거하고, 더보기 버튼에 지도 옵션 슬라이더 아이콘을 적용했습니다.
- 더보기 헤더·닫기 SVG·본문 스크롤·빠른 작업 버튼의 터치 영역을 정리했습니다.
- 업데이트 내역, 지도 설정, 글자 크기·굵기 설정 패널이 더보기 패널보다 위에 표시되도록 레이어 순서를 보정했습니다.
- 지도 안내창의 iPhone 설치 단계가 카드 안에서 잘리지 않도록 세부 콘텐츠 높이와 스크롤을 수정하고 아이콘·닫기 버튼 크기를 통일했습니다.
- 검색 추천창을 화면 좌우 12px 여백까지 넓히고 시각적 뷰포트에 맞춰 배치했습니다. 검색 입력에는 iOS 검색 키보드 힌트를 지정했습니다.

### 시설·교통 정보창
- 시설 상세창은 제목을 좌측에 두고 출발·도착·즐겨찾기·공유·닫기 동작을 우측 한 줄의 그룹으로 유지하도록 수정했습니다. 그룹을 `display:contents`로 분해하던 규칙을 제거해 즐겨찾기와 공유 버튼이 아래 행으로 밀리지 않게 했습니다.
- 시설 상세창 상단 전용 가장자리 드래그로 아래로 끌어 닫을 수 있습니다.
- 지하철역 상세창은 즐겨찾기 아이콘, 출발·도착 버튼 글씨 크기, 이전역·다음역 간격, 블러 제거 규칙을 적용했습니다.
- 버스정류장 상세창은 긴 정류장명이 세로로 찌그러지지 않도록 제목을 첫 행에 배치하고 출발·도착·즐겨찾기·닫기를 두 번째 행에 배치했습니다.
- 버스 도착 카드 안의 노선·방향·도착 문구를 가운데 정렬했습니다.
- 지하철역·버스정류장 창 모두 상단 전용 가장자리 드래그로 닫을 수 있도록 공통 시트 컨트롤러와 연결했습니다.

### 프로필
- 저장 버튼의 문구를 '변경사항 저장' / '이름 저장'으로 바꿔 동작을 명확히 했습니다.
- 저장 완료 알림을 버튼처럼 보이는 녹색 토스트 대신 화면 읽기 기능이 지원되는 비상호작용 인라인 상태 문구로 바꿨습니다.

## iOS 키보드 보조 막대 관련 제한
검색창 포커스 시 스크린샷에 보이는 위·아래 화살표와 체크 표시가 있는 회색 입력 보조 막대는 iOS Safari가 제공하는 시스템 키보드 UI입니다. 웹앱 CSS나 PWA 코드로 강제 제거할 수 없습니다. 앱이 자체적으로 띄우는 회색 오버레이·블러는 제거했고, 입력에는 `enterkeyhint="search"`, `autocapitalize="off"`, `spellcheck="false"`를 적용했습니다.
