1. 업데이트 내역·도로폭·지도 옵션·행정동·검색 결과 등 주요 닫기 버튼을 **단일 SVG X**로 표시합니다. 과거 CSS의 중복 `::before/::after` 아이콘은 숨깁니다.
2. PC의 보행안전 도구는 iPhone 설정 화면처럼 **왼쪽 대분류 5개, 오른쪽 선택 분류의 세부 항목** 구조로 배치합니다. 기존 레이어 제어·안전 데이터 및 이벤트는 재사용합니다. 모바일에서는 기존 세로형 UI를 유지합니다.

4. 다크모드 행정동 선택창의 배경·글씨·버튼을 다크 테마에 맞게 조정했습니다.
5. 최신 수정 기록을 **v8.0.3 최신 패치** 항목으로 업데이트 내역 맨 위에 추가했습니다. 과거 기록은 삭제하지 않고 원본 보존합니다.
6. 모바일 업데이트 내역 창의 최대 높이와 하단 위치를 하단 탭과 분리합니다. 중복된 접이식 '지도 데이터 출처' 박스는 숨기고 기존 화면 내 '데이터 출처' 탭은 그대로 제공합니다.
7. 검색 버튼을 눌렀을 때 검색 함수를 직접 호출하도록 수정했습니다. 로컬에서 검증된 대학·공공시설·지하철 위치를 즉시 표시하며, 외부 장소 검색 결과는 응답을 받을 때 합쳐 표시합니다. 선택 시 지도 이동은 기존 원본 코드를 유지합니다.

## 실행·배포

새 폴더에 전체 ZIP을 압축 해제하거나, 직전 988개 통과본 프로젝트에만 패치를 적용하십시오.

```powershell
npm ci
npm test
npm run build
npm run dev
```

Cloudflare Pages 프리뷰 배포는 빌드 성공 후:

```powershell
npm run deploy:pages
```
