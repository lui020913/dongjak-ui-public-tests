# 동작하는 안전지도 v8.7.8 — 안정화 1차

기준: v8.7.7 전체본. 신규 UI 기능을 추가하지 않고 기존 창 관리 충돌을 줄입니다.

## 반영 범위
- 안전지도 홈 탭의 기존 더블탭 제어와 새 홈 이동 제어가 동시에 실행되지 않도록 소유권 구분 (`safety-home-guard.js`, `v833-home-reset.js`)
- 지도 옵션/보행안전 창을 다른 화면 때문에 닫을 때 배경 차단 레이어, ARIA, 종료 애니메이션 상태를 함께 정리 (`window-surface-cleanup.js`, `v806-unified-ui.js`)
- iOS PWA 복귀 및 WebGL 복원 직후 렌더링 재개, 불필요하게 남는 재시도 타이머 정리 (`v875-map-resume.js`)
- 신규 동작 회귀 테스트 5개 (`tests/v878-stability-phase1.test.mjs`)

## 검증
- 전체 Node 자동 테스트: 1,422 / 1,447 통과; 기존 v8.7.7의 25개 실패와 실패 항목 동일
- 신규 집중 테스트: 5 / 5 통과
- JavaScript 구문 검사, 릴리스 버전 정합성 검사 통과
- 실제 iPhone의 WebGL 강제 중단 복귀 및 온라인 API 전 구간은 미검증
- npm 설치·빌드 생략

## 다음 단계
기존 테스트 실패 항목을 실제 기능 이상·구형 스냅샷 기준으로 분류하고, 각 창의 통합 브라우저 테스트와 반응형 충돌 점검을 계속할 필요가 있습니다. 이 배포본을 전체 리팩터링 완료로 간주하지 마세요.
