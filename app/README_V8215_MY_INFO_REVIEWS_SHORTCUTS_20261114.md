# 동작하는 안전지도 v8.2.15 — 내 정보·시설 리뷰·상단 바로가기

기준: `DongjakApp_FULL_v8.2.14_UI_KAKAO_PRIORITY_SAFE_MERGED_20261114.zip`

## 적용 사항

- 지도 원형 버튼의 확장 폭을 문구 길이로 측정해 조정. 짧은 버튼의 불필요한 여백 축소
- 더보기에서 `밖으로` 버튼 및 하단의 중복 편집 목록 삭제. 모든 기능을 한눈에 표시하고 각 기능의 `상단 표시` 토글로 관리
- 모바일 하단 `내 기록` → `내 정보`로 변경. 프로필·지도와 이동·테마/글자 설정·즐겨찾기 메뉴를 설정 카드 UI로 구성
- 기존 Supabase/Kakao 계정센터의 로그인, 이름 수정, 비밀번호 및 연결 계정 기능을 그대로 연결
- 일반 시설 정보 팝업에 `리뷰 작성`, 1~5점, 5~800자, 저장 및 재조회 기능 추가

## 시설 리뷰 데이터 공유

기본값은 기기 내 저장입니다. 로그인하지 않았거나 Supabase 리뷰 테이블이 없을 때에는 다른 사용자가 리뷰를 볼 수 없으며, 화면에도 '이 기기에만 저장됨'이라고 표시합니다.

**로그인한 사용자끼리 공개 리뷰를 공유하려면** 기존 프로젝트 Supabase의 SQL Editor에서 `supabase/place_reviews.sql`을 한 번 실행하세요. 테이블 생성 및 Row Level Security 정책 설정 후 카카오/이메일 로그인 계정에서 작성한 리뷰가 Supabase에 저장되고, 다른 사용자가 읽을 수 있습니다. 비로그인 이용자는 로그인 없이도 로컬 리뷰를 작성할 수 있으나 공개 서버에는 올라가지 않습니다.

새 API 키나 서비스 역할 키를 앱 소스에 넣지 마세요. 기존 로그인 설정을 그대로 사용합니다. 일반 시설 상세 팝업에서 작성할 수 있으며 버스/지하철의 별도 도착정보 패널은 이번 패치 대상이 아닙니다.
