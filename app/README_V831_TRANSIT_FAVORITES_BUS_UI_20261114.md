# 동작구 보행안전 지도 v8.3.1 — 교통정보 즐겨찾기·버스 노선 색상·하단 패널 패치

## 기준과 버전
- 기준 원본: `DongjakApp_FULL_v8.3.0_SEMVER_RELEASE_MANAGEMENT_20261114(1).zip`
- 적용 릴리스: **v8.3.1 (Patch)** — v8.3.0의 SemVer 정책에 따라 기능 동작·UI 보정으로 분류
- 구형 v8.2.15 패치의 HTML을 그대로 덮어쓰지 않고, v8.3.0의 소스를 보존하면서 CSS/JS 연결만 병합

## 반영 내용
1. 대중교통 즐겨찾기의 버튼 글자를 단순 별표로 표시하고, 미로그인 시 저장 대신 애니메이션 로그인 안내창 표시
2. 로그인 안내에서 카카오 간편로그인과 기존 내 정보/회원가입 경로로 이동 가능
3. 시설정보 '장소 저장'도 로그인 요구. 기존 계정·저장 데이터 삭제 없음
4. 버스 정류장명과 ARS 정보를 왼쪽에 정렬하고 출발·도착·즐겨찾기를 닫기 X 왼쪽에 배치
5. 노선 유형이 분류되는 버스 번호 배경에 간선·지선·마을·광역·공항·순환·심야 색상 적용. 불명확한 유형은 중립색 처리
6. 보조 글씨 크기 소폭 확대, 대중교통 패널 상단 손잡이에서 아래로 스와이프해 닫기 지원

## 보존 범위
- v8.3.0의 주요 UI/지하철·버스 API/카카오·Supabase 클라이언트/경로안내/지도 소스 유지
- 기존 SemVer 메이저·마이너·패치 명령과 버전 체크 유지
- 로그인 여부는 기존 Supabase 세션을 조회하며 카카오 키 또는 Client Secret을 포함하지 않음
