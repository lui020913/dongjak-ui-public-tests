# 동작하는 안전지도 v8.2.3 — 모바일 길찾기 닫기 버튼·경로 찾기 버튼 수정

기준: v8.2.2 전체 통합본 (카카오 로그인·기존 즐겨찾기 보존).

## 변경 사항

- 모바일 길찾기 헤더에 제목/닫기 버튼 독립 그리드 열 적용. 닫기 버튼은 우상단 고정, 다른 레이아웃 CSS로 인해 좌측으로 이동하지 않도록 런타임에서도 위치 속성 확정.
- 경로 계산 버튼 `#route-calc`를 경유지 편집 UI보다 먼저 표시. 출발지·목적지 바로 아래에서 찾을 수 있도록 변경.
- 길찾기 패널 `overflow:hidden` 강제 규칙을 해제하고 모바일 최대 높이 내 내부 스크롤 허용. iPhone 화면 높이가 작거나 확대 시에도 하단 기능 접근 가능.
- 기존 `data-close-page` 클릭 이벤트, 실제 길찾기 계산·GPS, 교통정보, 즐겨찾기, Supabase, Kakao OAuth는 변경하지 않음.
- 업데이트 내역 및 버전 표기를 v8.2.3으로 동기화.

## 설치

**전체본:** 새 폴더에 압축 해제합니다. 기존 `.env.local` / `.env.production.local`과 개인 설정은 새 프로젝트에 필요한 경우 따로 이전하십시오. 민감한 키는 ZIP에 포함하지 않았습니다.

**패치:** 직전 v8.2.2 전체본에 한해 `APPLY_PATCH.cmd`를 실행하고 프로젝트 경로를 입력하세요. 적용 전에 기준 버전과 변경 대상 파일을 검사하고, 원본은 프로젝트 밖 백업 폴더에 보관합니다.

```powershell
npm ci
npm test
npm run check:release
npm run build
npm run deploy:pages
```

## 검증 범위

- Node.js 자동 테스트 1,093개 통과.
- Chromium 정적 DOM + 프로젝트 전체 CSS 검사: 모바일 320×568, 375×667, 390×844, 430×932, PC 1206×800. 닫기 버튼을 헤더 우상단에 표시하고, 경로 계산 버튼이 첫 화면에 노출되는 좌표 확인.
- 실제 MapLibre 지도/서버와 함께 실행한 iPhone Safari·PWA 동작은 미검증. 실행 환경에 Vite가 설치되어 있지 않아 `npm run build` 완료 못 함.

배포 후 구버전 화면이 남아 있으면 모바일 PWA를 완전히 종료하고 다시 열거나 배포된 버전 표시를 확인하세요. `npm run deploy:pages`는 빌드와 배포를 모두 수행합니다.
