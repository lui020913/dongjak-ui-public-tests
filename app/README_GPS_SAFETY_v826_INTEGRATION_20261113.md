# 동작하는 안전지도 v8.2.6 — GPS 위치 기반 보행안전 안내 통합

## 기준과 보존

- **실제 기준 프로젝트:** `DongjakApp_FULL_v8.2.5_WALK_NAVIGATION_ROUTE_CHOICES_20261113(1).zip`
- 앱 버전 **8.2.5 → 8.2.6** (프로젝트의 `scripts/bump-app-version.mjs` 사용)
- 기존 보행경로 비교, 내비게이션, GPS 지도 마커, 음성/진동, 대중교통, 계정 및 모든 지도 데이터를 유지했습니다.
- `src/main.js`, `src/v825-navigation-experience.js` 및 지도 관련 기존 CSS를 변경하지 않았습니다.

## 사용 절차

1. 지도 화면의 **현재 위치(타깃 모양)** 버튼을 누릅니다. 기존 자동 추적 기능이 시작/유지됩니다.
2. 별도 보행안전 요약 패널이 표시되고, 권한 부여 후 GPS 좌표와 안전정보를 분석합니다.
3. 사고다발지역과 등록 횡단 지점이 100m 범위 내에 있는지 **직선거리 기준**으로 안내합니다. 안전등급 인증이 아닙니다.
4. 현지 기기시간 **18:00~06:00**에는 CCTV/가로등/보안등 등록 위치 및 주변 도로 경사 참고정보가 추가됩니다.
5. **위치 다시 조회**로 갱신하고, X·다른 탭 이동·위치추적 종료 시 닫힙니다. GPS 보행 내비게이션 중에는 경로 안내창을 가리지 않도록 팝업을 열지 않습니다.

## UI·UX 구성

- **PC:** 오른쪽 독립 패널(최대 452px), 일정 높이 내 내부 스크롤, 우측 상단 중앙 정렬 X.
- **모바일:** 하단 메뉴의 실제 화면 위치를 기준으로 바로 위에 표시, 화면 높이의 최대 43% 및 내부 스크롤. 지도 중앙의 GPS 마커가 가려지지 않도록 함.
- 현재 위치의 상태, 가장 가까운 횡단 후보, 사고다발 정보가 먼저 나오는 요약형 정보 계층. 야간 상세내용 및 동서남북 후보는 아래에서 스크롤해 확인.
- 라이트/다크 테마, 기존 Pretendard 폰트 및 앱 설정의 글자 크기(작게/기본/크게)를 따름.
- 키보드 Escape, 닫기 버튼, 모달 설명, 키보드 포커스 복귀에 대응.

## 사용 데이터와 오해 방지

| 자료 | 용도 | 제한 |
|---|---|---|
| 상도1동 팀 조사 횡단 후보 41곳 | 가까운 후보 직선거리·방향 | 후보 현장 미검증, 전체 횡단보도 목록 아님 |
| 상도1동 OSM 참고 경계 | 시범 조사영역 판단 | 법정 행정경계 아님 |
| 동작구 보행자 사고다발지역 통계면 | 통계상 포함 여부 | 실시간 사고·법정 위험 판정 아님 |
| 공개 보호구역 일부 경계 | 자료상 포함 여부 | 실제 지정 범위 전체 포괄 아님 |
| CCTV 등록 위치 | 가까운 CCTV 추정 위치 | 정상 작동 여부 미확인 |
| 가로등/보안등 등록 위치 | 조명 설치 후보 위치 | 현장 조도·점등 상태 아님 |
| 도로 경사도 계산 추정자료 | 인근 경사 추정 | 단일 도로·이동방향의 실제 구배가 아닐 수 있음 |

자료 미수신, 현재 위치 오차가 100m를 넘는 경우 안전·위험을 임의로 확정하지 않습니다. 100m는 실제 시야(가시거리)가 아니라 등록 후보까지의 직선거리이며 법적 기준이 아닙니다. 출처 확인이 불가능한 연간 전국 사고 건수, 실시간 유동인구, AED·비상벨·안심지킴이집 위치를 만들어 표시하지 않습니다.
