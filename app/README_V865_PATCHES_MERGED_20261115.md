## 충돌 처리
- 기존 전체본의 v8.6.3 게스트 온보딩과 v8.6.4 플로팅 온보딩, 애니메이션, 교통 수정 모듈과 지도 안내의 `<details>` 구조는 유지했습니다.
- 이전 패치 ZIP의 `index.html`, `package.json`, 잠금파일, 버전 JSON, 전체 릴리스 기록을 통째로 덮어쓰지 않고 신규 모듈과 필요한 코드만 이식했습니다.
- PC 전용 CSS는 1080px 이상, 중간 화면은 700~1079px, 모바일 시설 UI는 699px 이하로 분리했습니다.
- 구버전 검색 추천창이 지정한 `translate:-50% 0`와 충돌하지 않도록 PC/태블릿 검색 추천창의 translate를 원점으로 보정했습니다.
- 기존 패치의 야간시야 `render()` 내부 중복 click listener는 적용하지 않고 독립적인 세션 가드에서 한 번만 처리하도록 유지했습니다.
- 기존 v8.6.4 대중교통 렌더러에 이미 있는 공유 버튼을 재사용합니다. 이전 패치의 별도 공유 버튼 생성기를 추가하지 않아 중복 ID와 이벤트 중복을 방지합니다.
- 원본의 인증 설정, 사용자 데이터, 환경변수는 수정하지 않았습니다.

## 검증 범위
- npm 명령은 **사용자 요청에 따라 일절 실행하지 않았습니다.**
- ZIP 엔트리 및 무결성 확인, Node JS 구문 검사와 내장 node:test 정적·일부 단위 검사 수행(별도 결과 참고).
- Vite 빌드, iOS Safari/실제 지도 렌더링과 API 통신은 확인하지 못했습니다.
