# 동작구 보행안전 지도 — v8.0.3 최신본 통합 패치 (v820 호환)

## 적용 기준

- **정확한 기준 파일:** `DongjakApp_CLEAN_LATEST(20261113-060112).zip`
- **포함 패치:** `Four_WalkSafety_Functions`, `Map_App_Phase1_Phase2`, `Navigation_TTS_Male_Female_VoicePicker` (2026-11-13 업로드된 세 파일)
- **버전:** 앱 package.json `8.0.3` 유지; `v820`은 이번 세 패치 통합/UX 호환 작업 식별자입니다.
- 최신본에 이미 반영된 v819 PC 한 화면 보행도구, 글꼴, 애니메이션, 모바일 상세 UI, iOS 홈 화면 아이콘, 안전 레이어 및 지하철·버스 API 코드를 보존했습니다.

## 반영 기능

1. 보행경로 **일반·경사 회피** 실제 경로 결과 비교 (추정 상승량, 사고다발 선정기록 주변점 근접 정보)
2. 보행 내비게이션 **GPS 정확도**, 기기 지원 시 **진동 안내·화면 켜짐 유지** (명시적으로 켜야 함)
3. **날씨 보행정보** (Open-Meteo, 동작구 대표값, 관측시각 확인)
4. **보행안전 자료현황 리포트** (동작구/상도1동, 인쇄→PDF, HTML 파일)
5. 장소 빠른 카테고리 검색·현재 지도 범위 필터·최근 검색·기기 내 장소 저장/폴더/공유
6. 도보 경유지 최대 5곳, 순서 변경, **실제 보행경로 구간 합산**, 지하철 연계 참고 이동안
7. 브라우저 TTS에서 **기본·여성·남성·전체 한국어 목소리 선택**, 미리듣기
8. **UI 통합:** 새로운 날씨·리포트 도구는 보행도구 내 접기/펼치기 그룹으로 통합해 PC 화면 높이를 보존; 모바일·다크모드 보완

## 중요 기능적 제한

- **지하철 연계 참고안은 실제 열차 운행·환승시간표가 아닙니다.** 버스 환승 경로는 이 통합본에 없습니다.
- 경사/사고 선정지점 근접/날씨는 보행 안전 인증·공식 위험등급이 아닙니다.
- 경유지 포함 GPS 안내는 **자동 경로 재탐색을 제한**했습니다. 다른 지점을 건너뛰고 목적지로 직행하는 위험을 막기 위한 조치입니다. 경로에서 벗어나면 안내 종료 후 재계산하세요.
- 남녀 TTS 분류는 기기 음성 이름을 통한 **추정**입니다. Web Speech API는 성별 정보 필드를 제공하지 않습니다.
- 데이터·지도·폰트 일부는 인터넷 연결이나 Cloudflare Functions/Secret을 필요로 합니다.
- 저장한 장소/최근 검색은 **이 브라우저의 로컬스토리지에만** 보관됩니다.

## Windows / VS Code — 전체 ZIP을 사용할 때

1. 전체 ZIP을 `C:\DongjakApp\DongjakApp_Integrated` 같은 새 폴더에 압축 풉니다.
2. VS Code에서 **`package.json`이 있는 폴더**를 엽니다.
3. 터미널(PowerShell)에서 다음을 실행합니다.

```powershell
npm ci
npm test
npm run build
npm run dev
```

- `npm test`의 일부 오래된 테스트는 *원본 `src/main.js`의 SHA가 절대 달라지면 안 된다*고 검사합니다. 경유지/음성안내 기능을 메인 경로 엔진에 연결하기 때문에 그 검사는 구버전 전제이며 실패할 수 있습니다. 새 통합 회귀검사 `tests/v820-integrated-patches.test.mjs` 및 기능별 테스트를 함께 확인하세요.
- `npm run build` 후 `dist`가 새로 생성됩니다. 구버전 `dist`/`build`/`.wrangler`는 오래된 빌드 아티팩트이므로 통합 ZIP에서 제외했습니다.
- 배포: `npm run deploy:pages` (현재 Wrangler 로그인/권한과 프로젝트 설정 필요), 고정 사이트 `https://dongjak-walk-safety-preview.pages.dev/`.
- 실제 테스트: PC/모바일 320·390·1440px, 검색 제안/클릭, 경유지 추가·삭제, 음성 미리듣기, GPS 정확도, 날씨 실시간 값, 리포트 인쇄, 지도로드/API/콘솔 오류 확인.

## Windows / VS Code — 소용량 패치 ZIP을 사용할 때

1. **기존 원본을 안전한 폴더에 별도로 백업**합니다.
2. 델타 패치 ZIP 압축해제 후 `APPLY_PATCH.cmd`를 실행합니다.
3. `package.json`이 있는 위의 **정확한 20261113-060112 원본 프로젝트 경로**를 입력합니다.
4. 원본 파일 SHA-256이 일치할 때만 변경 파일을 백업하고 적용합니다. 같은 8.0.3이라도 다른 수정본은 거부됩니다.
5. 원본 백업 폴더는 `.patch_backups\v820-threepatches-...` 입니다. 되돌릴 때는 `RESTORE_PATCH.cmd`를 실행합니다.

**주의:** 세 개의 이전 패치를 다시 덮어쓰면 기존 UI가 손실됩니다. 이번 통합 패치 하나만 적용하세요.

## 검증 상태 (현재 실행환경)

- 새로운 통합 UI·기능 검사 `v820` 5/5 통과, TTS 4/4 통과, 4종 기능 검사 8/9 통과(1건은 의도적인 메인 파일 변경에 대한 구버전 SHA 테스트).
- 전체 테스트에는 기존 패치의 SHA-256 불변조건 검사 실패가 존재합니다. 기존 테스트를 숨기거나 삭제하지 않았습니다.
- JavaScript 주요 파일 문법검사 통과.

- Cloudflare 배포와 GPS/TTS/인쇄 기능의 **실기기 작동은 미검증**입니다.
