# 동작하는 안전지도 v7.13.0 – PC·모바일 정보창 및 교통 UI

기준 원본: `DongjakApp_FULL_v7.12.0_PC_MOBILE_UX_FIXED_20261112.zip`

## 적용 내용
- **PC/iOS/Android:** 검색창과 별도 앱 아이콘을 눌렀을 때 현재 앱 버전과 업데이트 내역을 제공하는 애니메이션 앱 정보창을 표시합니다.
- **모바일 더보기:** 날씨 설명을 제거하고 `전체 업데이트 내역`, `지도 설정` 두 개만 제공합니다. 원형 온도 버튼은 지도 상단 도구에 유지합니다.
- **다크모드 설정:** 앱 정보창과 설정창에 테마별 표면색을 적용했습니다. 설정창의 글씨 크기·움직임 줄이기·날씨·지도 조작 버튼은 기존 localStorage 저장 기능을 유지합니다.
- **버스/지하철 교통 패널:** 정보창이 열린 동안 오른쪽 모바일 지도 조작 버튼이 중복 표시되지 않습니다. 실시간·시간표 탭을 동일한 분할 버튼 디자인으로 맞추고, 작은 화면에 맞춘 크기·스크롤·고정 제목을 적용합니다.
- **폰트:** 모바일과 PC의 메뉴·탭·본문 글꼴 크기와 굵기를 분리해 통일합니다.
- **iOS Safari 첫 실행:** 홈 화면 앱이 아닌 iPhone Safari 접속에서는 공유 > 홈 화면에 추가 안내를 보여줍니다.
- **iOS PWA 전환:** 테마 변경 후 기존 700ms 고정 재시작 대기를 150ms로 줄였습니다. 실제 전체 로딩 시간은 지도·네트워크·기기 성능에 좌우됩니다.

## 제외 및 유의사항
- 원본 지도 엔진(`src/main.js`), 교통 API 응답 처리(`src/transport-map.js`), 야간 시야 분석과 공공데이터는 수정하지 않았습니다.
- 지도 타일 실렌더링, 실시간 버스/지하철 API, iOS PWA·Android 실기기 동작 검증은 별도입니다.
- 기존 앱 저장된 설정을 초기화하거나 브라우저 데이터를 지우지 않습니다.

## 실행
```powershell
npm ci
npm test
npm run build
npm run dev
```

기존 Cloudflare 프로젝트 배포는 로컬 검증 후 `npm run deploy:pages`를 사용합니다.
