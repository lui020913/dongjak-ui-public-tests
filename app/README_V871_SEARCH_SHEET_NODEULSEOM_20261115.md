# v8.7.1 검색 추천창·시트 드래그·노들섬 표시 보강

- 기준: v8.7.0 전체 통합본
- 모바일 검색 결과를 상단 검색칸의 좁은 부모 박스에서 분리하고 #app 하위의 별도 오버레이로 이동합니다. 태블릿/PC에서는 원래 부모로 되돌립니다.
- 검색 추천창 진입·종료는 220/180ms 페이드로 전환하고 키보드 가시영역에 맞게 높이를 자동 조절합니다.
- 모바일 공통 시트는 헤더에서 위로 밀어 펼치고 아래로 밀어 접거나 닫습니다. 내용 스크롤과 버튼은 기존 이벤트 유지합니다.
- 노들섬: 확인된 지도 좌표와 시설정보 레코드를 재사용하여 클릭 상세 팝업을 열고, 지도 아이콘 이미지가 누락될 때 원형 대체 마커를 표시합니다.
- iOS 키보드 위의 회색 입력 도구 막대는 OS의 키보드 액세서리 화면으로 웹사이트 CSS/JavaScript가 제거할 수 없습니다.
- npm 실행/빌드는 요청에 따라 생략했습니다. 정적/통합 테스트는 별도 기록을 참조하세요.
