# V814 — 한 번에 하나의 플로팅 창만 표시

기준: `DongjakApp_FULL_v8.0.3_FADE_VISIBLE_973PASS_20261113.zip`

## 변경 내용

- `src/v806-unified-ui.js`의 기존 애니메이션·가시성 관리자를 **단일 창 활성화 관리자**로 확장했습니다.
- 지도 옵션, 보행안전, 도로폭, 야간 시야, 설정, 업데이트, 행정동, 도보 길찾기, 교통정보, 내 기록, 동작 소식, 보행 도구 및 MapLibre 시설 팝업 등 **주요 플로팅 창을 배타적으로 표시**합니다.
- 새 창을 열면 기존 창은 원래 표시 상태(`hidden`, 앱 클래스 등)를 변경하여 닫습니다. 다른 창 위에 단순히 겹치거나 CSS로만 숨기지 않습니다.
- 알려진 열기 버튼은 **클릭 캡처 단계**에서 기존 창을 닫고, 비동기 콜백에서 열리는 창은 `MutationObserver`로 **다음 렌더링 전에** 정리합니다.
- 교통정보창은 원래 닫기 버튼의 처리 로직을 호출해 선택 상태와 비동기 조회를 정리합니다. 도로폭 창은 기존 토글 버튼의 닫기 처리를 이용합니다.
- MapLibre 지도 시설 팝업 또한 다른 주요 창과 동시에 표시되지 않으며, 팝업이 여러 개 등록되면 마지막 팝업만 남습니다.
- `src/v800-ui-architecture.js`의 오래된 중복 관리자는 새 단일 관리자 사용 중 별도 배타적 닫기를 실행하지 않게 했습니다.
- 이전에 요청하신 **페이드 애니메이션(열기 320ms / 닫기 220ms)**, 라이트·다크·iPhone 홈화면 아이콘 분리, 지도 데이터 및 교통 API는 보존했습니다.

## 적용 방법

전체 ZIP은 새 폴더에 압축을 풉니다.
소용량 패치는 **정확히 위 973개 테스트 통과본**에만 적용합니다. `APPLY_PATCH.cmd`를 실행해 기존 프로젝트 경로를 지정합니다. 원본 파일의 SHA-256을 확인한 후 변경 파일을 백업·덮어쓰기합니다.

```powershell
npm ci
npm test
npm run build
npm run dev
```

Cloudflare Pages에 배포한 사이트는 새 프로젝트 파일을 배포해야 갱신됩니다.
