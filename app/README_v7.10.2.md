# 동작구 보행안전 지도 v7.10.2 (모바일 단일 플로팅·테마 전환)

기준 버전: **v7.10.1 전용**. 다른 버전에 패치를 직접 적용하지 마세요.

- 안전지도 탭에서 **기존 안전정보 안내창과 행정동 선택창이 동시에 열리는 문제 수정**: 행정동 선택창만 유지
- 길찾기·커뮤니티·동작 소식·내 기록 창 높이를 **43dvh(최대 480px)**로 축소
- 각 플로팅 창 **고정 제목·X 버튼 유지**, 아래 본문만 스크롤
- iOS 홈 화면 PWA의 상단 웹 배경을 라이트/다크 모드에 맞게 지정하고 색상 체계 힌트 동기화
- 모바일 테마 전환 시 **14px 블러**와 가운데 `테마 전환 중…` 문구 제공
- PC Chromium·Android 공통 지도 코어는 건드리지 않음

적용 방법: 이 패치 ZIP을 별도 폴더에 압축 해제 후 `APPLY_PATCH.cmd` 실행 → 기존 v7.10.1 프로젝트 폴더를 입력합니다.
해시가 불일치하면 적용 전에 중단하며 이전 파일은 `patch-backups` 아래에 저장됩니다.
복원: `RESTORE_PATCH.ps1 -ProjectRoot "프로젝트 경로" -BackupFolder "생성된 백업 경로"`.

검증: `npm test` 798개 통과, 모바일 Chromium 320/390/430/699px 헤더·높이·중복창·블러 검사 통과, PC 1024px 영향 없음.
실제 Vite 빌드는 환경에 vite 패키지가 없어 완료하지 못했으며 iPhone PWA 실제 기기 동작은 미검증입니다.

주의: iOS의 **시스템 소유 상태 표시줄**은 설치된 홈 화면 PWA의 배경색을 고정하는 경우가 있어, 테마에 따른 시스템 바 색 전환은 iOS 버전에 따라 제한될 수 있습니다. 앱 웹 영역의 색상은 테마와 동기화됩니다.

로컬 확인: `npm ci`, `npm test`, `npm run build`, `npm run dev`.
Cloudflare: 실제 로컬 화면을 확인한 뒤 `npm run deploy:pages`.
