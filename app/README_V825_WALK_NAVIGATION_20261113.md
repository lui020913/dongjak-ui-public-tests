# 동작하는 안전지도 v8.2.5 — 경로 추천·보행 내비게이션

기준: v8.2.4 전체 통합 소스 (Supabase·카카오 인증과 기존 지도 코드는 그대로 유지)

## 변경

- **지도에서 도보 경로 비교**: 실제 도보 계산으로 얻은 일반 보행 / 경사 회피 우선 경로의 소요시간·거리·추정 상승량을 직접 비교·선택합니다. 교통수단별 실시간 배차를 만들어내지 않습니다.
- **안내 화면 간결화**: 모바일 GPS 길안내 시작 중 하단 다섯 탭만 숨깁니다. PC의 왼쪽 메뉴는 유지합니다. 안내창은 큰 두 줄 수치 카드 대신 한 줄 거리·시간과 작은 버튼을 사용합니다.
- **현재 GPS 위치**: 실제 `watchPosition`으로 수신한 좌표에만 파란 점과 '내 위치' 라벨을 표시하며, 새 위치가 들어올 때 추적합니다. GPS가 연결되지 않거나 권한이 없으면 위치를 임의로 표시하지 않습니다.
- **좌·우회전 TTS**: 경로 서버에서 방향전환 정보를 전달하면 기존 안내를 사용합니다. 서버 정보가 없는 실제 도보 경로에서는 경로 기하의 55° 이상 방향전환을 보수적으로 찾아 100m/30m/직전 기준으로 한국어 음성을 보완합니다. 고도 미확인, 미세한 굴곡, GPS 오차 40m 초과에서는 보완 안내를 하지 않습니다. 지형 꺾임이 교차로나 실제 우회전 가능을 의미하지는 않습니다.
- **진동/화면 켜짐**: 기존 진동 선택은 기기 지원 시 유지합니다. 불필요한 화면 켜짐 유지 옵션은 제거합니다. iOS Safari/PWA에서 진동 API를 사용할 수 없는 경우 '진동 미지원'으로 표시합니다.

## 실행·배포

```powershell
npm ci
npm test
npm run build
npm run deploy:pages
```

- 배포 명령은 기존 Cloudflare Pages 고정 프로젝트 `dongjak-walk-safety-preview`를 대상으로 합니다.
- Supabase URL·Publishable Key 환경변수는 ZIP에 넣지 않습니다. 전체 ZIP을 새 폴더에 해제할 때 기존 `.env.local` 및 `.env.production.local` 파일을 안전하게 옮겨야 로그인·즐겨찾기 동기화를 쓸 수 있습니다. Secret/service_role 키를 웹앱에 넣지 마십시오.
- 지도 웹앱의 GPS는 HTTPS·위치권한을 필요로 하며, OS가 앱을 잠그거나 백그라운드로 보내면 추적과 음성이 중단될 수 있습니다.
- 도보 경로·진동·음성은 실제 iPhone과 Android에서 실사용 전 별도 검증이 필요합니다. 서버 경로의 정확성·안전성을 보증하지 않습니다.
