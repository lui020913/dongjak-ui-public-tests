# 동작하는 안전지도 v8.7.7 — 모바일 플로팅 창·내 정보·지도 설정

기준: v8.7.6 전체본. PC 지도·교통 레이아웃은 변경하지 않았습니다.

## 적용 사항

- 모바일 `길찾기`, `커뮤니티`, `동작 소식`, `내 정보`, `대중교통` 창에서 상단 펼치기 버튼을 눌러 화면 너비까지 확장·접기. 기존 위·아래 스와이프를 통한 확장과 닫기 동작 유지. 펼침 상태에서는 하단 5개 탭을 화면 가로폭 전체로 표시.
- 모바일 `내 정보`의 앱 및 화면 섹션에 `지도 설정 · 범례 · 도보`, `글자 크기·굵기`, `전체 업데이트 내역` 통합. 더보기에서 이전의 중복 설정 바로가기만 숨기고 앱 둘러보기 진입 기능은 유지.
- 지도 설정에 `지도 범례`, `도보 설정`, `지도 디자인 설정` 섹션 추가. 기존 실제 설정 소유자(`[data-base-layer]`, `#nav-voice`, `#nav-orientation`, `#dj816-voice-mode`)를 재사용하며, 별도 데이터/상태를 이중화하지 않음.
- 내 정보 프로필 화면에서 이미지 선택, 256×256 JPEG 압축 미리보기, 기기 내 저장과 삭제 지원. 현재 프로필 사진은 이 기기의 로컬 저장소에만 저장되며 Supabase 또는 카카오 계정에 업로드/동기화되지 않음.
- 본문 스크롤과 플로팅 시트 헤더 조작은 별도 영역으로 유지.

## 확인할 경로

1. 모바일 하단 `내 정보` → `지도 설정 · 범례 · 도보` → 지도 범례, 도보 설정, 지도 디자인 설정.
2. `내 정보` → `글자 크기·굵기` → 실제 화면 글씨 변경.
3. `내 정보` → `전체 업데이트 내역`.
4. `내 정보` → 프로필 → 사진 선택 또는 기본 이미지로 되돌리기.
5. `길찾기`, `내 정보`, `지하철·버스 정보` 등에서 상단 펼치기 아이콘 탭 또는 헤더를 위로 밀기 → 전체화면 / 다시 접기.

## 제한 사항

- 프로필 이미지는 해당 기기의 브라우저/웹앱 저장소에만 저장됩니다. 캐시/앱 데이터 삭제 시 사라질 수 있습니다.
- 지도 범례는 설치된 기존 지도의 주요 기호를 설명합니다. 보행안전 상세 범례는 기존 데이터별 범례를 따릅니다.
- 음성 합성 기능은 실제 기기가 제공하는 한국어 음성 목록에 의존합니다.
- `npm`을 통한 설치/빌드는 진행하지 않았습니다. 기존 Node.js 검사와 Chromium 독립 모듈 UI 검증을 수행했습니다.
