# 동작하는 안전지도 v8.11 UI 패치 안내 (2026-11-13)

## 정확한 기준 파일
`DongjakApp_FULL_v8.0.3_MOBILE_MOTION_VISUAL_FIX_959PASS_20261113.zip`

## 주요 변경
- 플로팅 창 기본 애니메이션을 짧은 페이드 효과로 변경. 설정 → 창 전환 효과에서 `부드럽게 나타나기`, `아래에서 펼치기`, `효과 없음` 중 선택 가능. 기존 설정 저장 방식 유지.
- 현재 활성화된 하단 탭을 다시 누르면 중복 화면 전환 차단. 기존 지도 메뉴의 정상 전환은 유지.
- 앱 자체의 지도 로딩 문구 및 진행 표시 스타일 보강. **iPhone 자체 OS 시작 화면**은 별개로, 이 화면은 웹 CSS로 변경 불가.
- 모바일 하단 탭의 카드별 그림자/테두리 제거, 전체 하단 도크 그림자 유지.
- 시설 팝업 화면 높이 제한 및 시설 실제 좌표 기준 지도 카메라 상단 배치. 지도 핀은 기존 좌표 핀을 재사용하고 중복 생성하지 않음. 시설 정보 닫기 버튼 모양 통일.
- 검색창 추천어 선택 시 실제 input과 복제 placeholder 상태 동기화 후 기존 전체 검색 수행. 검색 API 장애 시 결과가 제한될 수 있음.
- 웹 페이지 자체의 확대 방지(viewport 및 더블탭 처리). MapLibre 지도 제스처 확대는 유지. *주의: 접근성 확대 기능에 영향을 줄 수 있음.*
- 모바일 버스/지하철 정보 패널 최대 높이를 낮추고 내부 스크롤로 상세 정보를 유지.
- 버스 정류소명 표시 시작 시점을 거리 축척 약 16.5로 조정. 이름 중첩은 지도 자체 충돌 방지 엔진에 위임.

## 검증
- `npm test`: 965/965 통과 (기존 959 + 신규 6)
- 모바일/PC Chromium 정적 화면에서 부드럽게 나타나기/아래에서 펼치기/효과 없음의 열기·닫기 동작 확인
- `node --check` 수정 JS 문법 검사 통과
- `npm run build`는 실행 환경의 Vite 의존성 부재로 완료하지 못함. 실제 iPhone Safari/Cloudflare API 검증 불가.

## 로컬 실행 및 배포 (Windows PowerShell)
```powershell
npm ci
npm test
npm run build
npm run dev
```
Cloudflare Pages에 배포하려면 기존 프로젝트 설정을 확인한 후:
```powershell
npm run deploy:pages
```
기존 고정 URL(`https://dongjak-walk-safety-preview.pages.dev/`)은 동일 프로젝트에 배포할 때 유지됩니다.

## 델타 패치 적용
1. 기준 전체본의 프로젝트 루트에 압축 해제하거나 `APPLY_PATCH.cmd` 실행.
2. 기존 파일 SHA-256이 기준과 다른 경우 자동 적용을 중단합니다. 임의의 과거 프로젝트에는 적용하지 마십시오.
3. 기존 파일 백업은 프로젝트 안의 `backup_before_v811_*` 폴더에 생성됩니다.
