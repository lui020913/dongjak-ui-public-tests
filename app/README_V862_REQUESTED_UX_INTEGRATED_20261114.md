# 동작하는 안전지도 v8.6.2 — 요청 UX 통합본

## 기준 파일
- 사용자 제공 기준 ZIP: `DongjakApp_FULL_v8.6.1_MOBILE_UI_REPAIR_20261114(1).zip`
- 통합 버전: `8.6.2`
- 기존 v8.6.1 모바일 UI 복구 및 그 이전 지도·교통·인증·즐겨찾기·온보딩 기능은 유지합니다.

## 반영 사항

1. **로그아웃 확인 및 저장 항목 보존**
   - 로그아웃 전에 확인창을 표시합니다.
   - 즐겨찾기와 그룹은 Supabase 계정 데이터에 보관되며 동일 계정 재로그인 시 복원된다고 안내합니다.
   - 미동기화 데이터가 있으면 서버 동기화를 기다리고, 동기화가 실패하면 로그아웃을 취소합니다.
   - 로그아웃 후에는 이전 계정의 로컬 즐겨찾기 스냅샷을 비워 다른 사용자가 이전 계정 저장 항목을 보지 못하게 합니다.

2. **하단 플로팅 창 상하 슬라이드**
   - 모바일 하단 탭의 길찾기·커뮤니티·동작 소식·내 정보 패널을 열 때 아래에서 위로, 닫을 때 위에서 아래로 이동시킵니다.
   - 대중교통 패널과 시설정보(MapLibre 팝업)에도 같은 모션을 적용합니다.
   - 기존 닫기 핸들러를 재사용하고, 별도 제어기를 가진 더보기 패널의 닫기 동작은 기존 방식으로 유지합니다.
   - 사용자의 reduced-motion 설정을 존중합니다.

3. **대중교통 헤더 액션**
   - 출발·도착·즐겨찾기·공유 액션을 가로 액션 레일에 배치합니다.
   - 출발·도착은 아이콘 버튼으로 표시하고 즐겨찾기 별 아이콘은 버튼 중앙에 정렬합니다.
   - 공유 버튼은 즐겨찾기 오른쪽에 배치하고 기존 장소 공유 URL 및 Web Share/복사 동작을 사용합니다.
   - 기존 교통 조회·시간표·노선 선택 로직은 유지합니다.

4. **검색 추천창**
   - PC·태블릿 추천창을 뷰포트 중앙 기준 최대 960px로 확장합니다.
   - 검색창의 실제 하단 위치와 visual viewport를 기준으로 추천창 위치·높이를 계산합니다.
   - 모바일은 기존 v8.5.7 키보드/visual viewport 처리 로직을 유지합니다.

## 검증
- `npm test`: **1,366개 테스트 통과**
- `npm run check:release`: **통과 (v8.6.2 버전 정합성)**
- 수정한 JavaScript 파일 `node --check`: **통과**
- `npm run build`: **실행 불가** — 작업 환경에 Vite가 설치되어 있지 않았습니다.
- `npm ci --ignore-scripts --no-audit --no-fund`: **시간 초과** — 의존성 설치가 완료되지 않았습니다.
- 실제 브라우저/기기에서의 시각적 회귀 검증은 아직 수행하지 않았습니다.

## 실행 및 빌드
프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
npm ci
npm run build
npm run dev
```

배포는 기존 프로젝트 절차에 따라 `npm run deploy:pages`를 사용합니다.
