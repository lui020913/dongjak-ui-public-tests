# 동작하는 안전지도 v8.7.4 — 검색·대중교통·시설·모바일 UX 정리

기준: v8.7.3 전체 통합본. PC 지도·PC 교통 레이아웃·기존 시설 데이터 소스는 보존합니다.

## 적용 범위

- 모바일 일반시설 검색을 서울시 D1·현재 시설 캐시·범위 제한 OSM 장소 검색으로 보강하고 확대 시 카페·편의점 등의 표식과 명칭 표시 배율 완화
- 모바일 온보딩 건너뛰기 세로 여백 확대 및 중복 진행 표시를 페이지 점으로 통일
- 지하철·버스 헤더 2행 구조 통합, 즐겨찾기 가운데 정렬, 이전·현재·다음역 3분할 알약바 적용
- 환승역 호선 전환 시 기존 헤더 DOM과 선택 마커를 유지해 패널 재개방·깜빡임 억제
- 날씨 조회 실패 시 --° 표시 및 주요 버튼 누름 피드백
- 보행안전 정보 종류를 모바일 가로 카테고리 탭으로 전환하여 아래로 연속 확장되지 않게 수정
- 시설 상세의 불필요한 구분선과 주소·전화번호 여백 정리, TIP 중첩 차단 및 네이버지도 외부 확인 링크 유지
- 버스 도착정보 카드 밀도·노선 유형 색상 보정, 헤더 및 실시간·시간표 컨트롤 고정
- 교통 바텀시트 회색 손잡이 주변 전체 너비 44px 제스처 영역과 시설 상세 상단 드래그 영역 조정

## 외부 자료 한계

- 서울시 D1 API 또는 OSM 온라인 조회 성공 여부는 배포 환경 설정과 외부 서버 상태에 따릅니다. 조회 결과를 만들어 내지 않습니다.
- 네이버지도 자체 장소 상세·연락처를 자동 수집해 앱에 저장하는 것은 네이버 지도 API 이용 계약/인증 없이는 구현되지 않았습니다. 등록 자료와 외부 네이버 지도 검색 링크로만 확인합니다.
- 지하철 호선/버스 정류장 실시간 운행 상태, 기기별 FPS와 실제 iPhone 터치 반응은 운영 환경에서 별도 검증이 필요합니다.

## 배포

새 폴더에 압축 해제 후 기존 `.env.local` 등을 필요한 경우 복사해 주세요. 이전 요청대로 여기서는 npm 설치·빌드를 수행하지 않았습니다.
