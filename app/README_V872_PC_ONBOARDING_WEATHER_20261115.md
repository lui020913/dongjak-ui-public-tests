# 동작하는 안전지도 v8.7.2 — PC 온보딩 및 날씨 버튼 보정

기준: v8.7.1 전체 통합본. PC 온보딩의 다음/건너뛰기/점 이동 버튼이 클릭 불능인 원인은 `v860-onboarding.js`의 부모 모달 `setPointerCapture()` 처리로 확인되었습니다. 버튼을 누르는 마우스 포인터의 `click`이 모달로 재타겟팅되는 현상을 Playwright에서 재현했습니다. 전체 모달 포인터 강제 캡처를 제거하고 스와이프 방향 검사는 유지합니다.

PC(700px 이상) 전용 스타일 `src/v872-pc-onboarding-weather.css`에 온보딩 폰트·버튼 확대와 상단 날씨 컨트롤 56px 일치 스타일을 분리했습니다. 모바일(699px 이하) 스타일과 맵/교통 로직은 유지합니다.

검증: npm을 실행하지 않고 JavaScript 구문 검사, node 전용 집중 테스트, Playwright 온보딩 실제 클릭/5단계 완료/키보드·스와이프/상단 날씨 치수 검증 및 ZIP 파일 무결성 확인.

실제 Cloudflare 배포와 실기기 통합 동작 검증은 별도로 필요합니다.
