# DongjakApp v8.4.0 — v8.3.1 교통기능 보존 + 15개 요구사항 적용

## 병합 기준

- 기존 v8.3.1 교통정보 로그인 안내, 버스 노선 색상, 정보창 스와이프 기능 유지

## 15개 요구사항
1. 안전지도 홈 탭에서 행정동 선택창 자동 표시 금지
2. 탭 전환 시 안전지도 글씨 내려감 수정
3. 레이어 표시/경계선 옵션은 더보기 전용 (상단 꺼내기 불가)
4. 더보기의 불필요한 `상단 표시` 문구 제거
5. 행정동 선택 버튼은 선택창만 열고 중복 정보창 제거
6. X 닫기로 바로가기 확장 및 활성 상태 복구
7. 추천 장소 표시 중 검색창 아래 바로가기 숨김
8. 현재 로드된 OSM POI + Photon 기반 시설 검색 후보 확장
9. 도움말 물음표 아이콘 청록색
10. 열린 창이 없을 때 하단 탭을 안전지도로 복구
11. 지도 팁 알약형 UI 및 10초 순환
12. 내 정보 테마 라벨·화살표 위치 및 확인창 개선
13. 프로필 저장/수정 상태·알림·로그인 상태의 보안 탭 표시 조정
14. 더보기 업데이트 내역과 지도 설정 좌우 배치
15. 하단 내비게이션 알약형 곡률

- Windows: 패치 압축을 푼 뒤 APPLY_PATCH.cmd 실행 → v8.3.1 원본 프로젝트 루트 선택
- 모든 변경 파일의 이전 SHA-256/패치 SHA-256 및 기준 버전 확인 후 전체 적용
- 원본 자동 백업; RESTORE_PATCH.cmd를 통한 복원 지원
- npm ci → npm test → npm run check:release → npm run build → npm run deploy:pages
