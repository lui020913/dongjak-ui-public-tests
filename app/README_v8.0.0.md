# 동작하는 안전지도 v8.0.0 — 공통 UI 구조 개편

기준 원본: `DongjakApp_FULL_v7.13.0_SMOOTH_PANELS_SEARCH_FPS_INTEGRATED_20261112(1).zip`.

## 개편 범위

- **동시에 하나의 메인 플로팅 창만 표시**: 지도 옵션·보행안전·길찾기·커뮤니티·동작 소식·내 기록·교통 상세·행정동 선택·도로폭·야간시야·설정·앱 정보·업데이트 내역을 공통 표시 규칙으로 조정합니다.
- **모바일**: 하단 탭 위치에 맞춰 정보창의 하단 간격 정렬, 교통정보창과 지도 조작 레일의 겹침 방지, 호선 선택 영역 배경과 상·하행 카드 색상 구분, 간결한 도보 길찾기 화면, 별도 글자 크기·굵기(큰 가/작은 가) 아이콘 및 설정창, 앱 로고 크기를 테마 버튼 기준으로 보정했습니다.
- **PC**: 모든 플로팅 창의 시작 위치를 왼쪽 탭 영역 실제 좌표로 계산, 왼쪽 탭과 안전 버튼의 정렬 및 글자 크기·굵기 통일, 상단 버튼 높이를 검색창과 맞췄습니다.
- **테마**: 라이트·다크의 텍스트·카드·테두리·버튼 색상 분리, 팝업 등장 애니메이션. PWA 테마/야간시야 전환 중 기존 첫 로딩 로고가 잠깐 보이지 않도록 새로고침 전용 프리페인트 화면을 수정했습니다. 저장한 다크 테마가 재실행 후 라이트로 강제로 초기화되지 않도록 보완했습니다.
- **나침반**: 모바일의 지도 조작 버튼은 기존 PC/지도 나침반을 클릭하는 프록시로 유지하며, 방위각 회전 상태와 아이콘을 원본에 동기화합니다.
- **버전**: 대규모 UI 변경으로 `v8.0.0`로 분류하되, 1.0.0부터의 과거 변경 사항은 보존했습니다.

기존 MapLibre 지도 초기화, 버스·지하철 데이터 연산, 야간시야 추정 및 보행안전 원천 데이터는 변경하지 않았습니다.

## 설치와 실행

새 폴더에 전체 ZIP을 압축 해제해 기존 `.env`를 필요한 경우 복사하십시오.

```powershell
npm ci
npm test
npm run build
npm run dev
```

Cloudflare 배포는 **로컬 지도 화면 검증 후** `npm run deploy:pages`를 사용합니다. 기본 URL은 기존 프로젝트 설정에 따릅니다.

## 검사 결과와 한계

- Node 자동 테스트: **864/864 통과**.
- 별도 Chromium DOM·CSS 검사: 320/390/430px 모바일, 1440px PC. 6개 모바일 툴바 버튼 가로 정렬, 주요 팝업 상호 배타, 글자 크기 플로팅 창, PC 플로팅 창 위치 검사 통과.
- 수정 JavaScript 구문 검사 통과.
- `npm run build`: 현재 검사 환경에 Vite 의존성이 없어 `vite: not found`로 중단(빌드 성공 아님).
- **실제 지도 타일 렌더링, 실제 iOS 홈 화면 PWA/Android, 실시간 교통 API 연동은 검증하지 못했습니다.** 실제 기기 검증 전에는 안정 배포본으로 간주하지 마십시오.

## 설계 규칙

1. 메인 작업 창은 한 번에 하나만 표시합니다. 지도 조작 프록시는 중복 생성하지 않습니다.
2. 팝업은 기존 이벤트/DOM을 재사용하고 공통 애니메이션을 적용합니다.
3. 모바일 화면과 PC 화면은 별도 레이아웃 토큰으로 관리합니다.
4. 라이트/다크는 서로 다른 표면·글자·경계·상태 색상 토큰을 사용합니다.
5. 지도 데이터 처리 및 본래 앱 컨트롤 동작은 변경하지 않습니다.
