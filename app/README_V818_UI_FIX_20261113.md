# 동작하는 안전지도 — v8.0.3 UI 후속 수정 (2026-11-13)

기준 ZIP: `DongjakApp_FULL_v8.0.3_EXCLUSIVE_SEARCH_SAFETY_994PASS_20261113.zip`

## 변경 내역
1. PC 글꼴: Apple SD Gothic Neo → AppleSDGothicNeo → 시스템 기본 대체 글꼴 순으로 적용. 웹서버에서 폰트를 자동 제공하는 것은 기술적으로 가능하지만 폰트별 웹 배포 라이선스가 필요하므로 이 패키지에는 글꼴 바이너리를 포함하지 않습니다. Windows PC에 적법하게 설치된 Apple SD Gothic Neo는 자동 활용됩니다.
2. 날씨 표시 토글: 사용자 설정으로 켜고 끌 때 240ms 페이드 인/아웃. 완전히 사라진 뒤 `display:none`을 적용해 갑작스러운 소거를 방지하고, 연속 조작 시 오래된 애니메이션 종료 결과를 무시합니다. '움직임 줄이기'가 켜져 있으면 효과를 생략합니다.
3. PC 도로폭: 버튼 클릭 이벤트의 캡처 단계에서 왼쪽 사이드바 좌표를 먼저 계산하고 해당 패널에 반영합니다. 옛 CSS에 남은 이동·변형 효과는 비활성화해 오른쪽에서 번쩍 나타나는 문제를 방지합니다.
4. 모바일 글꼴: 기존 '가/가' 글씨 크기/굵기 UI가 교통정보·보행안전·지도 옵션·소식·내 기록·설정 등 주요 화면의 개별 크기 위계를 유지하면서 적용되도록 변경했습니다. 기본/작게/크게/더 크게와 기본/굵게를 선택할 수 있으며 저장 기능은 기존 로직을 사용합니다.
5. 지하철·버스 정보: 상세창을 새로 열 때 선택 위치가 화면 중앙보다 약간 위에 오도록 카메라 오프셋을 적용했습니다. 호선만 바꿀 때는 카메라를 다시 움직이지 않습니다. 모바일 시설 선택 핀은 대표 좌표·이름 가까이 표시하도록 오프셋을 좁혔습니다.
6. 모바일 검색창 양옆: 상단 아이콘↔검색창, 검색창↔테마 버튼 간격을 10px로 동일하게 정렬했습니다.
7. 앱 업데이트 내역: 위 변경을 v8.0.3의 최신 수정사항 항목에 추가했습니다.

## 자동 검증
- `npm test`: 1,000/1,000 통과
- Chromium 1280×800 및 390×844의 로컬 HTML UI 점검: 날씨 페이드 중간 프레임·숨김·재표시, 글꼴 크기/굵기 반영, 도로폭 창 첫 표시 위치, 모바일 양옆 간격 통과
- `transport-map.js`: 승인된 카메라 블록 이외 원본 소스 바이트 불변 검증 (교통 API 및 데이터 처리 보호)
- `npm run build`: 이 환경에서 Vite 실행 파일이 설치되지 않아 **실패** (`vite: not found`). 실제 지도 API 및 iPhone Safari 전체 통합 실행은 검증하지 못했습니다.

## 웹폰트 배포 주의
직접 제공받은 Apple 산돌고딕 네오 파일이라도 공개 웹사이트 호스팅 권한이 있는 것은 아닙니다. 웹폰트를 실제 호스팅하려면 해당 폰트의 웹 배포 권한 확인 후 허가된 형식(WOFF2 등)으로 제공해야 합니다. 이번 ZIP에는 폰트 파일을 일절 포함하지 않습니다.
