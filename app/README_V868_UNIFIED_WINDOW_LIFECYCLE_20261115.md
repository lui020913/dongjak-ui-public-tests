# v8.6.8 공통 창 상태 라이프사이클

기준: v8.6.7 `DongjakApp_FULL_v8.6.7_TRANSPORT_WINDOW_LIFECYCLE_REBUILD_INTEGRATED_20261115.zip`

## 수정 범위

- 하단 탭, 지도 안내, 지도 도구, 검색 추천, 상세정보, 모달 등 v806에서 관리하는 모든 표면의 상태를 공통 라이프사이클 코어에 연결
- 임시 창(온보딩, 로그인 안내, 경계 안내, 날씨/기타 정보 등)은 독립형 상태로 추가 감시하여 닫힘 후 유령 재등장 차단
- MapLibre 시설 팝업은 MapLibre 기존 닫기 핸들러를 우선 실행하고 재클릭은 하지 않음
- 사용자 X: 닫음 상태 먼저 기록하고 기존 단일 핸들러로 즉시 닫음. 과거의 '애니메이션 뒤 클릭 다시 실행' 루프 제거
- 닫기 직후의 비명시적 재열림은 680ms 제한. 실제 사용자가 버튼을 다시 눌러 여는 것은 즉시 허용
- 대중교통 출발·도착 텍스트 표시 CSS 명시, PC와 모바일 레이아웃은 각각 유지
- 모바일 시트 드래그 닫기는 동일 라이프사이클에 기록

## 주의/검증

- `npm` 명령은 실행하지 않음. Node 구문 검사, 릴리스 검사와 신규 핵심 테스트를 실행.
- 이전 버전은 애니메이션 뒤 가짜 클릭으로 닫았지만 중복 창 문제가 있어 재생 방식을 제거. 창 입장 애니메이션은 유지하나 일부 X 닫기 전환은 즉시 닫힘.
- 기존 테스트 중 예전 지연 재클릭·닫기 애니메이션의 구현 형태 자체를 검사하는 항목은 이번 설계와 일치하지 않아 실패할 수 있음.
- 실제 iPhone/PWA에 배포해 전체 화면을 끝까지 재현한 테스트는 완료하지 못함.
