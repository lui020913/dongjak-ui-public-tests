7. 모바일 시설 선택 위치 핀을 지도 글씨 위에 보이도록 약간 위로 조정
8. 앱 UI DOM 글꼴 우선순위를 `Apple SD Gothic Neo`로 변경. 제목·버튼·본문 가중치 조정

## 글꼴 적용 제한
첨부받은 Apple 산돌고딕 네오 폰트 파일은 **배포 ZIP에 포함하지 않았습니다**.
- iOS Safari에서는 OS 제공 글꼴을 우선 사용합니다.
- Windows/PC에서는 사용자가 해당 글꼴을 **로컬에 설치해야** 동일하게 표시됩니다.
- 글꼴이 없는 환경에서는 시스템 한글 폰트로 자동 대체됩니다.
- MapLibre의 벡터 타일/지명 글꼴은 별도 지도 스타일의 글리프 리소스라 이 CSS만으로 바뀌지 않습니다.
