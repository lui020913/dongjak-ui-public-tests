## 기준
- **기준 원본**: `DongjakApp_FULL_v8.2.9_MOBILE_UI_LAYOUT_FIXED_20261114.zip`
- **목표**: `v8.2.10` (v8.2.9 전용 델타 패치)
- 지도 데이터, 실시간 교통 요청, 카카오 OAuth, GPS, 경로탐색, PC 지도 렌더링 코드는 변경하지 않습니다.

## 반영된 요청
1. 지하철역명과 호선 배지 각각 중앙 정렬: 기존 전환 버튼은 그대로 보존하며 표시만 별도 래퍼로 구성합니다.
2. 이전역·현재역·다음역의 외곽 이중 배경 제거: 각 역 버튼 및 노선 색은 그대로 유지합니다.
3. 지하철·버스 선택 위치 핀을 시설정보의 녹색 위치 핀과 **동일한 SVG**로 통일합니다.
4. 모바일 시설정보를 하단 탭 위 고정 플로팅 카드(최대 53dvh·내부 스크롤)로 변경합니다. 주소·전화·홈페이지는 밀도를 높이되 데이터 자체는 바꾸지 않습니다.
5. 시설정보 출처 문구를 화면에서 제거하고 외부 검색 버튼을 **네이버지도에서 시설 주소·연락처 검색**으로 표기합니다.
6. 모바일 동작 로고 버튼 외곽을 테마 버튼과 같은 크기로 맞춥니다(소형 화면 포함).
7. MapLibre 시설 팝업의 X와 기존 v817 SVG X 위에 중복으로 그려지는 CSS X를 제거합니다.
8. 버전 표시/기록만 `8.2.10`으로 동기화합니다.

## 접근성·표시 기준
- 원본 시설 좌표와 개별 선택 마커를 그대로 유지합니다.
- 가로폭 699px 이하 모바일 시설 카드는 지도 좌표의 MapLibre 말풍선 대신 독립 하단 카드로 표시합니다. 실제 지리좌표는 녹색 핀이 표시합니다.
- iOS 안전영역과 하단 5개 탭 위 여백을 사용하며 스크롤은 카드 안에서만 허용합니다.
- 모바일 시설정보창의 닫기 버튼은 MapLibre 기본 close를 그대로 사용합니다.

## 설치
1. 기존 v8.2.9 앱 폴더를 백업하십시오.
2. 이 패치 ZIP의 `APPLY_PATCH.cmd`를 실행하고 v8.2.9 프로젝트 폴더를 선택하십시오.
3. 해시 검사가 통과하면 기존 변경 파일은 `patch_backups\v8210_날짜_시간`에 백업된 뒤 적용됩니다.
4. VS Code에서 `npm ci`, `npm test`, `npm run check:release`, `npm run build`를 실행하십시오.
5. 화면과 교통·시설 클릭이 정상일 때 `npm run deploy:pages`로 배포하십시오.
6. 문제가 발생하면 `RESTORE_PATCH.cmd`로 이전 파일을 복원할 수 있습니다.
