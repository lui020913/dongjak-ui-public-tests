# 동작하는 안전지도 v8.0.3 — PC·모바일 UI 정렬 및 테마 전환 안정화

**기준 소스:** `DongjakApp_FULL_v8.0.2_TOPIS_SDOT_PC_MOBILE_POLISH_20261112(2).zip` (사용자 첨부 원본)

## 핵심 변경
- PC 검색창 높이 56px 유지, 앱 아이콘 60px, 날씨·테마·버전·설정 버튼 56px 및 알약형 모서리/간격 재정비
- PC 왼쪽 내비게이션 아이콘·텍스트를 고정된 그리드로 정렬, 지도 도구 버튼 테두리 제거, 야간 시야 글자 크기 통일
- PC 큰 제목 굵기 강화, 도보 길찾기 도입 설명 숨김, 날씨·내 위치와 검색 버튼 내부 정렬 보완
- 보행안전 메뉴에서는 가독성 설정을 숨기고, 기기 환경설정/모바일 전용 글자 도구는 그대로 유지
- 설정창의 글자 크기·날씨·지도 조작 버튼·움직임 줄이기 실제 상태를 적용 및 저장
- 모바일 지도옵션·보행안전·하단 탭·교통정보 등 기존 창이 열리는 순간 애니메이션 재생 보강. 중복 재생 방지
- 모바일 지도 옵션·보행안전 닫기 버튼 X 표시를 중앙 정렬하고 다크 테마 텍스트 대비 개선
- 신규 페이지/앱 시작은 항상 라이트 테마. iOS 홈 화면 PWA에서 **테마/야간 시야 변경을 위해 진행 중인 재로드만** 선택한 테마로 복귀
- 테마 재로드 중 기존 앱 첫 로딩 이미지가 잠깐 보이지 않게 하고 전환 화면 유지
- 앱 정보창에 `동작구 아이디어 리그 안전팀 시범 운영 프로그램` 표시
- 지도 조작 안내(?)에 Safari → 공유 → 홈 화면에 추가 도움말 표시
- 이전 버전 내역 및 TOPIS·S-DOT·지도·교통·보행안전 원본 기능 유지

## 실행

```powershell
npm ci
npm test
npm run build
npm run dev
```

Cloudflare Pages 기존 프로젝트 배포:

```powershell
npm run deploy:pages
```
