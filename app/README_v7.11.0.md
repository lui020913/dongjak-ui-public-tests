## 모바일
- 앱 이미지 자체를 누르면 '동작하는 안전지도' 브랜드명이 오른쪽으로 펼쳐지며 검색창 너비가 줄어듭니다.
- 테마 및 야간 시야 전환 시 로고 대신 블러 배경 + 회전 로딩 + 중앙 안내 문구를 사용합니다.
- iOS 홈 화면 PWA의 기존 새로고침 방식과 전환 토큰을 연계해 전환 중 화면을 유지합니다.
- 오른쪽 지도 도움말/나침반/홈/GPS 버튼은 PC 컨트롤에 포함된 원본 SVG 및 마크업을 재사용합니다.
- 주요 모바일 시트의 간격과 컨트롤 높이를 압축해 스크롤 사용을 줄였습니다.

## PC Chromium
- 하단 다른 탭에서도 오른쪽 지도 도움말 및 지도 조작 버튼이 표시되도록 보정했습니다.
- 사이드바 지도 옵션 기준의 버튼 색상·테두리·모서리를 통일하고 글자를 확대했습니다.
- 테마/야간시야 전환 중 화면 블러와 로딩 안내를 사용합니다.
- 환승역은 역 이름 옆의 노선 배지로 호선을 선택하며, 아래 중복 환승 선택 행을 제거했습니다.
- 지하철 교통 정보 패널을 왼쪽 탭 기준으로 고정해 마우스를 따라 움직이지 않습니다.
- 업데이트 이력 화면의 스타일 및 탭 전환, 도로폭 범례 창의 진입 애니메이션을 추가했습니다.

## 실행
1. **전체 ZIP 권장**: 빈 폴더에 압축을 풉니다. 기존 `.env` 값만 새 폴더로 옮깁니다.
2. `npm ci` → `npm test` → `npm run build` → `npm run dev`
3. Cloudflare 배포는 로컬 기능 확인 후 기존 `npm run deploy:pages` 명령을 사용합니다.

패치 ZIP은 기존 첨부 통합본을 보존하려는 경우에만 사용하십시오. 본 패치는 적용 전 원본 SHA-256을 검증하고, 백업/복원 기능을 제공합니다.
