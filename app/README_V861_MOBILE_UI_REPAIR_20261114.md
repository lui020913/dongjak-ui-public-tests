# v8.6.1 모바일 UI 수정

기준 버전: v8.6.0
릴리스 버전: v8.6.1

## 수정 사항

1. 더보기 창을 기존 상단 우측 드롭다운이 아닌 하단 플로팅 시트로 표시합니다.
   - 하단 5개 탭 위에 배치
   - 고정 헤더와 내부 스크롤 유지
   - 구버전 v8.2.9 배치 규칙보다 우선하도록 CSS 우선순위 정리
2. 더보기 닫기 충돌을 수정합니다.
   - 공통 시트 애니메이션 조정기가 더보기 X 버튼을 중복 처리하지 않도록 제외
   - 닫기 시 aria 상태, 드래그 상태, 페이드 상태를 정리
   - 업데이트 내역과 지도 설정은 더보기 창을 먼저 닫은 다음 목적지 화면을 실행
3. 지도 TIP을 축척바와 분리합니다.
   - TIP 폭을 최대 248px로 제한
   - 오른쪽 12px에 정렬
   - 축척바가 사용하는 왼쪽 영역을 확보
4. 최초 지도 조작 안내창을 모바일 화면 중앙에 배치합니다.
   - iOS 안전영역 반영
   - 화면 높이에 맞춘 최대 높이와 내부 스크롤

## 검증

- 자동 테스트: 1,362개 통과
- 변경 JavaScript 구문 검사: 통과
- 릴리스 버전 검사: 통과 (v8.6.1)
- CSS 문법 검사: tinycss2 파서 기준 오류 없음
- 프로덕션 빌드: 미완료. 작업 환경에서 `npm ci`가 시간 초과되어 Vite 실행 파일이 설치되지 않았습니다.
