# 동작하는 안전지도 v8.5.6 — 미반영 UI 요청 통합 마무리

기준: `DongjakApp_FULL_v8.5.5_MAP_STARTUP_FIXED_20261114.zip`

## 반영한 항목

### PC 헤더 및 사이드 메뉴
- 700~1079px 구간에서 상단 헤더를 화면 가장자리에서 8px 띄우고, 검색창과 도구 영역을 별도 그리드 열로 분리했습니다.
- 검색창 최대 폭을 560px로 제한하고, 모바일 설정 버튼이 PC 헤더에 중복 배치되지 않도록 숨겼습니다.
- 오른쪽 나침반·홈·도움말·위치 컨트롤은 헤더 아래에 배치해 설정 버튼과 겹치지 않도록 했습니다.
- PC에서 안전지도 탭을 DOM 순서상 첫 번째로 배치하고, 지도 옵션·야간 시야·보행안전 버튼의 높이(46px), 아이콘 상자(18px), 글꼴(13px)을 통일했습니다.

### iPhone 안내 및 업데이트 내역
- iPhone 홈 화면 추가 안내를 Safari 실행 → 공유 → 홈 화면 추가의 3단계로 정리했습니다.
- 구버전 정리 스크립트가 제거하던 최신 업데이트 바로가기를 새 UI 모듈에서 복원했습니다.
- 바로가기는 업데이트 내역 창을 열고 현재 버전(v8.5.6)의 항목으로 스크롤한 뒤 강조 애니메이션을 적용합니다.

### 지도·교통·날씨
- 노들섬 DOM Marker를 제거하고, MapLibre `symbol` 레이어에 아이콘과 지명을 함께 렌더링하도록 변경했습니다. 지리 레이어가 지도 카메라 렌더링과 함께 이동하므로 DOM 마커의 지연 추종을 줄입니다.
- 모바일에서 상단 날씨 요약 알약을 숨기고 하단 도구 모음의 날씨 진입점 하나만 유지합니다. 날씨 상세 시트는 기존 동작을 사용합니다.
- 지하철 호선 배지 클릭 시 기존 교통정보 패널을 유지합니다. 이벤트 캡처 단계에서 패널의 자동 스크롤을 막고 스크롤 위치를 복원하며, 선택한 호선 콘텐츠에 짧은 전환 애니메이션을 적용합니다. 기존 교통 지도 렌더러와 `transport-map.js`는 수정하지 않았습니다.
- 지도 TIP 알약 폭을 248px 이하로 줄이고, 기존 문구 이동·지도 안내창 연결 동작을 보존했습니다.

### 기존 기능 보존
- v8.5.4의 검색 결과 대중교통/일반 시설 2열, 독립 스크롤, 빠른 검색 접기, 지도 범위 제한 제거를 유지합니다.
- 시설 및 대중교통 즐겨찾기 아이콘 전용 UI, 더보기 제목/닫기 고정, 지도 레이어 토글, 언어 설정, PC 시설/교통/뉴스 패널 레이아웃을 유지합니다.
- v8.5.5의 언어 MutationObserver 무한 반복 방지와 TIP 측정 반복 방지를 유지합니다.
- `src/main.js` 및 `src/transport-map.js`는 보호된 기존 핵심 코드로 그대로 보존했습니다.
