## 변경 사항

### PC
1. `안전지도` 탭 클릭 시 **기존 행정동 선택 컨트롤**을 직접 호출. 빈 개요 패널을 닫고 행정동 목록을 표시. 기존 행정동 지리 정보는 재구성하지 않음
2. 행정동·교통정보 패널의 강제 전면 높이 제거. 내용 높이에 맞게 표시하고 화면을 초과할 때만 내부 스크롤
3. 검색창의 `검색` 버튼 모서리를 pill 형태로 조정
4. 제목, 기본 설명, 버스·지하철 실시간 정보, 뉴스, 내 기록의 글자 크기·두께 확대
5. 업데이트 내역 모달의 등장 애니메이션 적용
6. PC `?` 안내창의 iPhone 홈 화면 설치 설명 숨김, PC 조작 도움말 글자 확대
7. 다크모드 출발·도착 버튼 뒤의 불필요한 배경 제거

### 공통
1. `도보 길찾기` 제목 굵게, 경로 선택 패널 밖 하단 장문 안내문 숨김(원본 안내문 보존)
2. 주요 패널 열기 애니메이션 통일, 닫기 버튼은 기존 클릭 동작을 170ms 종료 애니메이션 뒤에 재생(동작 줄이기 설정 예외)
3. 지도 위 한강철교 및 5개 교량명 전용 MapLibre 레이어: 다크모드에서 밝은 텍스트 + 어두운 테두리, 라이트모드 원래 색상

### 모바일
1. 글자 크기 버튼의 `가`/`가` 간격을 2px로 조정
2. 지하철 정보창 여백·높이를 압축하여 한 화면 표시를 우선. 실제 콘텐츠가 들어맞을 때만 스크롤 완전히 비활성화. 작은 화면에서 잘리지 않게 스크롤을 조건부 허용
3. 버스정류장 유형·정류소 이름·ARS 문구 가운데 정렬, 버스 한 건당 카드 높이·간격 축소
4. 시설정보 지도 팝업의 오른쪽 여유 공간을 확보하여 지도 조작 버튼을 가리지 않음. 팝업 상자의 최대 높이는 하단 탭의 화면 위치를 기준으로 제한하고 내부에서 스크롤

## Windows 실행 및 테스트
1. 전체 ZIP을 새로운 폴더에 압축 해제하고 VS Code에서 폴더 열기
2. PowerShell 터미널에서 아래 실행

```powershell
npm install
npm test
npm run build
npm run dev
```

- `npm install`이 실패하면 PowerShell/Node 네트워크·프록시·npm 설정을 먼저 확인. `npm ci`는 현 설치 환경에서 오류가 있었으므로 `npm install`을 우선 시도
- 빌드 결과를 Cloudflare의 **기존 고정 Pages 프로젝트**에 반영하려면 해당 프로젝트 설정과 비밀키가 정상인지 확인한 후 `npm run deploy:pages`
- 고정 Pages 주소: `https://dongjak-walk-safety-preview.pages.dev/` (배포 완료 여부는 별도 확인 필요)
- API 비밀키는 ZIP에 포함하지 않음. 실제 버스·지하철·AED 연동은 배포 환경의 비밀키/권한에 좌우됨

## 패치 ZIP 적용
- 원본 통합 프로젝트(8.0.3) 폴더에만 적용
- `APPLY_PATCH.cmd` 실행 → 프로젝트 폴더 입력 → 기준 파일 SHA-256 검사 → 변경 대상 파일 백업 → 패치 적용
- 백업: 프로젝트 폴더 내 `.dj-patch-backups` 하위의 날짜별 디렉터리
- 이미 다른 수정을 진행한 파일이 원본과 다를 경우 자동 덮어쓰기 거부. 그 경우 최신 통합 소스와 비교 병합해야 함
