# 동작하는 안전지도 v8.2.7 전체 통합본

이 ZIP은 사용자가 제공한 `DongjakApp_FULL_v8.2.6_GPS_SAFETY_NAV_INTEGRATED_20261113(1).zip`의 **모든 소스 파일**에 `Dongjak_v826_to_v827_LIVE_TRANSIT_INTEGRATED_PATCH_20261113.zip`의 변경 파일 19개를 적용하여 생성했습니다. **별도 패치 설치가 필요하지 않습니다.**

## 시작

1. 이 ZIP을 원하는 새 폴더에 **그대로 압축 해제**합니다(기존 v8.2.6 프로젝트에 덮어쓰지 않아도 됩니다).
2. VS Code에서 해당 폴더를 엽니다.
3. 터미널에서 `npm ci` → `npm test` → `npm run check:release` → `npm run build` → `npm run dev` 순으로 실행합니다.
4. 웹에서 실제 교통 API 응답과 차량 표출을 확인한 후 `npm run deploy:pages`로 배포합니다.

## 실시간 차량 표시

- 지도 표시 설정에서 `실시간 지하철`, `실시간 버스`를 켜면 차량을 조회·표시합니다(초깃값 모두 OFF).
- 지하철 위치는 실시간 역 정보와 선로 형상으로 **추정한 좌표**이며 GPS 실측값이 아닙니다.
- 버스는 서울 버스 GPS API의 실제 좌표가 제공되는 노선에 한해 표시합니다.
- 지도 줌 레벨 13.2 이상, 동작구 내부에서만 표출하며, 데이터가 오래되면 숨깁니다.
- `SEOUL_SUBWAY_API_KEY` 또는 `SEOUL_METRO_API_KEY`, `SEOUL_BUS_SERVICE_KEY` 또는 호환 버스 API 키 설정이 필요합니다. API별 이용 권한 및 Cloudflare 환경변수 설정을 확인하세요.
- 버스 기본 대상은 동작구 내 대표 정류장에서 탐색한 최대 8개 노선입니다. 전체 노선의 모든 차량이 자동 표시되는 것은 아닙니다.
- 자세한 옵션과 한계는 패치 설명에 준합니다.
