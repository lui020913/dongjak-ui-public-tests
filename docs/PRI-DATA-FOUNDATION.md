# PRI 데이터 기반 — 상도1동 조명 실증

- 지도 기능 더보기 → 상도1동 PRI 위험도 → JSON 자료 불러오기: 팀원의 lighting_segments.json 원본 형식을 지원합니다. 업로드는 로컬 브라우저에서만 처리하며, 원본 자료는 공개 저장소에 넣지 않습니다. 현재 페이지 세션에만 유지됩니다.
- 기본 비활성 상태입니다. 지도 색상은 보행안전점수 0~100 연속 팔레트(빨강→초록), 100점에 가까울수록 상대적으로 양호, 미평가 구간 회색. 연속된 같은 OSM way의 관측선 안에서만 색을 보간하고 데이터 없는 도로 사이를 연결하지 않습니다. 점 좌표만 있는 원본 구간은 확대한 경우 점입니다.
- 내보낸 PRI 네트워크 JSON은 schemaVersion:1, networkVersion, area, factors, segments, config를 포함합니다. geometry는 WGS84 [경도,위도]. scores는 정규화된 0~100 안전점수 또는 null이고, 0은 유효한 취약 점수다. 지표마다 id,label,source,method,date,estimated. 실제 공동 도로망과 구간 ID 확정 전까지 조명 조사 구간은 임시 기준이다.
- 추가 지표 파일: { "type":"pri-factor-scores", "schemaVersion":1, "networkVersion":"내보낸 버전", "factor":{"id":"width","label":"도로폭","source":"출처","method":"방법"}, "scores":[{"id":"실제 공통 구간 ID","score":45}] }. 같은 버전과 ID만 추가 가능. 추가 파일의 점수 방향은 `factor.scoreDirection: "risk" | "safety"`로 명시할 수 있으며 risk이면 `100-원본점수`로 정규화한다(기본 safety). 누락은 원칙적으로 null이고 해당 지표의 전체 관측 집합을 교체한다. 단, 팀에서 승인한 모델상 임시 기준값이 있으면 `unmatchedScore`(이미 안전 방향)와 `unmatchedReason`을 모두 제공한다. 다른 공간 형식의 자료는 먼저 GIS에서 공통 구간에 매핑해야 한다.
- 승인 후 전체 bundle의 config를 {"status":"approved","version":"pri-v1","weights":{"lighting":0.5,"width":0.5}}와 같이 설정(수치는 형식 예시일 뿐). 양의 가중치 합 1, 두 개 이상 지표. 필수 점수 중 하나라도 결측이면 종합 PRI 미평가. 지표 갱신은 다시 draft로 변경해 재승인 요구. 실제 가중치·등급 경계 미확정.
- 배포할 공통 bundle은 app/public/data/pri/에 두고 manifest.json의 bundle로 기본 조명 파일을 로드한 뒤 patches에서 상도1동 사고 지수를 결합합니다. 다른 4개 지표와 승인된 전체 종합 PRI는 아직 미평가입니다.
- routeExposure는 검증된 경로-구간 대응을 받는 향후 연동 함수. 현재 실제 경로 추천은 변경하지 않는다. 사고 확률 아님. 독립적인 기존 야간시야 및 다른 레이어는 유지.

## 확정된 팀 담당 항목
1. 교통사고 이력 및 위험 지수 (accidents) — 상도1동 경계 내 보행자 사고다발지 3건 → 76개 조명 도로구간에 실제 선정정보 기반 안전점수, 미선정 1,610개에는 임시 기본점수 100점(실제 무사고 뜻 아님)
2. 신호등·횡단보도 단절 구간 (crossing) — 미제출, null
3. 보차혼용 및 보행 공간 위험 (sharedRoad) — 미제출, null
4. 통행제한속도 및 감속 구간 (speed) — 미제출, null
5. 제도적 사각지대 (protectionGap) — 미제출, null
6. 가로등·CCTV 야간 안전 취약점 (lighting) — 원본 조명 취약도 점수만 제공됨; CCTV 미제출
원본 JSON 1,686개 구간, 419개 조명 지점, 총 40,131.5m. 좌표 한 개뿐인 10개 구간(그중 길이 0m 4개) 점 형상 유지. 테스트 데이터는 테스트에만 존재. 도로망 ID는 조명 조사 기준 임시 버전이며 다른 지표의 공간 매핑은 팀원 자료 도착 후 수행. 사용자 명시 요청으로 공개 앱 저장소에 원본 조명 파일을 실증용으로 포함한다. 지도 레이어는 기본 off이며, 지도 더보기 > 상도1동 PRI 위험도에서 야간 시야 안전점수, 사고다발지역 안전점수, 두 지수 평균(시범)을 선택한다.

### 연장 검증 (2026-11-20)
원본 조사 구간의 len 합 40,131.5m, 제공 좌표 내 선형 합 약 36,355.2m. 같은 OSM way의 연속 번호 구간 사이 4m 이하인 간격 1,309곳의 합 약 3,703.9m, 10m 초과인 간격 16곳의 합 약 902.8m. 간격의 실제 통행 가능성과 경계·중첩은 확인되지 않았으므로 선형을 이어 붙이지 않는다. 지도 범례에서 원본 조사연장과 좌표 선형을 구분하며 공식 총연장이나 중복 제거 도로망 연장으로 주장하지 않는다.

## PRI ② 사고다발지역 위험도 시범 반영 (2026-11-21)

- 사용자 제공 `동작구 보행자 사고다발지역 위험도 지수.xlsx`의 38개 선정기록 가운데 **야간 시야 `lighting_segments.json`의 상도1동 경계 내부에 있는 세 지점**만 사용한다: 구립로야어린이집(2024·50점), 상도1동주민센터(2023·40점), 리치타운(2022·40점).
- 법정동 '상도동' 전체를 사용하지 않는다. 사고다발지역 공식 제공 폴리곤을 기존 약 25m 조명 도로구간의 선형과 공간 교차하여 **76개 구간**에 사고 지수를 매핑한다.
- 사고 원본은 **위험도가 높을수록 높은 점수**다. 같은 구간에 사고다발 폴리곤이 겹치면 원본 위험점수 **최댓값**을 사용한 뒤 `100-위험점수`로 안전점수를 계산한다. 실제 중첩 76개 구간은 안전점수 50점(46개) 또는 60점(30개)이다. 나머지 1,610개는 사용자가 정한 **임시 기본 안전점수 100점**으로 처리하지만, 사고 발생 0건이나 안전 보장을 의미하지 않는다.
- 배포용 자료 `app/public/data/pri/sangdo1_accidents_factor.json`을 manifest의 `patches`에서 자동 로드하며, 같은 `networkVersion`의 공통 도로망에만 결합한다. 기존 야간 시야 레이어 자체와 측정값은 변경하지 않는다.
- `PRI ①·② 평균 (시범)`은 기존 1,686개 도로구간 전체에 **(100-원본 야간 시야 위험점수 + 사고 안전점수)/2**를 표시한다. 사고지수가 있는 76개 구간은 50~60점의 사고 안전점수를, 나머지는 임시 기본 안전점수 100점을 이용한다. **나머지 4개 지수는 결측(null)으로 유지되고 전체 6개 PRI는 비활성**이다. 즉 2개 지수 평균은 최종 PRI가 아니다.
- 자료 연도는 사고다발지 ID의 선정 기준연도이며 개별 사고 발생연도가 아니다. 산출 점수는 통행 중 사고 발생 확률이 아닌 상대적 위험도 참고 자료이다.

### 점수 방향 통일 (2026-11-21)

- 6개 PRI의 공통 해석 방향을 **100점=상대적으로 양호, 0점=상대적으로 취약**으로 지정한다. 아직 제출되지 않은 4개 지수의 점수 방향은 자료가 도착할 때 출처별로 확인하며, 자동으로 추정하지 않는다.
- 야간 시야 `lighting_segments.json`의 원본 `score`는 **높을수록 암부가 큰 위험점수**이다. 원본 파일을 고치지 않고 `adaptLighting()`에서 `scores.lighting=100-원본 score`로 변환한다. 기존 별도 야간 시야 분석 UI·원본 자료는 바꾸지 않는다.
- 사고다발지 `sangdo1_accidents_factor.json` 역시 원본 40·50점(위험)을 유지하며, import 시 안전 방향의 60·50점으로 변환한다. 자료가 없는 구간 1,610개에 대한 100점은 **공간 미선정의 모델상 기본점수**일 뿐 독립적 사고 발생조사 결과가 아니다.
- 팔레트는 **빨강=안전점수 낮음, 초록=안전점수 높음**이고 툴팁·범례에도 같은 설명을 적용한다. 단, 최종 상·중·하 등급 경계는 승인 전이다.
