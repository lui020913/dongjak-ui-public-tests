# 동작하는 안전지도 — 실제 앱 자동 개발 디자인 계약
기준: v8.9.11 후보 bd2d45b71158f4dc66c0fa62157a993d7b8ac285, 공개 UI 검증 44249437043 (9/9).
이 문서는 기존 공개 작업실의 [디자인 언어](DESIGN_LANGUAGE.md)와 [품질 감사](QUALITY_AUDIT.md)를 보존하며 실제 앱의 수정 업무에 적용할 추가 요구사항을 정리한다. 기존 문서의 프로토타입 전용 권한 제한을 이 문서로 우회하지 않는다. 아래 사항은 개선 목표이며 전 항목 실기기 통과를 의미하지 않는다.

## 디자인 및 인터랙션 불변 조건
- Modern Civic Minimalism, map-first, 녹색 브랜드, 밝은 아이보리, 라이트/다크 모두 기존 색상 의도 유지. 새 브랜드 테마 임의 도입 금지. 실제 앱의 기존 토큰을 재사용하고 공개 시제품 토큰을 원본에 일괄 덮어쓰지 않는다.
- Pretendard 우선, 한국어 가독성, 공통 베이스라인, 아이콘과 글자의 시각 중심, 일관된 굵기·라운드·4px 간격 체계. 불필요한 선/여백/그림자 제거하되 focus-visible 보존.
- 모바일·터치 태블릿(대형 가로 포함)·PC 전용 배치. 모바일 확대만으로 태블릿을 구성하지 않으며 검색/지도 버튼/하단탭/패널 겹침 금지. safe-area, 주소창, PWA 및 iOS 상단바 색상 경계를 별도로 고려. iOS 실기기 미검증을 명시한다.
- 검색창 내부 로고, 안전지도 아이콘 배경 제거 및 가독성, AI 버튼·검색창 뒤 불필요한 사각 배경 제거. 보행안전·야간시야·행정동 라벨 표시, 날씨는 동일 아이콘 위치와 온도 라벨, 더보기 형태 통일. 모바일 도구 스와이프 및 잘림 방지. 기존 주요 지도 기능을 제거하지 않는다.
- 모바일 하단 5개 탭(길찾기·커뮤니티·동작소식·내 기록·업데이트)은 기존 기능과 의미 유지. 탭/창 간격 일관성, TIP과 축척바 간격, 설치 안내와 TIP 중복 금지, 패널 열림 시 TIP 숨김.
- 창 제목과 X 위치 통일, 자연스러운 Fade와 방향성 있는 슬라이드, 단계별 closed/half/full 양방향 드래그·스와이프, 연타·취소·역방향 안전, 잔상/유령 팝업 방지. 기존 모션 시간과 reduced-motion을 존중하고 프레임을 측정하기 전 성능 향상을 주장하지 않는다.
- 시설 팝업 위치핀/제목/주소/전화/홈페이지 정렬, 기존 링크와 지도 선택 유지. 지하철 이전 종착 기점 표기 제거, 단일 방향은 전체 폭, 환승 탭·상하행·급행/시간표 유지. 버스 카드 정보 정렬/ETA 우측 정렬, 태블릿 카드 폭·손잡이 중심 정렬. 실제 데이터/오류 상태를 임의 조작하지 않는다.
- 더보기 SVG 크기/체크 UI 통일, 안전 패널 dim은 전체 화면, 안전 도구·야간시야 및 기존 기능 유지. 필요 없는 과도한 블러 추가 금지. 지도 조작과 키보드/터치 접근성 보존.
- 온보딩 승인된 녹색 계열 AI 그림 5장과 기존 설명 유지, 인물 번갈아 등장, 이미지 잘림 금지(object-fit contain), PC/태블릿 비율에 맞는 구성. 임의 재생성/교체 금지.
- 로그인/즐겨찾기/실시간 교통/안전시설/길찾기/내비게이션 등 기존 기능·연동 회귀 방지. 수정 요청과 무관한 기능·브랜드·테스트를 변경하지 않는다.

## 실행과 증빙
- 사용자 요청과 실제 재현 오류를 우선하며, 수정 전에 최신 소스와 동시 작업을 확인한다. 연관 결함만 묶어 수정하고 이미 해결한 항목을 반복 변경하지 않는다.
- 실제 Preview의 정확한 소스 SHA와 build run을 검증하고 기존 Node 전체 테스트, 빌드, 9개 화면(mobile375, mobile390, tablet768, tablet820, tablet1024, tablet1180, pc1280, pc1440, pc1920)의 브라우저 검증을 유지한다.
- 전후 화면·DOM 좌표·계산 CSS를 비교하고 라이트/다크·키보드·터치·드래그·반응형·접근성·상태 전환을 변경 범위에 맞춰 추가 검증한다. 미검증은 미검증으로 기록. 기존 테스트 약화/삭제, 실패 숨김, 장애 우회 금지.
- 이벤트 기반 실행만 사용하고 복구 시도는 총 3회로 제한한다. 기존 공개 UI 작업실의 시간제 실행 권고는 이번 실제 앱의 이벤트 기반 실행 규칙으로 대체한다.
- 비공개 소스·인증 정보·비공개 빌드 로그를 공개 저장소/외부 모델로 전송하지 않는다. Gemini에는 허용된 익명 진단과 이 공개 디자인 계약만 제공할 수 있다. 생성된 수정 제안은 실행 권한과 분리한다.
- Preview와 Production 구분. 직접 요청의 범위 내에서 수정/검증/Preview를 진행하되 Production 승인 게이트 및 정확한 검증 기록을 우회하지 않는다.
