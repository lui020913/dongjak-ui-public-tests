# 상도1동 제도적 보호구역 공백 연구: **300m 단일 평가기준**

작성: 2026-11-22. 이 연구의 **최신 평가 규칙**은 **300m 하나**다. 이전 150m 집중 평가·300~500m 확장 평가, 19시설 통합 '100-점수' 방향의 시범값은 **역사적 비교자료로만 보관**하며 이번 색상 지도와 최종 점수에 사용하지 않는다.

## 입력 범위 / 유효성
- 상도1동 **참고경계** 안 공통 OSM 25m 세그먼트 **1,686개** 중 유효 **1,676개**, 좌표 결측 **10개**.
- 동작구 경찰청 **2025-05-27** 자료만 사용: 어린이 관련 시설 대표점 **15곳**과 등록 폴리곤 **14개**, 노인 관련 시설 대표점 **4곳**과 등록 폴리곤 **4개**. 서로 다른 유형끼리 폴리곤이나 시설점을 혼합하지 않음. 장애인 대상 시설 원본 미확보 → **점수 미산정**, 시설이 없다는 의미 아님.
- 도로 중심선은 팀원들과 공통 사용하는 OSM 좌표이며 **조명, 도로폭, 사고다발지역, 경사, PRI 점수는 어떠한 가중치·선별 필터로도 넣지 않음**.
- 공식 **2026-09-20 초등학교 학구도 SHP**는 인근 학교 이름만 주석으로 연결한다. 통학구역을 실제 통학로/법정 어린이보호구역과 혼동하지 않음.
- **최신 2026 보호구역 고시**, 실 주 출입문, 인접 자치구 시설 전체, 법정 상도1동 행정경계는 **확정하지 못함**. 따라서 '법적 미지정 사각지대'라는 단정은 금지.

## 300m 내 도로 표본만 평가
1. 각 25m 도로 중심선을 약 **5m 간격으로 표본화**.
2. 해당 유형 시설 **대표점**까지 최단 직선거리 `d`가 **300m 초과**인 도로 표본은 계산에서 제외.
3. `d ≤ 300m`일 때 같은 유형 **2025년 등록 보호구역 폴리곤 내부**이면 보호 포함 점수 **100**, 외부이면 **`P=100×d/300`**.
4. 해당 도로 구간에서 유효한 **300m 내 표본끼리** 길이 가중평균해 도로의 `0~100 보호 포함 점수`를 구한다. **낮을수록 시설점 근처에서 기존 등록 보호구역이 비어 있다는 연구용 공백 신호가 큼.**
   - **표시 반올림 규칙:** 폴리곤 외부 표본이 하나라도 있는 도로의 평균이 소수 첫째 자리에서 100.0으로 반올림될 경우 **99.9점으로 제한**한다. 100점은 유형별 등록 폴리곤 안에 포함된 경우에만 사용한다.
5. 도로의 표본이 **전부 300m 밖이면 `null`(회색, 평가권 밖)**. 100점을 할당해 '보호 완료/안전'으로 보이지 않도록 함.
6. 부분적으로 300m에 걸친 도로는 `evaluated_pct_of_segment`에 적용 비율을 남기며, 지도용 **절단 선형(clipped GeoJSON)**에는 약 5m 중점이 300m 내인 부분만 출력한다. 절단 위치는 최대 약 2.5m 표본 오차를 가질 수 있다.

**색상은 도로의 보행사고 위험도가 아니라 시설 대표점과 2025 기존 등록 폴리곤의 공간 관계**를 시각화한다. 동일 도로 내 보호구역 일부가 포함됐더라도 도로 평균점수가 100 미만이면 평균색으로 표시하고, `registered_zone_pct_of_evaluated` 수치를 개별 속성에 보존한다. 시설에 가까운 도로가 위법하게 지정되지 않았다는 의미는 아님.

## 300m 전수 분석 결과
두 유형 간 같은 도로 세그먼트가 중복될 수 있으므로 단순 합산 금지. 도로 유형은 OSM의 `primary, secondary, tertiary, primary_link, residential, service`를 **차량도로형**으로, 보행로/계단은 점수를 보존하면서 차량도로 후보 순위에서 제외했다.

| 분류 | 어린이 보호구역 관련 | 노인 보호구역 관련 |
| --- | ---: | ---: |
| 매우 큰 보호 공백 (0~25 미만) | **68** | **56** |
| 큰 보호 공백 (25~50 미만) | **267** | **141** |
| 중간 보호 공백 (50~75 미만) | **279** | **166** |
| 작은 보호 공백 (75~100 미만) | **244** | **199** |
| **차량도로형 잠재 공백 검토 세그먼트** | **858** | **562** |
| 300m 해당 표본이 있는 전 차량·보행 도로 | 1,080 | 674 |
| 300m 내 기존 등록 보호구역으로만 덮인 세그먼트 | 38 | 2 |
| 300m 평가권 밖 세그먼트 | 596 | 1,002 |
| 유효 도로 형상 없음 | 10 | 10 |

**858개 / 562개는 세그먼트 수이며 독립적인 도로 수나 법적 지정 누락 건수가 아님.** 기준일이 오래됐고 직선거리/시설 대표점을 쓴 모형이므로, 실제 법적 지정 필요성은 별도 현행 고시·출입문·도로 기능 검증이 있어야 판정 가능.
