## 3개 자료 근거와 정확한 이용 범위
1. 2025-05-27 경찰청 등록 어린이/노인 보호구역 도형 및 19개 시설 대표점. 기존 300m 거리점수(보호구역 내부 100점, 외부는 거리/300×100, 범위 밖 NULL)를 그대로 기초 입력으로 사용한다.
2. `app/public/data/sangdo1-analysis-view/roadwidth.geojson`의 추정 도로폭을 각 도로 중심선 약 5m 표본과 공간교차한 뒤 중첩연장으로 가중평균한다. 중심선 연장의 50% 이상에서 도로폭이 확인될 때만 점수 보정에 사용한다. **도로폭은 보도의 실제 유효폭/보차분리 증거가 아니다.**
3. 한국교육시설안전원 공식 2026-09-20 초등학교 학구도 SHP와 정확한 공간교차 결과 `sangdo1_road_catchment_overlay_20260920.json`를 사용한다. **동일한 초등학교가 최근접 보호대상 시설인 어린이 유형 도로에서만** 해당 학교 학구의 도로 중첩률을 약한 보조 변수로 사용한다. 유치원/어린이집/노인시설에서는 학구를 보호 필요도로 오인하지 않고 해당 변수는 비적용이다. 학구는 **실제 통학로가 아니다.**

## 계산식: 통계적 실측 지수가 아닌 연구용 경험적 가중모형
- 기존 300m 거리·등록구역 점수 `D`, 권장 기초 가중치 60.
- 도로폭 우려 보정 `W=clip((추정 도로폭_m - 4)/4 ×100,0,100)`; 좁은 도로일수록 낮음. 가중치 25. 중첩률 50% 미만/자료 없음이면 W 미적용(0점 임의 대체 금지).
- 같은 초등학교 학구와 중첩 시 `C=100-(해당 학교 학구의 도로 중첩률 %)`; 많이 중첩할수록 낮음. 가중치 15. **가장 가까운 시설이 학교일 때에만 적용**. 자료 미적용을 100점 혹은 0점으로 바꾸지 않음.
- 유효 항목만 재정규화: `P=(60D+25W+15C)/(60+25+15)`에서 비적용 항목과 해당 가중치 자체를 각각 제외한다.
- 기존 300m 해당 유형 보호구역에 완전히 포함된 도로(D=100): **P=100**을 유지하여 유효한 등록구역에 감점을 주지 않는다.
- 기존 유형별 점수가 NULL이면 P도 NULL. 100점 미만 구간의 표시상 반올림이 100점이 되지 않도록 99.9점 상한 적용.
- 어린이 P와 노인 P를 **별도 보존**, 통합 시범 점수는 사용 가능한 두 유형 중 더 낮은 점수를 선택한다. 이 최솟값 규칙은 보수적 참고 결정이며 기관 공인 산식이 아니다.
- 일부만 300m 내인 25m 세그먼트는 기존 점수의 300m 내 표본 기준 평균을 이어받고 25m 세그먼트 전체에 같은 색을 적용한다. 경계 오차는 한 구간 안에서 발생할 수 있음.

## 팀 6개 지표 결합 계약
- `combined_new_score`가 숫자면 이 지표 포함 + 다른 5지표 = 6개 평균.
- `combined_new_score`가 NULL이면 **이 지표만 제외**, 나머지 5개 지표 평균. `team_average_divisor` 6 또는 5를 CSV에 기록.
- 단, 나머지 5지표 중 다른 결측이 있다면 추가로 합산식 검증 필요. 다른 팀원의 자료를 읽거나 합쳐 계산한 것이 아니다.
- `width_applied_child`, `width_applied_elderly`, `school_applied_child`, `width_coverage_pct`를 통해 자료 미포함/비적용 여부 확인.
- 공통 키 `segment_id`; 다른 팀원 자료의 서로 다른 세그먼트 ID는 선형 중첩/공간 조인으로 연결해야 하며 도로명만으로 조인 금지.
