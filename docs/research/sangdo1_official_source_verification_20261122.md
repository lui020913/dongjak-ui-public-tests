# 상도1동 통·반 경계 및 법적 보호구역 최신성 공개자료 확인
조사일: 2026-11-22 | 이-작 프로젝트 / 문헌·출처 확인 기록 (새 GIS 재분석 아님)

## 조사 결론
- 2026년 공식 **초등학교 통학구역 SHP**는 기존 분석에 확보되어 있으나, 20통 2반 및 22통 11반의 **행정 통·반 경계 SHP/GeoJSON**은 공개 검색에서 검증 가능한 원본을 찾지 못했다.
- 2025년 상도1동 통·반별 배정 정보는 동작관악교육지원청에서 제공. **2025 학구 배정표의 통·반 이름만으로 지도 좌표를 역산하지 않는다.**
- 최신 보호구역 확인용으로 **2026-09-22 수정 동작구 전국어린이보호구역표준데이터**가 공개되어 있음. 시·구 보호구역 목록은 시설 단위 속성 확인용으로만 사용 가능하며 **법적 지정 도로 시점·종점 증빙을 대체하지 않음**.
- **서울시 어린이 보호구역 지정현황 2026-06말 기준 XLSX**가 2026-07-15 게시됨.
- **도시교통정보센터(UTIC)**는 경찰청 연계 보호구역 point/polygon 지오메트리 REST API를 설명하며 1회/일 갱신을 표기. 실제 최신 동작구 레코드 대조를 위해 인증키와 다운로드된 피처별 데이터 확인 필요.
- 공개 검색 범위에서는 상도로54길 R0248·상도로62길 R0288의 **현행 고시 도로 구간을 특정한 증빙**을 발견하지 못했음. GIS상 폴리곤 미포함은 법적 지정 누락이나 위험확정의 증명이 아님.

## 자료별 사용 범위
| 자료 | 확인된 사실 | 사용하면 안 되는 주장 |
|---|---|---|
| 2025 교육지원청 표 | 거주 통·반의 학교 배정 규칙 | 개별 통·반의 위치 또는 학생 실제 도보경로 |
| 2026 통학구역 SHP | 학교 배정구역 면 경계 | 어린이보호구역 지정경계·통학로 |
| 2026 동작구 어린이보호구역 표준 CSV | 등록 시설/관리기관/기초 속성 | 도로별 고시의 법적 시·종점 |
| UTIC 보호구역 폴리곤 | 공개 등록 GIS 공간범위 (원본을 실제 새로 조회할 경우) | 고시문 대조 없이 법적 최종 범위 확정 |
| 지정 고시·지정구간 지도 | 현행 법적 지정구간 확인 가능 | 그 구간의 실제 보행위험도 확정 |

## 미확인 원자료 요구사항 (필요할 때)
**상도1동 주민센터·동작구 소관부서:** 2026년 11월 기준 20통 2반·22통 11반 관할구역도/번지별 포함 목록/위치도(개인정보 제외). 보유하지 않으면 통·반 구역을 확정한 부서 확인.

**서울시/동작구 교통소관부서:** 서울상현초, 샛별유치원 및 인접 보호구역의 최신 지정/변경/해제 고시번호, 원문, 도로별 시점·종점, 해당 구역 도면 및 현행성 날짜. 상도로54길(R0248), 상도로62길(R0288)은 프로젝트 임의 도로 ID이므로 민원에 실주소·GIS 이미지 동봉 권장.

**원본 비교 작업:** 2025-05-27 기존 경찰청 데이터와 2026-09-22 구 최신 현황, 당일 갱신 폴리곤을 시설 ID·등록일·기하학으로 비교하되, 세 데이터의 집계 대상(어린이/노인/장애인) 차이를 유지. 2026 공식 행정동 경계로 클리핑을 재검증한 후 점수 재산정. 현행성 검증 전 기존 지도/PRI/길찾기를 자동 변경하지 않는다.
