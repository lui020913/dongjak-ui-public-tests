# 상도1동 통·반 경계 및 보호구역 최신성 공개자료 검증
조사일: 2026-11-22 | 공개 웹 자료와 기존 GIS만 사용 | 담당기관 연락·정보공개청구 없음

## 공식 출처 재확인과 중요한 정정
1. **경찰청 도시교통정보센터(UTIC) 구 보호구역 API의 갱신은 2025-01-06 이후 중단**. 현재 페이지의 구 API 샘플과 화면에 ‘2026-11 최신 수정’ 및 ‘1일 1회’가 표기되어 있더라도, 동일 페이지에 명시된 **업데이트 중단 공지**를 우선 적용해야 한다. 이 구 API를 2026년 현행 보호구역 도형 근거로 쓰지 않는다.
   - 근거 https://www.utic.go.kr/guide/utisSafe.do
2. 경찰청의 **새 공공데이터포털 전국 보호구역 현황 API** (geometry 포함): https://www.data.go.kr/data/15142010/openapi.do — 서비스키가 필요한 REST API, URL `https://apis.data.go.kr/1320000/safetyzonedtlinfo`. 2026-11-22 실제 재호출 결과가 확보된 것은 아니므로 기존 2025-05-27 원본을 최신으로 간주하지 않는다.
3. **전국어린이보호구역표준데이터** https://www.data.go.kr/data/15012891/standard.do — 포털 수정일 **2026-09-22**, 반기 갱신, 시설종류·주소·위도·경도 등. *데이터셋 페이지의 수정일은 동작구 개별 시설의 현행 고시일을 증명하지 않는다.* 보호구역 도로 경계 폴리곤 대체 불가.
4. **서울시 어린이보호구역 지정 현황** https://data.seoul.go.kr/dataList/OA-2799/F/1/datasetView.do — `2026.6월말 기준.xlsx`가 **2026-07-15** 공개돼 있음. 표 자료 존재를 확인했으며 파일 본문을 가져와 시설별 매칭한 것은 아님.
5. **한국교육시설안전원 2026-09-20 공식 초등학교 학구도 SHP** https://www.data.go.kr/data/15159265/fileData.do — 기존 연구에서 SHA256 `66b7650d5eef3b900061083b3d8f5c8f6dcb8eb00b891e6b03132f08fdca2911` 검증, 상도1동 참고경계와 교차하는 8개 학구.
6. **2025-03-17 동작관악교육지원청 학교별 통학구역표** https://dgedu.sen.go.kr/CMS/introduction/introduction06/introduction0604/introduction060402/index.html — 상도1동 배정 4개교(강남초·상현초·은로초·봉현초), 반별 예외. 개별 통·반 좌표계·경계는 공개 검색에서 확보되지 않음.

## 자체 도로 단위 GIS 교차검증 (구 보호구역 vs 공식 학구도)
기준: 기존 프로젝트 25m 도로 **1,686개**, 선형 있는 **1,676개**. 2026 통학구역 SHP는 **단순화 전 원본 폴리곤으로 투영좌표 정확 교차**했던 도로별 학구 연장을 재사용했다. 2025-05-27 경찰청 연구용 18개 보호구역 등록 폴리곤은 **도로 2m 간격 점 샘플링으로 등록구역 내 도로연장을 추정**했다. 두 자료의 좌표/기하/시점 차이 때문에 법적 교차의 확정값이 아니라 *연구용 추정 구간*을 제공한다.

두 공간집합의 동일 도로 내 알려진 연장 (A)(학교별 학구), (Z)(등록 보호구역), 전체 도로 연장 (L)에 대해 두 선형의 교집합 길이는
`max(0, A + Z - L) <= 교차연장 <= min(A,Z)`.
**이 범위의 엄밀성은 입력 연장 A·Z가 정확하다는 조건부**이며 현재 Z는 표본 근사값이다. 특정 반의 실제 통학경로는 나타내지 않는다.

학교별 연장은 **학교별 중첩**이므로 합계가 학구도 전체 도로 합집합 35,210.20m와 반드시 같지 않다. 기존 보호구역 18개와 도로 중심선의 샘플링 추정 총교차는 **약 1,184.58m** (이전 기존모형 5m 샘플링 1,185.71m와 1.13m 차이). 보호구역 전체의 총선형연장은 기하학적 중심선·표본에 종속되고, 실제 지정 도로폭을 나타내지 않는다.

### 기존 집중검토 후보
- `R0248` 상도로54길, 68.94m 구간: 상현초 공식 학구도 폴리곤 내부(지도 표시용 경계와 도로 표본 중첩), 기존 2025 18개 경찰청 연구용 등록 보호구역 폴리곤과 교차 0m, 연구모형 27.4점. **법적 보호구역 미지정 확정 아님.**
- `R0288` 상도로62길, 58.51m 구간: 상현초 공식 학구도 내부, 기존 2025 폴리곤 교차 0m, 연구모형 19.0점. **법적 보호구역 미지정 확정 아님.**
- 검토 근거는 통학구역 소속 여부와 이전 TAAS 중첩(현장조사 증거)이며 **어린이가 실제 해당 도로를 이용하는지는 미확인**.

### 품질관리에서 발견된 중요한 오류 회피
2026년 공식 학구도 지도용 폴리곤은 경계 표시를 위해 **1.5m 단순화된 별도 산출물**이다. 이 표시용 도형을 도로 2m 간격으로 다시 샘플링하면 정확 SHP 원본 길이 대비 **1,315.09m 적게** 계산된다. 이를 보호구역 법적 미포함 또는 학구 공백으로 분류하는 것은 오류. 따라서 해당 샘플 집계 결과는 **폐기**, 원본 SHP의 투영좌표 도로교차 결과(`sangdo1_road_catchment_overlay_20260920.json`)로 대체했다.

## 현재 결론과 작업 제한
- 2025 경찰청 18개 연구용 폴리곤 **밖**의 도로는 식별할 수 있으나 2026 현행 법적 지정고시의 실제 **미지정 구간**이라고 확정할 수 없음.
- 2026 포털 표준/서울시 XLSX **데이터셋 존재는 검증했지만 본문 시설별 비교를 완료한 것이 아님**. 이번 결과를 최신 2026 시설별 대조 완료라고 쓰지 않음.
- 개별 통·반의 공간경계/아파트·번지 목록은 공식 공개 GIS로 미확보. 학교 학구도와 혼동하지 않음. 20통 2반, 22통 11반의 학교 배정 예외는 원문으로만 유지.
- **담당기관 연락, 민원, 정보공개청구 미실시.**
- 연구용 PR에서만 자료 보관. 실서비스 보호구역 표기·PRI 자동 패널티·운영 배포에 반영하지 않음.
