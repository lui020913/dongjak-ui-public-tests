## 설계 원칙: 보행안전 위험과 보호구역 공백은 다른 지표
1. **기존 125개 후보를 필터·학습·가중치로 사용하지 않는다.** 최초 전수 공간 입력은 25m 도로망 **1,686개** 전체다. 그중 형상 있는 **1,676개**, 결측 **10개**.
2. 보호구역 점수는 **2025-05-27 경찰청 등록 보호대상 시설 대표점 및 유형별 등록 폴리곤**의 공간 관계에서만 계산한다. **팀원 조명·도로폭·사고(TAAS)·경사·PRI 종합 점수는 사용하지 않는다.**
3. 팀원 분석에서 공유한 것은 **OSM 도로 중심선의 id·이름·도로유형·좌표**만이다. 해당 파일의 조명 점수, dark, 등급, 램프 위치를 사용하지 않는다.
4. 한국교육시설안전원 **2026-09-20 공식 초등학교 통학구역 SHP**의 정밀 도로 교차 결과는 *설명·검증용 부가 정보*다. **학교 배정구역을 어린이보호구역 또는 실제 통학로로 취급하지 않고 점수에 가중하지 않는다.**
5. **어린이/노인 유형을 분리해서 평가한다.** 어린이 시설 점수에 노인시설 등록 보호구역을 보호된 영역으로 합산하지 않는다. 장애인 시설 자료가 이번 추출범위에 **0건이므로 평가하지 않는다**. 장애인 공백점수 0 또는 100으로 허위 계산하지 않는다.

## 계산식과 해석
- 각 도로 중심선을 약 **5m 간격으로 표본화**하고, 각 표본의 보호구역 유형별 지정 폴리곤 안팎 및 유형별 시설 대표점과의 최소 **직선거리**를 사용한다.
- 동일 유형 지정 폴리곤 **내부**: 보호 포함 점수 `P=100`.
- **외부**: `P = min(100, d/5)` (d는 동일 유형 시설 대표점까지 최단 직선거리, m).
- 각 도로 점수는 5m 표본별 길이 가중평균. **보호 공백 신호 점수 = `100-P`**.
- 공백 신호 점수가 100에 가까우면 시설 대표점과 가깝고 기존 2025 유형별 폴리곤으로 덮이지 않은 도로다. **위험률·현행 위법·법적 의무·지정 필요성을 직접 뜻하지 않는다.**
- 내부 폴리곤이거나 대상 시설과 500m 초과라서 점수가 0인 도로도 **안전하다고 판정하는 것이 아니다**.
- 시설점 반경 **0~300m**와 **300~500m**를 별도 분류한다. 이 반경은 **법정 지정구간 확정 도형이 아니다**.
