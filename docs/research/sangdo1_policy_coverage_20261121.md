# 상도1동 보호구역 반경과 제도적 보호 공백 — 2026-11-21 시범 분석

## 목적과 결론
기존 지도에서 붉게 표시되던 R0248(상도로54길)·R0288(상도로62길)은 125개 현장검토 후보 중 최근 표기 사고다발지역과 중첩되는 **우선 검토 2곳**일 뿐, 상도1동의 전체 제도적 사각지대가 아니다.

이번 연구 브랜치는 기존 공개 앱의 도로 세그먼트 1,686개 전체를 대상으로, 보호대상 시설 **대표 POINT**로부터 300m/500m 분석 범위와 경찰청에 등록된 **실제 보호구역 폴리곤**을 중첩하여 **법적 위반·실제 사고위험 확정이 아닌, 현장검토 후보를 확대 표시**한다.

### 현재 입력
- 경찰청 보호구역 폴리곤 9곳: 어린이 7곳, 노인 2곳 (상도1동 경계와 교차하는 것)
- 해당 시설 대표 POINT 9곳: 초등학교 2곳, 다른 어린이시설 5곳, 노인시설 2곳
- `app/public/data/pri/lighting_segments.json`: 가로등 분석에 사용한 25m 도로 세그먼트 1,686개
- 원본 후보 자료 125개는 전수 도로망이 아니므로, 이번 전체 평가의 모수가 아니다.

## 실제 중첩 결과 (임시 수치)
| 결과 | 길이 | 중첩 세그먼트 |
| --- | ---: | ---: |
| 9개 시설 대표점 **300m 이내**, 보호구역 폴리곤 외부 | 21,284.0m | 1,016개 |
| 9개 시설 대표점 **300m 초과~500m 이내**, 보호구역 폴리곤 외부 | 8,037.7m | 389개 |
| 보호구역 폴리곤 내부에 해당하는 도로 좌표선형 | 1,185.7m | 76개 |
| **초등학교 2곳** 대표점 300m 이내, 해당 학교 보호구역 도형 외부 | **10,635.12m** | **516개** |
| **초등학교 2곳** 대표점 300m 초과~500m 이내, 해당 학교 보호구역 도형 외부 | **13,190.16m** | **637개** |

*세그먼트는 300m 경계를 가로지를 수 있어, 범주별 중첩 세그먼트 수는 중복된다. 길이는 5m 표본이 대표하는 길이의 합계다. 학교 대상 300m·500m 결과는 학교와 대응되는 지정 폴리곤만 사용한 별도 분석이다.*

원자료 명목 구간 길이는 **40,131.5m**지만, 실제 파일에 저장된 `pts` 좌표를 이은 선형의 계산 길이는 **36,375.83m**다. 1,686개 중 1,676개만 길이를 갖고, 10개는 `NULL`이다. 따라서 지도상 계산연장을 상도1동의 법정 총 도로연장으로 확대 해석하거나 두 수치를 섞지 않는다.

## 점수 산정 규칙 (연구 시범)
지점마다 5m 간격으로 거리와 지정 여부를 확인한다. 해당 지점이 보호구역 내부이면 시범 적정성 점수 `S=100`, 외부이면 가장 가까운 시설 대표점까지의 직선거리 `d(m)`를 사용하여 `S=min(100,d/5)`로 계산한다. 각 25m 세그먼트의 값은 표본이 대표하는 선형 길이에 따른 가중평균이다.

- 0점: 보호대상 시설 대표점과 인접하지만 지정 보호구역 밖이라는 **공간적 불일치가 큼**
- 100점: 지정 폴리곤 내부 **또는** 해당 모형의 검토 반경(500m) 밖
- 100점이라도 보행사고가 없거나 안전시설·제도적 보호가 충분하다는 의미는 아니다.
- 학교만의 분석은 초등학교 2곳과 대응되는 어린이보호구역 폴리곤으로 따로 계산했다.
- **점수에 사고 중첩·가로등·도로폭을 다시 가산하지 않았다.** 다른 PRI 위험점수와 의미 및 방향이 다르며 PRI에 직접 평균하거나 경로 회피비용으로 연결하지 않는다.

| ID | 도로명 | 모델 점수 | 지정구역 내 연장 | 300m 내 미지정 연장 |

두 구간은 시설 최단거리 하나가 아니라 **실제 선형의 5m 간격 표본 평균값**으로 계산했다. 가장 가까운 시설은 두 구간 모두 청송경로당이어서, 이전의 '상현초·샛별유치원 최소거리' 계산과 점수가 다르다.

## 앱 표시
- **상도1동 보행안전 검토 → 지도에 표시 → 상세 분석**에서 '초등학교 반경 300·500m 미지정 검토 도로'를 켤 수 있다(기본 체크).
- 주황색 계열: 300m 이내 미지정 검토 후보, 황토색 계열: 300~500m 확대 검토 후보.
- 클릭 팝업에는 학교 대표점까지 거리, 25m 구간에서 범위에 포함된 비율, 연구용 점수, 한계 안내를 제공한다.
- 간단 보기는 기존 2개 집중검토 후보를 유지해 복잡도를 늘리지 않는다.
- 다른 기본 지도 기능 및 기존 PRI 점수, 경로 탐색 비용은 수정하지 않는다.

## 검증/해석 한계 및 다음 단계
1. **대표 POINT ≠ 주 출입문.** 공식 출입문과 지정 고시의 시·종점을 확인해야 한다.
2. **법적 미지정 ≠ 지정 의무 위반.** 보호구역은 300m/500m 원 전체가 아니라 조사·협의에 따라 도로 중 일정 구간을 지정한다.
3. **인접 행정동 학교·시설 누락 가능.** 현재 앱에 있는 상도1동 교차 폴리곤 9곳만 분석하여, 전체 동작구 제공 64시설의 경계 외 효과는 포괄하지 못했다.
4. **직선거리 시범 계산.** 실제 도보 네트워크, 통학로 동선, 보행자 통행량, 대체 보호제도는 추가 검증 전이다.
5. **좌표선형 일부 단축 문제.** 조명 지도와 분석 경계·구간 ID를 재정합하고, 자료의 `len`과 `pts` 길이 차이를 검토해야 한다.
6. 팝업의 **시범 점수는 안전도·사고확률·공인 위험등급이 아니다.**
