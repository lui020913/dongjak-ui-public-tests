# Integrated Native compatibility preview
Separate experiment, application ID kr.dongjak.nativepreview. No production deployment. Original full app web assets and UI retain their current behavior. The Native SDK mirrors serialized style, currently loaded GIS sheets, district mask, transport/facility/PRI layers and camera. Dynamic HTML markers remain in WebView. Runtime image copies are best effort; style/source/terrain parity is not established. Raw Terrarium DEM is used for the native mirror instead of the browser-only corrected custom protocol. Five disjoint browser building stages are consolidated for native, with no intentional geometry reduction. Native style updates are snapshots, not incremental yet. Underlying GL continues rendering invisibly, therefore this preview cannot establish native-only FPS and can be slower. Fall back to visible GL if native style fails or user toggles. Native-specific click hit testing and camera alignment need physical device QA; the web engine remains interaction owner. This is a compatibility experiment, not a complete port. The existing public read APIs/config are unchanged; avoid using personal accounts during experimental testing. Do not merge or deploy to production. Native style compatibility, custom icons, feature state, corrected terrain and real-time updates require verification and eventual single-renderer adapter.
